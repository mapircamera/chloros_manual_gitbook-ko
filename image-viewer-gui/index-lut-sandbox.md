# 지수/LUT 샌드박스

지수/LUT 샌드박스는 Chloros 이미지 뷰어 내에 있는 대화형 작업 공간으로, 다중 스펙트럼 지수 계산과 색상 시각화를 실시간으로 실험해 볼 수 있습니다. 이 강력한 도구를 사용하면 전체 데이터 세트를 다시 처리하지 않고도 다양한 지수를 테스트하고, 값 범위를 조정하며, 바로 출판 가능한 시각화 자료를 생성할 수 있습니다.

## 인덱스/LUT 샌드박스란?

### 목적

샌드박스는 다음 기능을 제공합니다:

* **실시간 인덱스 계산** - 모든 식생 지수를 즉시 적용
* **대화형 LUT 조정** - 색상 그라데이션 및 범위 미세 조정
* **워크플로우 최적화** - 일괄 처리 전에 최적의 설정 결정

### 샌드박스 대 프로젝트 처리

**지수/LUT 샌드박스 (대화형):**

* 한 번에 하나의 이미지
* 즉각적인 피드백
* 실험 및 반복 작업
* 파일에 영구적인 변경 없음
* 탐색 및 테스트에 최적

**프로젝트 처리 (배치):**

* 전체 데이터셋을 한 번에 처리
* 사전 구성된 설정
* 영구적인 출력 파일
* 시간이 많이 소요됨
* 설정이 확정되었을 때 가장 적합

{% hint style="success" %}
**최적의 워크플로**: 샌드박스를 사용하여 실험하고 최적의 인덱스 및 LUT 설정을 찾은 다음, 프로젝트 처리 단계에서 전체 데이터셋에 해당 설정을 적용하세요.
{% endhint %}

## 인덱스/LUT 샌드박스 사용

### 사전 계산된 인덱스 이해

Chloros에서는 프로젝트 처리 중에 인덱스를 적용할 수 있습니다. 내보내기 작업에 적용할 인덱스 및 LUT 설정을 결정하는 가장 쉬운 방법은 이미지 뷰어 샌드박스를 사용하는 것입니다.

샌드박스를 사용하면 다음을 수행할 수 있습니다:

* **새로운 인덱스 및 색상 그라데이션(LUT)**을 적용하여 데이터를 시각화
* **시각화 설정**을 대화형으로 조정
* **이미 계산된 인덱스 이미지** 확인
* 모든 확대/축소 수준에서 픽셀 값 **확인**

### 샌드박스 열기

인덱스/LUT 샌드박스는 **이미지 뷰어** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 사이드바 탭에서 액세스할 수 있습니다:

1. 파일 브라우저 이미지 그리드에서 이미지를 클릭하면 **이미지 뷰어** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 탭에서 열립니다
2. **이미지 뷰어** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 탭을 클릭하여 왼쪽 팝아웃 사이드바를 엽니다(아직 열려 있지 않은 경우).

### 인덱스/LUT를 적용할 이미지 선택

이미지 뷰어 <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 샌드박스에서 인덱스를 사용하려면:

1. 메인 이미지 그리드에서 이미지를 클릭하여 **이미지를 엽니다**

2. 그러면**이미지 뷰어** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 탭이 열립니다
3. **레이어 드롭다운**(뷰어 우측 상단)을 클릭합니다
4. 드롭다운에서 레이어를 선택합니다:
   * RAW (반사율)

### 이미지에 인덱스 적용하기

이미지가 전체 화면으로 표시되고 **이미지 뷰어** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 탭 사이드바가 열리면:

1. 사이드바 상단의 인덱스(Index) 상자를 선택합니다
2. 왼쪽 드롭다운에서 카메라의 필터를 선택합니다
3. 오른쪽 드롭다운에서 원하는 인덱스 공식을 선택합니다
4. 필터 채널의 색상 원을 아래의 인덱스 공식 내 위치로 드래그합니다
5. 공식이 유효해지면 이미지가 업데이트되어 인덱스 값을 표시합니다
6. 마우스 커서를 움직여 커서가 위치한 곳의 값을 확인합니다
7. 확대하여 개별 픽셀과 해당 값을 확인하세요

각 인덱스에는 고유한 값 범위와 의미가 있습니다:

#### NDVI 예시

```

Formula: (NIR - Red) / (NIR + Red)

For Survey3W RGN camera:
NIR = 850nm band
Red = 661nm band

Result range: -1.0 to +1.0
Typical vegetation: 0.4 to 0.9
Stressed vegetation: 0.2 to 0.4
Bare soil: 0.0 to 0.2
Water: -0.1 to 0.1
```

인덱스 공식에 대한 전체 문서는 [다중 스펙트럼 인덱스 공식](../project-settings/multispectral-index-formulas.md)을 참조하세요.

## LUT(룩업 테이블) 사용

### LUT란 무엇인가요?

**룩업 테이블(LUT)**은 시각화를 위해 수치 인덱스 값을 색상으로 매핑합니다:

* **입력**: 인덱스 픽셀 값 (예: NDVI 0.65)
* **출력**: 색상 (예: 밝은 녹색)
* **목적**: 패턴을 더 쉽게 보고 해석할 수 있도록 함**그레이스케일 대 컬러 LUT:**

* 그레이스케일: 과학적이고 중립적이며, 원시 데이터를 보여줌
* 컬러 LUT: 직관적이고 시각적 효과가 뛰어나며, 패턴과 차이를 강조함

{% hint style="success" %}
**시각화 효과**: 그레이스케일 인덱스 이미지에 컬러 LUT를 적용하면 패턴, 이상 현상 및 관심 영역을 한눈에 식별하기가 훨씬 쉬워집니다.
{% endhint %}

### 인덱스 이미지에 LUT 적용하기

인덱스 이미지가 준비되면

1. <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> &quot;+LUT 추가&quot; 버튼을 클릭합니다
2. 색상 그라데이션을 선택합니다
3. 클리핑 최소/최대 끝점을 조정합니다
4. 클리핑 모드를 조정합니다
5. **이미지 뷰어** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 탭의 사이드바에서 &#x27;인덱스&#x27; 상자를 선택하여 LUT를 적용합니다

### 색상 그라데이션 선택

**그라데이션 선택 방법:**

1. LUT 패널에서**색상 그라데이션 막대**를 찾습니다
2. 마우스를 그 위에 올려놓으면 사용 가능한 그라데이션 사전 설정을 볼 수 있습니다
3. 원하는 그라데이션을 선택합니다
4. &#x27;인덱스&#x27; 상자가 선택되면 이미지가 새로운 색상으로 **즉시 업데이트**됩니다

{% hint style="success" %}
**모범 사례**: NDVI와 같은 식생 지수의 경우, Red-노랑-Green 그라데이션이 자연스러운 색상 연관성 (녹색=건강, 노란색=보통, 빨간색=스트레스).
{% endhint %}

### 색상 클래스 조정

**클래스 제어**는 그라데이션에 표시되는 개별 색상 단계의 수를 결정합니다:**클래스 수 옵션:*** **2-5개 클래스**: 매우 광범위한 범주, 뚜렷한 구역
* **6-10개 클래스**: 균형 잡힌 구성, 분류에 적합
* **11-20개 클래스**: 부드러운 그라데이션, 연속적인 외관
* **20개 이상 클래스**: 거의 연속적인 수준, 최대의 부드러움**조정 방법:**

1. LUT 패널에서**그라데이션 막대 아래의 색상 견본 사각형**을 찾습니다
2. **+** 버튼을 눌러 클래스 수를 늘립니다
3. 색상 견본을 더블 클릭하여 클래스 수를 줄입니다
4. 이미지의 그라데이션이 **실시간**으로 업데이트됩니다**시각화에 미치는 영향:*** **클래스 수가 적을 때** (3~5): 뚜렷한 영역 생성, 분류 단순화, 범주 구별 용이
* **중간 수준의 클래스** (6-10): 균형 잡힌 접근 방식, 대부분의 용도에 적합
* **많은 클래스** (15-20): 부드러운 전환, 세밀한 변화, 사진 같은 외관**사용 시점:*** **적은 클래스 (3-5)**: 프레젠테이션 슬라이드, 분류 지도, 간단한 보고서
* **중간 수준의 클래스 (6-10)**: 일반 분석, 균형 잡힌 세부 정보, 표준 보고서
* **많은 구획 (15-20)**: 과학적 분석, 상세 조사, 출판용 품질의 결과물

### 값 범위 미세 조정

**값 범위 제어**는 그라데이션에서 어떤 색상 값이 어떤 색상에 매핑될지 결정합니다:**LUT 패널의 범위 제어:*** **최소값**: 색상 척도의 하한
* **최대값**: 색상 스케일의 상한
* **중간값**: 최소값과 최대값 사이에 (클래스 수에 따라) 자동으로 분배됨

#### 최소/최대값 조정

**값 범위를 조정하려면:**

1. LUT 패널에서**최소값**및**최대값** 입력 필드를 찾습니다
2. **최소값** 필드를 클릭합니다
3. 원하는 최소값을 입력합니다(예: `0.2`)
4. **Enter** 키를 누르거나 필드 밖을 클릭합니다
5. **최대값** 필드에서도 같은 과정을 반복합니다(예: `0.9`)
6. 시각화가 **즉시 업데이트**됩니다

{% hint style="info" %}
**자동 스케일링**: LUT를 처음 적용하면, Chloros는 이미지의 실제 데이터 범위에 맞춰 최소/최대 값을 자동으로 설정합니다. 이후 이 범위를 좁혀 관심 있는 특정 값 범위에 집중할 수 있습니다.
{% endhint %}

**범위 조정 예시:*** **전체 범위**: `-1.0` ~ `1.0` (가능한 모든 값 표시)
* **식생 중심**: `0.2` ~ `0.9` (맨땅 및 물 제외)
* **건강한 식생만**: `0.5` ~ `0.9` (생육이 왕성한 식물만 강조)
* **스트레스 감지**: `0.2` ~ `0.5` (문제 영역 강조)
* **사용자 지정 범위**: 관측된 픽셀 값에 따라 조정**범위를 조정하는 이유는 무엇인가요?*** 관심 영역의 **명암 대비**를 높이기 위해
* **관련 없는 값 제외** (예: 수역, 맨땅)
* **여러 이미지 또는 날짜 간 시각화 표준화*** **좁은 값 범위 내의 미세한 차이 강조**

### 범위 외 값 클리핑

픽셀 값이 정의된 최소/최대 범위를 벗어날 경우, **클리핑 모드**를 사용하여 표시 방식을 제어할 수 있습니다.

#### **사용 가능한 클리핑 모드 옵션:**

#### 1. 최소 및 최대

* **최소값 미만**인 픽셀 → 그라데이션의**첫 번째 색상**(예: 빨간색)으로 표시
* **최대값 초과**인 픽셀 → 그라데이션의**마지막 색상**(예: 녹색)으로 표시
* **사용 사례**: 극단값을 강조하고, 한계점에서 채도가 높은 색상을 사용하여 전체 데이터 범위를 표시
* **예시**: 0.2 미만의 NDVI 값은 모두 빨간색으로, 0.9 이상의 값은 모두 녹색으로 표시

#### 2. 투명한 배경

* **범위 밖**의 픽셀은**완전히 투명**해집니다
* **범위 내**의 픽셀만 색상 그라데이션을 표시합니다
* **사용 사례**: GIS 오버레이, 특정 값 범위 분리, 관심 영역만 강조
* **예시**: NDVI 0.4-0.7 범위만 색상으로 표시하고, 그 외 모든 영역은 투명하게 처리

{% hint style="warning" %}
**투명도 제한**: 투명 픽셀은 뷰어에서 배경색으로 표시됩니다. 처리 중 내보낼 때, PNG 형식에서는 투명도가 유지되지만 JPG 형식에서는 유지되지 않습니다.
{% endhint %}

#### 3. 인덱스 배경

* **범위 외**픽셀은**그레이스케일**로 표시됩니다(원시 인덱스 값 표시).
* **범위 내**픽셀은**색상 그라데이션**으로 표시됩니다
* **사용 사례**: 미묘한 강조 표시, 관심 영역을 강조하면서도 맥락 유지
* **예시**: 스트레스를 받은 식생(NDVI 0.3-0.5)을 색상으로 강조하고 건강한 영역은 회색으로 표시

#### 4. 원본 배경

* **범위 밖**의 픽셀은**원본 다중 스펙트럼 이미지**로 표시됩니다
* **범위 내**픽셀은**색상 그라데이션**을 표시합니다
* **사용 사례**: 가장 직관적 - 자연스러운 이미지 컨텍스트와 분석용 색상 오버레이를 결합
* **예시**: 색상으로 구분된 스트레스 영역이 오버레이된 실제 현장/작물 상태를 확인

### 적합한 클리핑 모드 선택

| 클리핑 모드              | 가장 적합한 용도                                   | 시각화 스타일          |
| -------------------------- | ------------------------------------------ | ---------------------------- |
| **최소 및 최대**    | 전체 데이터 표시, 과학적 분석     | 모든 픽셀에 색상 적용           |
| **투명 배경** | GIS 오버레이, 특정 범위 분리    | 범위 내 색상, 범위 외 흰색 |
| **인덱스 배경**       | 미묘한 강조, 데이터 맥락 유지  | 범위 내 색상, 범위 외 회색  |
| **원본 배경**    | 보고서, 프레젠테이션, 직관적인 분석 | 범위 내 색상, 범위 외 사진 |

### 사용자 지정 LUT 색상 만들기

시각화를 완벽하게 제어하려면 개별 색상 스톱을 편집하여 **사용자 지정 색상 그라데이션**을 만들 수 있습니다.**사용자 지정 그라데이션을 만드는 방법:**

1. LUT 패널에서**그라데이션 미리보기 막대**를 찾습니다.
2. 그라데이션 아래에 있는 **색상 견본 사각형**을 찾습니다.
3. **색상 스톱을 클릭**하여 선택합니다.
4. **색상 선택기**가 열립니다
5. 다음을 사용하여 새 색상을 선택합니다:
   * **컬러 휠**: 시각적 색상 선택
   * **RGB/HSV 슬라이더**: 정밀한 색상 제어
   * **16진수 코드 입력**: 정확한 색상 지정 (예: 빨간색의 경우 `#FF0000`)
6. 색상 선택기 밖을 클릭하여 **새 색상을 적용**합니다
7. 이미지의 그라데이션이 **즉시 업데이트**됩니다**색상 스톱 추가 또는 제거:*** **스톱 추가**: + 아이콘을 클릭하여 끝에 새 색상 스와치를 추가합니다
* **스톱 제거**: 색상 사각형을 더블 클릭하여 스와치를 제거합니다**사용자 지정 전략:*** **그라데이션 반전**: 색상 순서를 뒤집어 의미를 반전시킵니다(예: 녹색=낮음, 빨간색=높음)
* **브랜드 색상**: 보고서에 조직의 색상 팔레트를 적용합니다
* **색맹 친화적**: 주황-파랑 또는 보라-노랑 조합을 사용합니다
* **인쇄 최적화**: 컬러 및 흑백 인쇄 모두에서 잘 표현되는 색상을 선택합니다
* **다중 임계값**: 분류를 위해 특정 값 임계값에 따라 서로 다른 색상을 사용합니다

{% hint style="info" %}
**사용자 정의 그라데이션 저장**: 사용자 정의 그라데이션을 저장하여 재사용할 수 있습니다. LUT 패널의 저장 아이콘을 클릭하여 나중에 사용할 수 있도록 사용자 정의 색상 구성을 저장하세요.
{% endhint %}

## 대화형 워크플로

### 실시간 업데이트

샌드박스 내의 모든 LUT 조정은 이미지를 **즉시 및 대화형으로** 업데이트합니다:

* **레이어 전환** → 이미지가 즉시 변경됩니다
* **그라데이션 선택** → 색상이 즉시 업데이트됩니다
* **값 범위 조정** → 대비가 실시간으로 변경됩니다
* **클래스 변경** → 그라데이션의 부드러움이 즉시 업데이트됩니다
* **클리핑 수정** → 배경 표시가 즉시 변경됩니다
* **색상 편집** → 사용자 지정 그라데이션이 즉시 적용됩니다**&quot;적용&quot; 버튼이 필요 없습니다** - 모든 변경 사항은 실시간으로 반영되며 상호작용이 가능합니다!

{% hint style="success" %}
**실시간 피드백**: 즉각적인 시각적 피드백을 통해 분석 요구 사항에 맞는 최적의 시각화 효과를 찾을 때까지 다양한 설정을 빠르게 실험해 볼 수 있습니다.
{% endhint %}

### 반복적 정제 워크플로

**일반적인 LUT 최적화 워크플로:**

1.**인덱스 레이어 선택** (예: RAW (반사율))
2. **인덱스 적용** - 카메라 필터와 인덱스 공식을 선택하고, 색상 원들을 인덱스 공식 내 적절한 위치로 드래그합니다.
3. **LUT 그라데이션 적용** - Red-Yellow-Green 프리셋으로 시작합니다.
4. **픽셀 값 확인** - 커서를 이동하며 값 범위를 확인
5. **최소/최대값 조정** - 식생에 집중하도록 범위를 좁힘 (예: 0.2~0.9)
6. **클리핑 선택** - 맥락을 파악하기 위해 &quot;Original Background&quot;를 시도
7. **색상 미세 조정** - 특정 부분을 강조해야 할 경우 필요에 따라 그라데이션을 사용자 정의
8. **설정 확정**- 설정을 기록하고 내보내기 처리를 위해 프로젝트 설정에 복사

### 픽셀 값 확인

효과적인 LUT 범위를 설정하려면 실제 픽셀 값을 이해하는 것이 중요합니다:**값 확인 방법:**

1. 이미지의 인덱스(Index) 또는 인덱스와 LUT**두 항목 모두 선택**되어 있을 때 픽셀 값이 표시됩니다.
2. **커서를**이미지의 여러 영역 위로**이동**하세요
3. 커서를 올렸을 때 범례에 표시되는 **픽셀 값**을**확인**하세요
4. 확대하여 개별 픽셀이 강조 표시되고 값이 뜨는 것을 확인하세요
5. 다양한 특징에 대한 값 범위를 **기록**하세요:
   * **건강한 식생**: 예: NDVI 0.55-0.85
   * **스트레스를 받은 식생**: 예: NDVI 0.30-0.50
   * **노출된 토양**: 예: NDVI 0.05-0.25
   * **물** (존재하는 경우): 예: NDVI -0.05 ~ 0.10**픽셀 값을 사용하여 LUT 범위 설정:**픽셀 값을 확인한 후, 그에 따라 LUT의 최소/최대 값을 조정하십시오:**예시 시나리오:*** **관찰 결과**: 토양 값 = 0.05-0.25, 스트레스 상태 = 0.25-0.50, 건강한 상태 = 0.50-0.85
* **목표**: 식물 건강 상태만 시각화 (토양 제외)
* **LUT 설정**: 최소값 = `0.25`, 최대값 = `0.85`
* **클리핑**: &quot;원본 배경&quot;을 선택하여 토양을 자연스러운 색상으로 표시
* **결과**: 색상 그라데이션은 식생에만 적용되며, 토양은 원본 이미지로 표시됨

{% hint style="info" %}
**동적 범위**: 작물, 계절, 생육 단계에 따라 값의 범위가 달라집니다. LUT 범위를 설정하기 전에 항상 특정 데이터 세트의 픽셀 값을 확인하십시오.
{% endhint %}

## 사용자 정의 지수 (Chloros+)

### 사용자 정의 지수 공식 생성

{% hint style="info" %}
**생성 위치**: 사용자 정의 지수는 처리 전**프로젝트 설정**에서 구성할 수 있으며, 이미지 뷰어 샌드박스 사이드바에서도 설정할 수 있습니다.
{% endhint %}

**사용자 정의 지수를 생성하려면:**

1.**프로젝트 설정**(처리 전) 또는 이미지 뷰어 샌드박스 사이드바를 엽니다.
2. **인덱스 공식 드롭다운**으로 이동합니다.
3. **&quot;사용자 지정&quot;** 옵션을 찾습니다(Chloros+ 라이선스로 로그인해야 함).
4. 밴드 변수를 사용하여 **공식을 정의**합니다:
   * 밴드 이름: `NIR`, `Red`, `Green`, `Blue`, `RedEdge` 등
   * 연산자: `+`, `-`, `*`, `/`, `^` (지수)
   * 함수: `sqrt()`, `abs()` 등 (지원되는 경우)
   * 괄호: 연산 순서를 지정하기 위한 `()`
5. **인덱스 이름 지정** (예: &quot;MyIndex&quot; 또는 &quot;CustomNDVI&quot;)
6. **설정 저장**

**사용자 정의 수식 예시:**

```

Modified NDVI with offset:
(NIR - Red) / (NIR + Red + 0.5)

Simple ratio:
NIR / Red

Complex multi-band:
(NIR - Red) / (NIR + Red - Blue)

Exponential index:
(NIR / Red) ^ 2
```

{% hint style="warning" %}
**수식 유효성 검사**: 수식에 사용된 밴드가 카메라에서 지원되는지 확인하십시오. 예를 들어, RedEdge는 RedEdge 필터가 장착된 카메라에서만 사용할 수 있습니다.
{% endhint %}
