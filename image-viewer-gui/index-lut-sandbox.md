# 인덱스/LUT 샌드박스

인덱스/LUT 샌드박스는 Chloros 이미지 뷰어 사이드바에 있는 대화형 작업 공간입니다. 공식을 선택하고, 카메라 채널을 해당 공식에 바인딩한 뒤, 그라데이션으로 색상을 적용하고 값 범위를 조정하면, 작업하는 동안 이미지가 실시간으로 업데이트됩니다. 1.2.0 버전부터는 재처리 과정 없이 단일 이미지나 전체 프로젝트에 대해 **만든 내용을 저장**할 수도 있습니다.

## 샌드박스의 용도

| 인덱스/LUT 샌드박스 (대화형)        | 프로젝트 처리 (일괄 처리)       |
| -------------------------------------- | -------------------------------- |
| 한 번에 한 장의 이미지, 즉각적인 피드백  | 한 번의 실행으로 전체 데이터셋 처리     |
| 실험적 및 반복적 작업             | 사전 구성된 설정          |
| 실시간으로 렌더링; 요청 시에만 저장  | 항상 결과 파일을 작성      |
| 적절한 설정을 찾는 데 최적 | 설정이 확정된 후 사용 시 최상 |

{% hint style="success" %}
**일반적인 워크플로**: 샌드박스에서 시각화 결과가 원하는 대로 나올 때까지 설정을 조정한 후, 샌드박스에서 바로 내보내거나 동일한 인덱스 및 LUT 설정을 [프로젝트 설정](../project-settings/project-settings.md)에 복사하여 다음 처리 실행 시 모든 이미지에 해당 설정이 반영되도록 합니다.
{% endhint %}

## 샌드박스 열기

1. 그리드에서 이미지를 클릭하면 **이미지 뷰어** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 탭에서 전체 화면으로 열립니다.
2. **이미지 뷰어** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 아이콘을 클릭하여 왼쪽 사이드바가 아직 열려 있지 않은 경우 펼쳐주세요.
3. 오른쪽 상단의 레이어 드롭다운 메뉴에서 멀티밴드 레이어를 선택하세요. 보정된 반사율에 대해 계산된 지수 값은 이미지 간에 비교가 가능하므로, 일반적으로 **RAW (반사율)**을 선택합니다.

사이드바에는 위에서 아래로 다음과 같은 항목이 표시됩니다:

* 이미지 이름 및 카메라 모델
* **이미지 내보내기/저장** 버튼 — 인덱스(Index) 또는 LUT에 체크하면 나타납니다
* **인덱스(Index)**및**LUT** 체크박스
* 인덱스 구성 패널
* 판독값, 히스토그램 및 GSD 제어 기능이 포함된 **커서 값** 패널

{% hint style="warning" %}
**모노 카메라에서는 사용할 수 없습니다.** 단일 대역 LATTICE M3M 이미지의 경우 두 체크박스 모두 비활성화되며, 툴팁에 _&quot;모노(M3M) 센서에서는 사용할 수 없음&quot;_이라고 표시됩니다. 단일 대역에서는 다중 대역 인덱스를 정의할 수 없기 때문입니다. M3M 카메라에서 인덱스를 계산하려면, 두 개 이상의 이미지를 정렬된 다중 대역 스택으로 결합한 후 LATTICE 인덱스 엔진을 사용하십시오.
{% endhint %}

## 인덱스 적용

1. 사이드바 상단의 **인덱스** 확인란을 선택하십시오.
2. 왼쪽 드롭다운 메뉴에서 카메라 필터를 선택합니다(`RGN`, `OCN`, `NGB`, `RGB`, `RE`, `NIR`)에서 선택하세요
3. 오른쪽 드롭다운 메뉴에서 인덱스 공식을 선택하세요 — 27개의 기본 제공 공식과 저장해 둔 사용자 정의 공식이 있습니다
4. 수식은 아래와 같이 수학 식으로 표시되며, 각 밴드 슬롯에는 빈 원이 나타납니다. **색상이 지정된 채널 원을 슬롯 위로 드래그**하여 바인딩하십시오
5. 수식이 사용하는 모든 슬롯이 바인딩되면 이미지가 업데이트되어 인덱스 값을 표시합니다
6. 이미지에 커서를 올리면 값을 확인할 수 있습니다. **커서 값** 패널에는 커서가 위치한 위치의 값이 포함된 인덱스 행이 추가됩니다

바인딩된 슬롯을 더블 클릭하면 바인딩이 해제됩니다. 수식이 완성되지 않은 상태는 드래그 중의 정상적인 상태이며 오류가 아닙니다. 수식이 완성될 때까지 이미지가 업데이트되지 않을 뿐입니다.

채널 원은 색상으로 구분됩니다: 빨간색 = Red, 녹색 = Green, 파란색 = Blue, 주황색 = Orange, 청록색 = Cyan, 보라색 = NIR, 자홍색 = RE. &#x27;커서 값&#x27; 패널의 채널 도트와 히스토그램 곡선에도 동일한 색상이 사용됩니다.

### NDVI 예시

```

Formula: (NIR - Red) / (NIR + Red)

For a Survey3W RGN camera:
  NIR = 850 nm band
  Red = 661 nm band

Result range:          -1.0 to +1.0
Typical vegetation:     0.4 to 0.9
Stressed vegetation:    0.2 to 0.4
Bare soil:              0.0 to 0.2
Water:                 -0.1 to 0.1
```

전체 공식 참조(세 가지 사전 설정 목록과 각 이름이 어디에서 사용되는지)는 [다중 스펙트럼 지수 공식](../project-settings/multispectral-index-formulas.md)을 참조하십시오.

### &#x27;지수&#x27;에 체크했으나 LUT를 사용하지 않은 경우

이미지는 두 임계값 사이에서 확장된 **그레이스케일**로 그려집니다. 이는 의도된 것입니다. 인덱스 이미지는 스칼라 데이터이며, 그레이스케일은 이를 있는 그대로 표현한 것입니다. 색상을 적용하려면 LUT를 추가하십시오.***

## LUT(룩업 테이블) 사용법**룩업 테이블(Look-Up Table)**은 인덱스 값을 색상으로 매핑합니다. 예를 들어, 입력값 NDVI 0.65에 대해 특정 녹색을 출력합니다. 이는 데이터를 변경하는 것이 아니라, 데이터를 해석하는 방식을 변경하는 것입니다.

### LUT 추가하기

1. 수식 아래에 있는 <img src="../.gitbook/assets/image (1) (1) (1).png" alt="" data-size="line"> **&quot;+ LUT 추가&quot;** 버튼을 클릭합니다.
2. 색상 그라데이션을 선택합니다.
3. 클리핑 최소값과 최대값을 설정합니다.
4. 클리핑 모드를 선택합니다.
5. 사이드바에서 **LUT** 확인란을 선택하여 렌더링합니다.

LUT가 인덱스에 실제로 구성될 때까지는 LUT 체크박스가 비활성화된 상태로 유지됩니다.

### 색상 그라데이션 선택

**그라데이션 막대**위에 마우스를 올리면 사전 설정 목록이 열립니다. Chloros에는**7가지** 그라데이션 사전 설정이 포함되어 있습니다:

| # | 그라데이션                            | 모양                                                               |
| - | ----------------------------------- | ------------------------------------------------------------------- |
| 1 | Red → 노란색 → Green (**기본값**)  | 발산형 — 일반적인 식생에 대한 직관과 일치하며, 녹색 = 건강함 |
| 2 | 보라색 → 노란색 → Green             | 발산형, 뚜렷한 저색 영역 포함                                  |
| 3 | 갈색 → 흰색 → Blue                | 밝은 중간 지점을 중심으로 발산                                   |
| 4 | 검은색 → 보라색 → 분홍색 → 옅은 노란색 | 순차적, 어두운 색에서 밝은 색으로                                           |
| 5 | Red → 노란색 → Blue                 | 밝은 중간 지점을 중심으로 발산                                   |
| 6 | 보라색 → Blue → Green → 노란색      | 순차적, 어두운 색에서 밝은 색으로                                           |
| 7 | Orange → 흰색 → 보라색             | 밝은 중간점을 중심으로 발산                                   |

**발산형**그라디언트는 창 중앙에 중립적인 색상을 배치하며, 중간점이 특정 의미를 가질 때(임계값, 기준일 등).**순차적** 그라데이션은 어두운 색에서 밝은 색으로 단조롭게 이어지며, “더 많다”와 “더 적다”만 존재하는 양을 나타낼 때 잘 어울립니다.

각 프리셋에는 7개의 색상 스톱이 있습니다. 프리셋을 클릭하면 이미지가 즉시 업데이트됩니다(LUT 상자에 체크된 경우).

### 색상 스톱 편집하기

그라데이션 바 아래에는 스톱마다 하나씩 색상 견본이 나열되어 있습니다:

* **색상 변경**: 색상 견본을 클릭하면 색상 선택기(컬러 휠, RGB/HSV 슬라이더 또는 `#FF0000`와 같은 16진수 코드)가 열립니다.
* **스톱 추가**: 행 끝의**+** 버튼을 클릭하면 흰색 스톱이 추가됩니다
* **스톱 제거**: 스와치를**더블 클릭**합니다
* **편집한 그라데이션 저장**: 그라데이션 막대 옆의 저장 아이콘을 클릭하여 편집한 그라데이션을 사전 설정 목록에 추가하면 나중에 다시 선택할 수 있습니다

인덱스에 설정해 둔 그라데이션은 프로젝트 설정의 해당 인덱스와 함께 저장되므로, 프로젝트를 닫았다가 다시 열어도 유지됩니다.

**스톱 수가 적을수록**분류처럼 구분되는 영역이 생성되며,**스톱 수가 많을수록** 사진처럼 매끄러운 전환이 나타납니다. 3~5개의 스톱은 프레젠테이션 슬라이드와 분류 지도에 적합하며, 6~10개는 일반 분석에, 15개 이상은 상세한 검사 및 출판용 도면에 적합합니다.

### 값 범위 설정

임계값 컨트롤은 −1에서 +1까지 이동하는 **이중 핸들 슬라이더**로, 양쪽 끝에 정확한 값을 입력할 수 있는 편집 가능한 텍스트 상자와**AUTO** 버튼이 있습니다.

* 양쪽 핸들 중 하나를 드래그하거나, 상자에 숫자를 입력한 후 Enter 키를 누르세요.
* **AUTO**를 선택하면 범위가 이미지의**유효 인덱스 값 중 2번째 및 98번째 백분위수** — 이는 이상치를 무시하는 좋은 시작점입니다. Chloros는 결과에 따라 적응적으로 반올림하며, 범위가 매우 좁을 경우 소수점 이하 4자리, 좁을 경우 3자리, 그 외에는 2자리로 반올림합니다
* AUTO를 다시 누르기 전까지는 수동으로 조정한 값이 AUTO 설정보다 우선 적용됩니다

NDVI 창 예시:

| 목표                                    | 최소  | 최대 |
| --------------------------------------- | ---- | --- |
| 모두 표시                             | −1.0 | 1.0 |
| 식생만 표시, 토양 및 물 제외         | 0.2  | 0.9 |
| 건강한 식생만 표시                 | 0.5  | 0.9 |
| 스트레스 강조                        | 0.2  | 0.5 |

창의 범위를 좁히면 관심 영역 내부의 대비가 높아지고, 그 외의 모든 요소는 범위 밖으로 밀려나게 되며, 이때 **클리핑 모드**에 따라 해당 요소가 어떻게 처리될지가 결정됩니다.***

## 클리핑 모드

픽셀의 인덱스 값이 최소/최대 창 범위를 벗어날 경우, 클리핑 모드에 따라 해당 픽셀이 어떻게 그려질지가 결정됩니다.

| 드롭다운 레이블                  | 저장된 값      | 범위 외 픽셀은 다음과 같이 그려집니다                                                                                                |
| ------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **최소 및 최대** (기본값) | `clip`            | 그라데이션의 가장 가까운 끝 색상 — 최소값 미만의 값은 첫 번째 색상을, 최대값 이상의 값은 마지막 색상을 취합니다 |
| **투명한 배경**      | `transparent`     | 완전히 투명함 (실제 알파)                                                                                                  |
| **인덱스 배경**| `indexColor`      | 그레이스케일로, 이미지의**전체** 인덱스 범위에 걸쳐 확장되므로, 범위 밖의 구조도 회색으로 여전히 표시됩니다                |
| **원본 배경**         | `backgroundColor` | 기본 이미지 자체이므로, 색상 오버레이가 실제 장면 위에 중첩됩니다                                                |

| 모드                       | 가장 적합한 경우                               | 외관                                      |
| -------------------------- | -------------------------------------- | ----------------------------------------- |
| **최소 및 최대**      | 전체 데이터 표시, 과학적 분석 | 모든 픽셀에 색상 적용                      |
| **투명 배경**      | GIS 오버레이, 특정 값 범위 분리   | 창 안쪽은 색상, 바깥쪽은 없음 |
| **인덱스 배경**       | 데이터 맥락을 유지하면서 강조    | 내부 색상, 외부 회색               |
| **원본 배경**    | 보고서 및 프레젠테이션              | 내부 색상, 외부 사진         |

{% hint style="info" %}
**데이터가 없는 픽셀은 모든 모드에서 항상 투명하게 표시됩니다.** 인덱스가 유한하지 않거나(0/0 나눗셈), 정확히 −1.0 또는 +1.0인 픽셀(한 밴드는 0을 나타내지만 다른 밴드는 그렇지 않아 발생하는 채도 센티넬)은 극단값이 아닌 데이터 미포함으로 처리됩니다. 이를 통해 과다 노출된 하이라이트와 완전히 어두운 섀도우는 프레임 내 가장 극단적인 값으로 처리되지 않고, 색상 스케일에서 제외됩니다. 동일한 규칙이 AUTO 임계값과 인덱스 히스토그램에 반영되는 픽셀을 정의하므로, 이 세 가지가 모두 일치합니다.
{% endhint %}

PNG 형식으로 내보낼 경우 투명도가 보존됩니다. JPG 형식에서는 이를 표현할 수 없습니다.

## 조정 중 값 읽기

구성 패널 아래에 있는 **커서 값** 패널은 샌드박스의 측정 도구입니다:

* 커서를 이미지 위로 이동하여 채널별 소스 값과 해당 행에 표시된 인덱스 값을 확인하세요
* 히스토그램 위의 **INDEX** 버튼을 켜면 프레임 내 인덱스 값의 분포를 확인할 수 있습니다. 이때 두 개의 클립 임계값은 주황색 점선으로, 커서의 값은 흰색 선으로 표시됩니다. 이는 실제 데이터가 포함된 창을 선택하는 가장 빠른 방법입니다.
* **CURSOR**를 켜면 포인터 아래의 값에 마커 선이 표시됩니다.
* 60배 이상(GSD 블록 크기가 설정된 경우 더 낮은 배율)으로 확대하면 표시된 개별 픽셀이 부동 값으로 강조 표시됩니다.

실용적인 절차:

1. 건강한 식생, 스트레스를 받은 식생, 맨땅, 물 위의 값을 확인합니다.
2. 해당 클러스터들이 지수 히스토그램에서 어디에 위치하는지 확인하세요
3. 관심 있는 클러스터를 포함하도록 최소/최대 값을 설정하세요
4. 클리핑 모드를 선택하세요 — _Original Background_ 모드는 주변 장면을 계속 표시해 줍니다

## 샌드박스에서 내보내기

저장하기 전까지는 위의 모든 내용이 실시간 미리보기입니다. 사이드바 상단의 **이미지 내보내기/저장** 버튼을 누르면 사이드바 위로 미끄러지듯 나타나는 패널이 열립니다(이미지를 가리지 않으므로, 결정 중인 내용을 계속 볼 수 있습니다).

<figure><img src="../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>### 옵션

| 옵션                          | 효과                                                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **현재 이미지에 적용**      | 표시된 이미지를 이 설정대로 정확히 저장합니다                                                                                                |
| **모든 프로젝트 이미지에 적용** | 프로젝트의 모든 이미지에 동일한 구성을 다시 적용합니다. 이 인덱스에 필요한 밴드가 없는 이미지는 오류로 처리되지 않고 건너뜁니다 |
| **인덱스/LUT 그라데이션 막대**      | 내보내기마다 값 범위가 표시된 별도의 범례 이미지를 함께 저장합니다                                                                     |
| **인덱스 히스토그램**             | 내보내기마다 데이터의 최소/최대값과 클립 임계값을 보여주는 별도의 히스토그램 이미지를 함께 저장합니다                                               |

이미지 탭의 **GSD 블록 크기**가 1보다 큰 경우, 적용하기 전에 패널에 해당 내용이 표시됩니다. 내보내기 시 현재 보고 있는 화면이 블록 평균 처리가 포함된 상태로 저장됩니다. 전체 해상도를 원한다면 먼저 GSD 설정을 1로 되돌리십시오.

### 파일 저장 위치

**내보내기**를 클릭할 때마다**새롭고 재사용되지 않는 폴더**가 할당됩니다:

```
<project folder>/Sandbox_Exports/<IndexName>_<Index|LUT>_<NNN>/
```

예시: `Sandbox_Exports/NDVI_LUT_001/`, 다음 실행 시에는 `Sandbox_Exports/NDVI_LUT_002/`. 번호는 디스크에 이미 존재하는 파일을 스캔하여 생성되므로, 재시작하거나 수동으로 폴더를 삭제하더라도 유지됩니다. 어떤 파일도 덮어쓰이지 않습니다. 샌드박스의 핵심 목적은 한 번의 시도를 이전 시도와 비교하는 것이기 때문입니다.

폴더 내부의 각 이미지별 구성:

| 파일                                                   | 내용                                                   |
| ------------------------------------------------------ | ---------------------------------------------------------- |
| `<source name>_<IndexName>_<Index\|LUT>.png`           | 뷰어에 표시된 것과 픽셀 단위로 동일한 렌더링된 이미지 |
| `<source name>_<IndexName>_<Index\|LUT>_legend.png`    | 요청된 경우, 그라데이션 바 사이드카                     |
| `<source name>_<IndexName>_<Index\|LUT>_histogram.png` | 요청된 경우, 인덱스 히스토그램 사이드카                  |

두 개의 사이드카는 메인 이미지가 블록 평균 처리된 경우라도 항상 **전체 해상도**로 기록됩니다. 블록 크기는 디스플레이 해상도와 동일하며, 두 사이드카 모두 픽셀별 실제 인덱스 값을 읽습니다. 또한 이 두 사이드카는 화면상에 표시되는 버전보다 더 많은 정보를 출력합니다. 둘 다 스트레치 창과 실제 데이터의 최소/최대값을 모두 표시하므로, 프로젝트를 열지 않은 상태에서도 몇 달이 지난 후에도 저장된 범례를 읽을 수 있습니다.

### 진행 상황 및 결과

전체 프로젝트 내보내기는 몇 분이면 완료되므로, 실행 과정은 작업을 차단하지 않고 실시간 진행 상태 채널을 통해 결과를 보고합니다:

* 진행률 표시줄에는 `current / total`와 기록 중인 파일이 표시됩니다
* 작업이 완료되면 패널에 내보낸 이미지 수, 건너뛴 이미지 수, 출력 폴더 경로가 표시됩니다.
* 건너뛴 이미지는 그 이유와 함께 나열됩니다(최대 5개까지 표시되며, 그 이후에는 &quot;+N개 더&quot;라는 줄이 나타납니다). 일반적인 이유는 이 인덱스에 필요한 채널이 없는 레이어가 있기 때문입니다.
* 프로젝트 내의 **어떤** 이미지도 해당 인덱스를 사용할 수 없는 경우, 실행 결과는 빈 폴더를 남기는 대신 실패로 보고됩니다

한 번에 하나의 샌드박스 내보내기 작업만 실행됩니다. 한 작업이 진행 중인 상태에서 두 번째 작업을 시작하려고 하면, 두 실행이 동일한 프로젝트 파일을 놓고 충돌하는 것을 방지하기 위해 명확한 메시지와 함께 거부됩니다.

### 그리드에서 실행 결과를 확인합니다

완료된 모든 실행은 [이미지 그리드](image-grid.md) 툴바에 `<IndexName> <Index|LUT> <NNN>`라는 라벨이 붙은 별도의 버튼으로 표시됩니다. 이것이 바로 실행 결과를 비교하는 방법입니다. 서로 다른 그라데이션이나 임계값을 사용하여 두 번 내보낸 다음, 그리드에 있는 두 버튼 사이를 전환해 보세요.

## 사용자 정의 인덱스 공식 (Chloros+)

{% hint style="info" %}
**생성 위치**: 샌드박스(Sandbox) 사이드바 또는 처리 전**프로젝트 설정**에서 생성할 수 있습니다. 두 곳 모두 동일한 프로젝트 수준 목록에 기록됩니다.
{% endhint %}

1. 인덱스 공식 드롭다운 메뉴에서 사용자 정의 공식 계산기를 엽니다 (해당 Chloros+ 구독으로 로그인해야 함)
2. **밴드 슬롯 기호**인 `x`, `y`, `z`, `y`, `a`, `b`, `c` — 밴드 이름이 아님
3. 사용 가능한 연산자: `+`, `-`, `*`, `/`, `^`, `()` (그룹화용)
4. 사용 가능한 함수: `sqrt()`, `log()`, `ln()`, `abs()`, `sign()`, `log1p()`, `log2()`
5. 이름을 지정하고 저장하세요. 그러면 수식 드롭다운 메뉴 하단에 표시되며, 내장 프리셋과 똑같이 채널 원을 드래그하여 슬롯을 바인딩할 수 있습니다.

```

Modified NDVI with an offset:   (y-x)/(y+x+0.5)
Simple ratio:                   y/x
Three-band difference:          (y-x)/(y+x-z)
Squared ratio:                  (y/x)^2
```

{% hint style="warning" %}
**사용자 정의 수식은 GUI에서만 사용할 수 있습니다.** CLI/SDK `--indices` 옵션은 22개의 내장 프리셋 이름을 확장하고, 사용자 정의 수식을 포함한 그 외의 모든 항목을 자동으로 건너뜁니다. 사용자 정의 수식을 일괄 처리하려면 프로젝트 설정에서 수식을 구성한 후 처리를 실행하거나, 샌드박스의 “모든 프로젝트 이미지에 적용” 내보내기 기능을 사용하십시오.
{% endhint %}

## 문제 해결

### “이 레이어에는 이 인덱스에 필요한 채널이 없습니다”

수식이 현재 레이어에 없는 채널 위치를 참조하고 있습니다. 예를 들어, 1채널 또는 2채널 파일에서 3슬롯 인덱스를 참조하는 경우입니다. 다중 대역 레이어(반사율 또는 디베이어 처리된 레이어)로 전환하거나, 카메라 필터에 맞는 인덱스를 선택하십시오.

### “이미지 처리 백엔드에 연결할 수 없습니다”

백엔드가 응답하지 않습니다. &#x27;로그&#x27; 탭을 확인하십시오. 백엔드가 재시작 중인 경우, 백엔드가 복구되면 샌드박스도 자동으로 복구됩니다.

### 원을 드래그했을 때 이미지가 변하지 않았습니다

수식이 아직 완성되지 않았습니다. 미완성된 수식은 일반적인 드래그 중 상태로 처리됩니다. 즉, 렌더링이 이루어지지 않으며 오류로 보고되지도 않습니다. 수식이 사용하는 모든 슬롯을 채워주세요.

### 전체 이미지가 한 가지 색상입니다

클립 창이 데이터 범위를 훨씬 벗어난 것 같습니다. **AUTO**를 눌러 2/98백분위수에 맞추거나,**INDEX** 히스토그램을 켜서 데이터가 실제로 어디에 분포하는지 확인하세요.

### 내보낸 색상이 제가 본 것과 일치하지 않습니다

일치해야 합니다. 내보내기 경로는 클리핑 모드 알파를 포함하여 라이브 미리보기를 의도적으로 반영한 것이며, 블록 평균화는 뷰어에서와 똑같이 색상 처리 _후_에 적용됩니다. 색상이 다르다면, 보기 시점과 내보내기 시점 사이에 GSD 블록 크기가 변경되지 않았는지 확인하십시오.
