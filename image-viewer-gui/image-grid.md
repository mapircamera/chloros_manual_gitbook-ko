# 이미지 그리드

프로젝트에 이미지를 가져오면 메인 영역에 이미지가 그리드 형태로 정렬되어 표시됩니다. 이 그리드에서 **각 이미지의 어떤 버전을 볼지** 선택할 수 있습니다. 그리드 상단의 버튼을 사용하면 모든 썸네일을 한 번에 원본 파일과 처리된 결과물 간에 전환할 수 있습니다.

## 썸네일 크기

오른쪽 상단의 확대/축소 슬라이더를 사용하여 이미지 썸네일의 크기를 조정할 수 있습니다. 슬라이더의 범위는 **64px에서 1200px**까지입니다.

* **Ctrl + 마우스 휠**을 사용해도 썸네일의 크기를 조절할 수 있습니다.
* **Ctrl + `+`**/**Ctrl + `=`**및**Ctrl + `−`**를 누를 때마다 크기가 4 px씩 단계별로 변경됩니다. 키보드 단축키로 조정 가능한 범위는 최소 64 px부터 시작하며, 최대 크기는 현재 창에서 한 행에 썸네일이 정확히 두 개 들어맞는 크기로 제한됩니다.
* 최종적으로 결정한 크기는 프로젝트와 함께 저장됩니다(`UI → Grid thumbnail size`에서 `project.json`, 기본값 `160`), 따라서 프로젝트를 다시 열면 해당 크기가 복원됩니다.

<figure><img src="../.gitbook/assets/chloros_grid_zoom.gif" alt=""><figcaption></figcaption></figure>썸네일 *해상도*는 썸네일 *크기*와는 별개의 설정입니다. [프로젝트 설정](../project-settings/project-settings.md)의 **표시 → 이미지 썸네일 해상도**를 참조하십시오(기본값: 긴 변 기준 512 픽셀). 크기는 타일이 그려지는 크기를 의미하며, 해상도는 타일을 채우기 위해 불러오는 세부 정보의 양을 의미합니다.***

## 그리드 도구 모음

그리드 상단의 버튼 행은 왼쪽에서 오른쪽으로 최대 세 개의 그룹으로 구성됩니다:

1. **트리거별 / 카메라별** — 그룹화 모드. LATTICE 캡처가 포함된 프로젝트에서만 표시됩니다.
2. **카메라 필터 버튼** — LATTICE 카메라당 하나씩 표시됩니다. ‘카메라별’ 모드에서만 표시됩니다.
3. **내보내기/보기 모드 버튼** — 각 썸네일이 표시하는 제품 유형을 선택합니다.

창이 너무 좁아 모든 버튼을 표시할 수 없는 경우, 그룹은 오른쪽에서 왼쪽 순서로 마우스를 올렸을 때 나타나는 드롭다운 메뉴로 접힙니다. 먼저 내보내기/보기 버튼이 접히고, 그 다음 카메라 버튼이 접힙니다. 접힌 그룹에는 현재 활성화된 선택 항목이 표시된 단 하나의 버튼만 남게 되며, 이 버튼 위에 마우스를 올리면 전체 버튼 세트가 아래로 밀려나옵니다. **&#x27;트리거별(Per Trigger)&#x27; 및 &#x27;카메라별(Per Camera)&#x27;은 절대 접히지 않습니다.

## 내보내기/보기 버튼

이 버튼들은 그리드 썸네일의 이미지 유형을 전환합니다. **버튼은 해당 버튼이 지칭하는 제품이 존재하는 즉시 나타납니다** — 소스 파일의 경우, 이는 처리 후가 아니라 가져오기 즉시를 의미합니다. Chloros는 작업이 진행 중일 때 프로젝트의 제품을 다시 스캔하므로, 각 제품이 디스크에 저장되기 시작할 때마다 처리 도중 버튼이 나타납니다.

### 기본 버튼

가장 왼쪽의 내보내기 버튼에는 **실제로 가져온 내용**이 표시됩니다:

| 가져온 항목 | 버튼 레이블 |
| --- | --- |
| Survey3 RAW+JPG | `JPG` |
| 원본 프레임 옆에 디스플레이 미리보기가 함께 표시되는 LATTICE 캡처 | `PNG` 또는 `TIFF` (미리보기가 표시되는 쪽) |
| 기본 파일이 **RAW 프레임인** LATTICE 캡처 | *버튼 없음* — `RAW (Original)`에 해당 파일이 이미 표시됨 |

혼합 프로젝트에서는 가장 많은 이미지가 사용하는 확장자를 기준으로 레이블이 지정됩니다.

### 제품 버튼

| 버튼 | 표시 내용 | 표시 시점 |
| --- | --- | --- |
| **타겟** | 보정 타겟이 감지된 이미지 | 타겟이 감지된 실행 후 |
| **타겟** | 보정 타겟이 감지된 이미지 | 타겟이 감지된 실행 후 | |
| **화이트 밸런스 적용** | 화이트 밸런스가 적용된 결과물 (RGB 카메라) | 처리 후 |
| **비네트 보정** | 보정되지 않은 비네트 보정 대체 결과 | 반사율 보정을 적용할 수 없었고 *비네트 보정*이 켜진 상태에서 실행된 후 |
| **센서 응답** | 보정되지 않은 센서 응답 대체값 | 위와 동일하지만 *비네팅 보정*이 꺼진 경우 |
| **`RAW (<INDEX> Index)`** | 계산된 인덱스당 하나의 버튼 | 인덱스가 구성된 실행 후 |
| **`<INDEX> LUT`** | 색상 매핑된 인덱스당 하나의 버튼 | LUT가 구성된 실행 후 |
| **`<Index> <Index\|LUT> <NNN>`** | [인덱스/LUT 샌드박스](index-lut-sandbox.md) 내보내기 실행당 하나의 버튼 | 샌드박스 내보내기가 완료되는 순간 |

### LATTICE 레벨 버튼

LATTICE 캡처가 포함된 프로젝트에는 제품명 대신 레벨 이름으로 표시된 다음 버튼이 추가됩니다:

| 버튼 | 레벨 |
| --- | --- |
| **RAW (원본)** | 가져온 소스 원본 프레임 |
| **RAW (방사도)** | Float32 스펙트럼 방사도, W/m²/sr/nm |
| **RAW (반사율)** | uint16 반사율, 32768 = ρ 1.0 |

`RAW (Original)`는 가져오기 즉시 사용할 수 있으며 별도의 처리가 필요하지 않습니다. LATTICE 가져오기에 기본 버튼이 전혀 없는 경우(모든 캡처의 기본 파일은 원본 프레임입니다), 그리드가 사용 가능한 첫 번째 레벨 버튼으로 자동으로 이동하여 툴바의 강조 표시가 화면과 일치하도록 합니다.

두 단계의 Chloros 내보내기 파일에는 **전용 그리드 버튼이 없습니다**:

* **데베이어 처리됨** — `RAW (Original)` 뷰는 이미 데베이어 처리된 상태로 렌더링되므로, 시각적으로 동일한 이미지에 두 번째 버튼을 추가하는 것은 불필요한 요소가 됩니다. `RAW (Debayered)` 산출물은 여전히 디스크에 기록되며, 전체 화면 레이어 드롭다운 메뉴에서 선택할 수 있습니다.
* **미리보기** — RGB 카메라에서 미리보기는 `White Balanced` 레이어로 등록되며, 이 레이어에는 버튼이 있습니다. 다중 스펙트럼 카메라에서는 `RAW (Preview)`로 등록되며, 전체 화면 레이어 드롭다운 메뉴에서 접근할 수 있습니다.

{% hint style="info" %}
이러한 레벨 버튼은 실제로 LATTICE 프레임을 포함하는 프로젝트에서만 표시됩니다. Survey3 프로젝트는 일부 동일한 내부 레이어 이름을 등록하며, 해당 프로젝트에서는 버튼이 필터링되어 Survey3 그리드는 익숙한 `JPG / Targets / Reflectance` 세트를 유지합니다.
{% endhint %}

그리드 썸네일을 클릭하면 **그리드가 표시하고 있는 것과 동일한 제품**에 대한 전체 화면 [이미지 뷰어](opening-an-image-full-screen.md)가 열립니다. — 그리드가 `Targets`로 설정된 경우, 썸네일을 클릭하면 내보낸 대상 이미지가 열립니다.

## LATTICE 프로젝트 그룹화: 트리거별 vs 카메라별

어레이 캡처는 서로 다른 카메라 모듈에서 동일한 순간의 여러 이미지를 생성합니다. 그룹화 설정은 그리드가 이러한 이미지를 어떻게 배열할지 결정합니다. 두 모드 모두 전체 너비의 접을 수 있는 헤더 막대를 표시하며, **모든 그룹은 펼쳐진 상태로 시작**하고, Chloros는 사용자가 접은 그룹을 기억합니다. 접힘 상태는 모드별로 별도로 추적되므로, ‘카메라별’ 모드에서 그룹을 접어도 ‘트리거별’ 모드에서는 아무것도 접히지 않습니다.

### 카메라별(기본값)

카메라 모듈당 하나의 그룹이 생성됩니다. 헤더에는 카메라 모델과 일련번호(`LATT-M3M — <serial>`), 사진 개수가 표시됩니다. 그룹 내의 타일은 촬영 이벤트 순서대로 정렬됩니다.

이 모드에서는 툴바에 **카메라당 하나의 카메라 필터 버튼**(라벨: `MODEL (SERIAL)`)이 표시됩니다. 모든 카메라가 기본적으로 선택된 상태로 시작되며, 버튼을 클릭하면 해당 카메라의 선택이 해제되고 그리드에서 해당 그룹이 제거됩니다. 이는 전체 비행 구간의 한 밴드를 빠르게 검토할 수 있는 방법입니다.

### 트리거별

캡처 이벤트당 하나의 그룹 — 동일한 트리거에서 모든 모듈이 촬영한 프레임 세트입니다. 헤더에는 캡처 시간, 기여한 카메라 수, 그리고 그룹 내 카메라 모델별 배지가 표시됩니다. 그룹 내의 타일은 카메라 일련번호 순으로 정렬되므로, 동일한 밴드는 모든 트리거에서 같은 열에 위치합니다.

혼합 프로젝트에 포함된 비-LATTICE 이미지는 그룹화되지 않으며, 그룹 뒤에 일반 타일로 표시됩니다.

## 그리드 썸네일은 GSD 블록 크기를 따릅니다

이미지 탭 사이드바에서 **GSD (px)** 블록 크기를 설정한 경우, 그리드 썸네일도 전체 화면 보기뿐만 아니라 동일한 지상 해상도로 제공됩니다. 블록 크기가 8인 경우, 이미지를 표시하는 앱 내 모든 위치에서 표시되는 각 픽셀은 8×8 블록의 원본 픽셀 평균값을 나타냅니다.

타일의 너비가 애초에 수백 픽셀에 불과하기 때문에, 전체 화면 보기보다 훨씬 앞서 그리드에서는 거친 블록 크기가 눈에 띄는 차이를 만들지 않게 됩니다. 160px 타일에 그려진 4000px 프레임은 이미 표시된 픽셀당 약 25개의 원본 픽셀에 해당합니다. 컨트롤 자체에 대해서는 [이미지 전체 화면 열기](opening-an-image-full-screen.md#gsd-block-size)를 참조하십시오.
