# 이미지 레이어

Chloros 이미지 뷰어의 ‘이미지 레이어(Image Layers)’ 드롭다운 메뉴를 사용하면 원본 캡처 이미지부터 처리된 반사도 출력 결과, 계산된 지수 이미지에 이르기까지 동일한 이미지의 다양한 버전을 빠르게 전환할 수 있습니다.

## 이미지 레이어란 무엇인가요?

Chloros에서 **레이어**란 단일 원본 이미지에 대해 사용할 수 있는 다양한 이미지 출력을 의미합니다. 이미지를 처리할 때, Chloros는 다음과 같은 여러 버전을 생성합니다:

* **원본 이미지** (카메라에서 가져온 JPG 및 RAW 파일)
* **반사율 보정** 출력물 (반사율 보정이 활성화된 경우)
* **타겟 이미지** (이미지에 보정 타겟이 포함된 경우)
* **인덱스 이미지** (NDVI, NDRE, GNDVI 등, 인덱스가 구성된 경우)

이미지 뷰어 우측 상단의 **레이어 선택기 드롭다운**을 사용하면 뷰어를 벗어나지 않고도 이러한 버전 간을 즉시 전환할 수 있습니다.***

## 사용 가능한 레이어 유형

### JPG

* 카메라에서 가져온 원본 JPG 미리보기 이미지
* 모든 이미지에 대해 항상 사용 가능
* 카메라로 촬영된 그대로의 미가공 이미지
* 로딩 및 표시 속도가 가장 빠름

**사용 시점:**

* 원본 촬영 이미지의 빠른 미리 보기
* 이미지 구도 및 프레임 확인
* 처리 전 촬영 품질 확인

### RAW (원본)

* 카메라에서 가져온 원본 RAW 센서 데이터
* 후처리 없이 디베이어링(debayering)만 적용된 상태
* JPG보다 높은 비트 심도 (일반적으로 12비트 또는 14비트 센서 데이터)

**사용 시점:**

* 원본 센서 데이터 품질 검사
* 센서 문제 또는 아티팩트 확인
* 처리 전후 결과 비교

### RAW (타겟)

* 보정 타겟이 포함된 것으로 식별된 이미지에만 표시됨
* 타겟이 감지된 원본 RAW 이미지 표시
* 타겟 감지가 성공적으로 이루어졌는지 확인하는 데 사용

**확인 시점:**

* 보정 타겟이 올바르게 감지되었는지 확인
* 타겟 이미지 품질 확인
* 보정 문제 해결

{% hint style="info" %}
**타겟 레이어**: 이 레이어는 보정 타겟이 포함된 이미지의 드롭다운 메뉴에만 표시됩니다. 일반 캡처 이미지에는 이 옵션이 없습니다.
{% endhint %}

### RAW (반사율)

* 보정된 반사율 출력 이미지
* 비네팅 보정됨 (처리 시 활성화된 경우)
* 타겟 데이터를 사용하여 반사율 보정됨 (활성화된 경우)
* 모든 카메라 채널을 포함한 다중 대역 TIFF
* 픽셀 값은 반사율 백분율을 나타냄 (백분율 모드 사용 시)
* [인덱스/LUT 샌드박스](index-lut-sandbox.md)에서 바로 편집 가능

**사용 시점:**

* 보정 결과 확인
* 보정 품질 검증
* 과학적 정확성을 위한 픽셀 값 확인
* 원본과 비교하여 보정 효과 확인

{% hint style="success" %}
**권장**: 과학적 측정 및 분석을 위해 픽셀 값을 확인할 때는 RAW (반사율) 레이어를 사용하십시오.
{% endhint %}

### RAW (NDVI 지수)... 및 유사 항목

* 계산된 식생 지수 이미지 (이 예시에서는 NDVI)
* 지수 이름은 처리 과정에서 어떤 지수가 구성되었는지에 따라 달라집니다.
* 예시: RAW (NDVI 지수), RAW (NDRE 지수), RAW (GNDVI 지수) 등
* 지수 계산 결과를 보여주는 단일 대역 그레이스케일 이미지
* 프로젝트 설정에서 구성된 각 인덱스마다 하나의 레이어가 표시됩니다

**가능한 인덱스 이름:**

* RAW (NDVI 인덱스)
* RAW (NDRE 인덱스)
* RAW (GNDVI 인덱스)
* RAW (OSAVI 지수)
* RAW (EVI 지수)
* RAW (SAVI 지수)
* 그 외 다수... ([다중 스펙트럼 지수 공식](../project-settings/multispectral-index-formulas.md) 참조)

**확인 시점:**

* 지수 계산 결과 검토
* 지수 값 범위 확인
* 관심 영역 식별
* GIS 또는 분석에 사용하기 전 지수 이미지 확인

## 레이어 선택기 사용법

### 드롭다운 열기

1. 이미지를 전체 화면 모드로 엽니다 (이미지 뷰어의 썸네일 중 아무 곳이나 클릭)
2. 뷰어 우측 상단에 있는 **레이어 드롭다운**을 찾습니다
3. 드롭다운에는 현재 선택된 레이어(예: &quot;JPG&quot;)가 표시됩니다
4. 드롭다운을 클릭하면 사용 가능한 모든 레이어를 볼 수 있습니다

### 레이어 전환

1. 레이어 드롭다운을 클릭하여 목록을 엽니다
2. 현재 이미지에 사용 가능한 모든 레이어가 표시됩니다
3. 레이어 이름을 클릭하면 해당 버전으로 전환됩니다
4. 이미지가 즉시 업데이트되어 선택한 레이어가 표시됩니다

**빠른 전환:**

* 드롭다운은 마지막 선택 항목을 기억합니다
* 다음 이미지로 이동할 때, Chloros는 동일한 레이어 유형을 표시하려고 시도합니다
* 다음 이미지에 해당 레이어가 없는 경우, 기본적으로 JPG로 설정됩니다

### 레이어 사용 가능 여부

모든 이미지에 모든 레이어가 사용 가능한 것은 아닙니다:

**항상 사용 가능:*** ✅ JPG (모든 이미지에 JPG 미리보기가 있습니다)

**조건부 사용 가능:**

* ⚠️ RAW (원본) - 이미지가 RAW 또는 RAW+JPG 모드로 촬영된 경우에만
* ⚠️ RAW (타겟) - 이미지에 감지된 보정 타겟이 포함된 경우에만
* ⚠️ RAW (반사율) - 반사율 보정이 활성화된 상태로 처리된 후에만 표시됩니다
* ⚠️ RAW (\[Index] 지수) - 지수가 구성된 상태로 처리된 후에만 표시됩니다

## 레이어 유지

### 이미지 간 이동

다른 이미지로 이동할 때(화살표 키 사용 또는 썸네일 클릭):**레이어 설정은 유지됩니다:**

* &quot;RAW (반사율)&quot;을 보고 있는 경우, 다음 이미지는 &quot;RAW (반사율)&quot;로 표시됩니다(사용 가능한 경우)
* &quot;RAW (NDVI 인덱스)&quot;를 보고 있는 경우, 다음 이미지는 &quot;RAW (NDVI 인덱스)&quot;로 표시됩니다 (사용 가능한 경우)
* 동일한 레이어가 존재하지 않으면 기본적으로 JPG로 표시됩니다

**작업 흐름 예시:**

1. 이미지 1을 열고, RAW (NDVI Index)로 전환합니다
2. → 키를 눌러 이미지 2를 확인합니다
3. 이미지 2에 RAW (NDVI Index) 레이어가 자동으로 표시됩니다
4. 계속 탐색 - 모든 이미지에 NDVI 레이어가 표시됨
5. 다수의 이미지에 대한 인덱스 결과를 검토하는 데 매우 효율적

***

## 일반적인 워크플로

### 워크플로 1: 전후 비교

**목표**: 원본 이미지와 보정된 이미지 비교

1. 이미지 뷰어에서 처리된 이미지를 엽니다
2. 드롭다운 메뉴에서 **RAW (Original)**을 선택합니다
3. 비네팅 및 보정되지 않은 값을 확인합니다
4. 드롭다운 메뉴에서 **RAW (반사율)**로 전환합니다
5. 비교 - 비네팅 제거, 값 보정됨

### 워크플로 2: 인덱스 검토

**목표**: 데이터셋 전반에 걸쳐 NDVI 결과를 빠르게 검토

1. 첫 번째 처리된 이미지를 엽니다
2. 드롭다운 메뉴에서 **RAW (NDVI 인덱스)**를 선택합니다
3. → 화살표 키를 사용하여 다음 이미지로 이동합니다
4. NDVI 레이어가 자동으로 유지됩니다
5. 모든 이미지를 순차적으로 확인하며 NDVI 패턴을 점검합니다
6. 비교를 위해 **RAW (NDRE Index)**로 전환

### 워크플로 3: 타겟 검증

**목표**: 모든 타겟 이미지가 올바르게 감지되었는지 확인

1. 타겟 이미지로 이동
2. 드롭다운에서 **RAW (Target)** 선택
3. 보정 타겟이 선명하게 보이고 감지되었는지 확인
4. 다음 타겟 이미지로 이동
5. 모든 타겟에 대해 검증을 반복

### 워크플로우 4: 픽셀 값 검사

**목표**: 과학적 정확성을 위해 반사율 값 확인

1. 처리된 이미지 열기
2. **RAW (반사율)** 레이어 선택
3. **픽셀 백분율** 모드 활성화 (오른쪽 상단 도구 모음의 버튼)
4. 커서를 식생 영역 위로 이동
5. 픽셀 값이 예상 범위 내에 있는지 확인합니다(NIR의 경우 30-70%, Red의 경우 5-15%)
6. 토양 및 수역 영역의 값이 적절한지 확인합니다

***

## 레이어별 픽셀 값 이해

레이어에 따라 픽셀 값 범위가 다릅니다:

### JPG 레이어

* **범위**: 0-255 (8비트)
* **의미**: 감마 보정된 표시 값
* **용도**: 시각적 확인용이며, 과학적 측정에 사용하지 않음

### RAW (원본)

* **범위**: 0-65535 (16비트)
* **의미**: 센서의 원시 디지털 수치
* **용도**: 센서 성능 확인용, 보정되지 않음

### RAW (반사율)

* **범위**: 0-65,535 (16비트 TIFF) 또는 0.0-1.0 (32비트 백분율)
* **의미**: 보정된 반사율(%)
* **용도**: 과학적 측정 및 분석**16비트 TIFF의 경우:**65,535로 나누어 반사율(%)을 구합니다.**32비트 백분율의 경우:** 값이 직접 백분율을 나타냅니다(0.5 = 50% 반사율).

### RAW (인덱스 이미지)

* **범위**: 인덱스에 따라 다름 (일반적으로 정규화된 인덱스의 경우 -1.0 ~ +1.0)
* **의미**: 인덱스 계산 결과
* **예시**:
  * NDVI: -1 ~ +1 (식생은 일반적으로 0.4 ~ 0.9)
  * NDRE: -1 ~ +1 (스트레스 감지)
  * EVI: 0 ~ 1 (강화된 식생)

***

## 팁 및 모범 사례

### 효율적인 레이어 전환

* **키보드 단축키 활용**: 레이어 전용 단축키는 없지만, 탐색 화살표(←/→)는 모든 레이어에서 작동합니다
* **일관된 워크플로**: 하나의 레이어(예: NDVI)를 선택하여 전체 데이터셋을 검토한 후 다른 레이어로 전환하세요
* **빠른 비교**: &#x27;Original&#x27;과 &#x27;Reflectance&#x27; 레이어를 전환하며 처리 품질을 확인하세요

### 성능 고려 사항

* **JPG가 가장 빠르게 로드됩니다**: 많은 이미지를 빠르게 탐색할 때 사용하세요
* **RAW 레이어는 로드 속도가 느립니다**: 해상도와 비트 심도가 높기 때문입니다
* **인덱스 레이어**: Reflectance 레이어와 비슷한 속도입니다
* **첫 로딩이 가장 느립니다**: 동일한 레이어를 다시 볼 때는 캐시되어 더 빠르게 로드됩니다

### 품질 확인

* **항상 RAW(원본) 확인**: 처리된 결과를 신뢰하기 전에 원본 데이터의 품질을 확인하십시오
* **레이어 비교**: 레이어 전환 기능을 사용하여 처리가 올바르게 수행되었는지 확인하십시오
* **인덱스 범위 확인**: 인덱스 레이어에서 픽셀 백분율 모드를 사용하여 값이 타당한지 확인하십시오***

## 문제 해결

### 레이어가 표시되지 않음

**문제**: 드롭다운 메뉴에 예상한 레이어가 표시되지 않음**가능한 원인:**

* 이미지가 처리되지 않았음 (JPG 및 RAW(원본)만 사용 가능)
* 처리 중 반사율 보정이 비활성화됨
* 프로젝트 설정에서 특정 인덱스가 구성되지 않음
* 이미지가 타겟 전용 이미지임 (타겟에 대해서는 인덱스가 생성되지 않음)

**해결 방법:**

1. 이미지가 처리되었는지 확인하십시오(출력 폴더에서 처리된 파일을 확인).
2. 프로젝트 설정을 확인하여 인덱스가 구성되었는지 확인하십시오.
3. 원하는 인덱스를 활성화한 상태로 다시 처리하십시오.

### 잘못된 레이어가 표시됨

**문제**: 이미지가 예상치 못한 레이어로 열립니다.**원인**: 이전 이미지의 레이어 설정이 그대로 적용되었으나, 현재 이미지에는 해당 레이어가 존재하지 않습니다.**해결 방법**: 선호 레이어를 사용할 수 없을 경우 Chloros는 자동으로 JPG로 전환됩니다. 이는 정상적인 동작입니다.

### 보정 타겟이 보이지 않음

**문제**: RAW(타겟) 레이어에 타겟 감지 결과가 표시되지 않음**가능한 원인:**

* 처리 중에 타겟이 감지되지 않았음
* 이미지에 실제로 타겟이 포함되어 있지 않음
* 타겟 감지 설정이 너무 엄격함

**해결 방법:**

1. 디버그 로그에서 &quot;Target found&quot; 메시지 확인
2. 이미지에 실제로 보이는 보정 타겟이 포함되어 있는지 확인
3. 프로젝트 설정에서 타겟 감지 설정 조정
4. [타겟 이미지 선택](../processing-images-gui/choosing-target-images.md) 참조

## 관련 기능

### 이미지 뷰어 도구

레이어를 볼 때 다음 기능을 사용할 수 있습니다:

* **확대/축소 컨트롤**: 확대하여 세부 사항을 확인
* **이동**: 클릭하고 드래그하여 확대된 이미지를 이동
* **픽셀 값 확인**: 커서 위치의 값 확인
* **이동 화살표**: 레이어를 유지한 채 이미지 간 이동
* **픽셀 백분율 모드**: DN 표시와 백분율 표시 간 전환

이미지 뷰어에 대한 전체 문서는 [이미지 전체 화면 열기](opening-an-image-full-screen.md)를 참조하십시오.

### 인덱스/LUT 샌드박스

대화형 인덱스 테스트 및 시각화를 위해:

* **실시간 인덱스 계산**: 다양한 인덱스 공식을 테스트합니다
* **LUT 색상 매핑**: 그레이스케일 인덱스에 색상 그라데이션을 적용합니다
* **시각화 내보내기**: 색상이 적용된 인덱스 이미지를 저장합니다

자세한 내용은 [인덱스/LUT 샌드박스](index-lut-sandbox.md)를 참조하십시오.
