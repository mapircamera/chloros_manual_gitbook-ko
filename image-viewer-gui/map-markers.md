# 지도 마커

‘지도’ 탭에서는 GPS 좌표를 기반으로 이미지를 대화형 2D 지도에 표시합니다. 이를 통해 촬영 세션의 지리적 개요를 파악하고 공간적 범위를 시각적으로 확인할 수 있습니다. 또한 이미지를 처음 가져올 때 처리할 필요가 없는 이미지를 빠르게 제거하는 데 유용합니다.

<figure><img src="../.gitbook/assets/chloros_map_markers.gif" alt=""><figcaption></figcaption></figure>

## 지도 탭 열기

1. Chloros에서 프로젝트를 열거나 생성합니다.
2. GPS 메타데이터가 포함된 이미지를 가져옵니다.
3. 왼쪽 사이드바의 **지도** <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> 탭을 클릭합니다
4. 지도에 각 이미지의 GPS 위치에 마커가 표시됩니다

{% hint style="info" %}
**GPS 필수**: EXIF 메타데이터에 GPS 좌표가 포함된 이미지만 지도에 표시됩니다. 촬영 시 카메라의 GPS 기능이 활성화되어 있는지 확인하십시오.
{% endhint %}

## 지도 탭에서 이미지 조정하기**지도**<img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> 탭에는 추가  <img src="../.gitbook/assets/image.png" alt="" data-size="line">   <img src="../.gitbook/assets/image (1).png" alt="" data-size="line">  및 삭제  <img src="../.gitbook/assets/image (2).png" alt="" data-size="line">  버튼을 제공합니다. 또한 [**파일 브라우저**](../processing-images-gui/adding-files-to-a-project.md) <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> 탭과 동일한 파일 추가및 제거버튼을 제공합니다. 또한 동일한 프로젝트 파일 테이블 목록을 표시하지만 열 머리글은 다릅니다:

### 파일 이름

* 카메라의 원본 파일 이름
* 카메라의 명명 규칙을 유지합니다(예: IMG\_0001.RAW)

### 위도

* 이미지의 위도

### 경도

* 이미지의 경도

### 고도

* 이미지의 고도

{% hint style="info" %}
표의 열 머리글을 클릭하면 행 데이터가 정렬됩니다
{% endhint %}

## 이미지 마커

GPS 데이터가 포함된 각 이미지는 지도상의 마커로 표시됩니다:

### 마커 표시

* 마커는 각 이미지가 촬영된 정확한 GPS 좌표를 나타냅니다
* 축소 시 밀집된 마커가 한데 묶여 표시될 수 있습니다
* 확대하여 개별 이미지 위치를 확인하세요

{% hint style="success" %}
슈퍼 줌: 지도 타일 제공업체의 최대 확대 수준에 도달하면, 더 확대할 때 타일이 확대되어 서로 가까이 있는 마커를 볼 수 있습니다.
{% endhint %}

### 마우스 오버 미리보기

* 마우스를 마커 위에 **올리면** 해당 이미지의 썸네일 미리보기를 볼 수 있습니다
* 이를 통해 지도 화면을 벗어나지 않고도 빠르게 이미지를 식별할 수 있습니다
* 대용량 촬영 세션 내에서 특정 이미지를 찾는 데 유용합니다

***

## 지도 타일 제공업체

{% hint style="success" %}
**자동 선택**: Chloros는 현재 지도 위치에 가장 적합한 확대/축소 수준을 제공하는 타일 서비스를 자동으로 선택합니다. 원할 경우 수동으로 제공자를 전환할 수 있습니다.
{% endhint %}

지도 탭은 배경 지도 이미지에 대해 두 가지 타일 제공자를 지원합니다:

### Google Maps

* Google의 표준 위성 및 지도 이미지
* 전 세계적인 범위를 포괄하는 데 가장 적합

### ESRI

* ESRI ArcGIS의 위성 및 항공 이미지
* 특정 지역에서 더 높은 해상도의 이미지를 제공하는 경우가 많음

***

## 지도 타일 유형

지도 레이어 유형을 선택할 수 있습니다(왼쪽부터 오른쪽 순):

 <img src="../.gitbook/assets/image (23).png" alt="" data-size="original">### 지형

고도 프로필과 세부 정보(도로 등)가 포함된 지도 타일을 표시합니다

### 지도

세부 정보(도로 등)가 포함된 표준(저대역폭) 지도 타일을 표시합니다

### 위성

세부적인(고대역폭) 위성 지도 타일을 표시합니다

### 하이브리드

세부 정보(도로 등)가 추가된 위성 지도 타일을 표시합니다

## 지도 탐색

### 확대/축소 제어

* **확대/축소**: 마우스 휠 또는 확대/축소 버튼을 사용합니다
* **전체 화면**: 지도를 전체 화면으로 표시합니다

### 이동 제어

* **이동**: 클릭하고 드래그하여 지도를 이동합니다***

## 사용 사례

### 비행 경로 시각화

* 드론 촬영 세션의 커버리지 영역 확인
* 이미지 커버리지의 누락된 부분 파악
* 비행 경로 실행 확인

### 지상 조사 검토

* 지상 촬영 데이터의 공간적 분포 확인
* 조사 영역을 기준으로 보정 대상 이미지 위치 파악
* 추가 촬영 위치 계획

### 품질 관리

* 예상치 못한 위치에서 촬영된 이미지를 신속하게 식별
* 데이터 세트 전반에 걸친 GPS 정확도 확인
* 이미지 위치와 현장 기록을 상호 참조

***

## 문제 해결

### 마커가 표시되지 않음

**가능한 원인:**

* 이미지에 GPS 메타데이터가 포함되어 있지 않음
* 촬영 중 카메라의 GPS가 비활성화됨
* 외부 소프트웨어에 의해 EXIF 데이터가 제거됨

**해결 방법**: 카메라에서 GPS가 활성화되어 있는지 확인하고 원본 파일을 다시 가져오십시오

### 마커 위치가 잘못된 경우

**가능한 원인:**

* 카메라 GPS의 위성 신호 수신이 불량함
* 촬영 중 GPS 신호 편차 발생

**해결 방법**: 이는 일반적으로 촬영 시점의 문제입니다. 정밀 측정이 필요한 경우 PPK/RTK GPS 사용을 고려하십시오
