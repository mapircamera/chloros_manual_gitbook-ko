# 지도 마커

‘지도’ 탭은 GPS 좌표를 기반으로 이미지를 대화형 2D 지도에 표시합니다. 이 기능을 통해 촬영 세션의 지리적 개요를 파악할 수 있으며, 이미지 가져오기 직후 처리하지 않으려는 이미지를 가장 빠르게 제외할 수 있는 방법입니다.

<figure><img src="../.gitbook/assets/chloros_map_markers.gif" alt=""><figcaption></figcaption></figure>

## 지도 탭 열기

1. Chloros에서 프로젝트를 열거나 생성합니다.
2. GPS 메타데이터가 포함된 이미지를 가져옵니다.
3. 왼쪽 사이드바에서 **지도** <img src="../.gitbook/assets/image (3) (1).png" alt="" data-size="line"> 탭을 클릭합니다.
4. 지도에는 각 이미지의 GPS 위치에 마커가 표시됩니다.

{% hint style="info" %}
**GPS 필수**: EXIF 메타데이터에 GPS 좌표가 포함된 이미지만 지도에 표시됩니다. 좌표가 없는 이미지는 여전히 프로젝트에 남아 있으며 정상적으로 처리됩니다. 단지 마커가 표시되지 않을 뿐입니다.
{% endhint %}

***

## ‘지도’ 탭에서 이미지 조정하기**지도**<img src="../.gitbook/assets/image (3) (1).png" alt="" data-size="line"> 탭에는 [**파일 브라우저**](../processing-images-gui/adding-files-to-a-project.md) <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> 탭과 동일한 ‘추가’ <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> 및 ‘제거’ <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line"> 파일 버튼이 있습니다. 이 탭에는 지리적 열이 포함된 동일한 프로젝트 파일 목록이 표시됩니다:

| 열        | 내용                                                           |
| ------------- | ------------------------------------------------------------------ |
| **이름**      | 카메라에서 가져온 파일 이름                             |
| **위도**  | 소수점 이하 6자리까지의 도 단위                                |
| **경도**      | 소수점 이하 6자리까지의 소수 도                                |
| **고도**      | 소수점 이하 1자리까지의 미터 — 이미지에 고도 정보가 없는 경우 `-` |

{% hint style="info" %}
열 머리글을 클릭하면 해당 기준으로 정렬되며, 다시 클릭하면 정렬 순서가 반전됩니다.
{% endhint %}

{% hint style="warning" %}
**고도는 지면 위 높이가 아닌 해수면 위 높이를 의미합니다.** 이 값은 이미지의 EXIF `GPSAltitude` 태그에서 가져온 것으로, 기준 해수면을 기준으로 합니다. 이는 지형 위의 비행 고도가 아니며, Chloros는 이를 바탕으로 지상 샘플 거리를 산출하지 않습니다. 해발 300m인 들판 위에서 AGL 100m 높이의 드론이 비행할 경우, 이 열에는 대략 400m로 기록됩니다. 이 열은 AGL 측정값으로 사용하기보다는 이상치를 파악하고 일관된 비행 고도를 확인하는 데 활용하십시오.
{% endhint %}

## 이미지 마커

GPS 데이터가 포함된 각 이미지에는 해당 좌표에 마커가 표시됩니다.

### 마커 표시

* 마커는 각 촬영 시 기록된 정확한 좌표에 위치합니다.
* 마커가 서로 가까이 있으면 화면을 축소했을 때 시각적으로 겹쳐 보일 수 있습니다. 확대하여 구분해 주십시오.
* 선택되거나 강조 표시된 마커는 나머지 마커보다 위에 표시됩니다.

### 마우스 오버 미리보기

* 마커 위에 **마우스 커서를 올리면** 해당 이미지의 썸네일과 파일 이름이 표시되는 팝업이 나타납니다
* 마커를 **클릭**하면 이미지가 선택되고 팝업이**고정**됩니다. 다른 곳을 클릭할 때까지 팝업이 유지됩니다. 팝업이 고정된 상태에서는 다른 마커 위에 마우스를 올려도 팝업이 사라지지 않습니다.
* 이는 지도를 벗어나지 않고도 방대한 세션에서 특정 프레임을 빠르게 찾을 수 있는 방법입니다.

<figure><img src="../.gitbook/assets/image (36).png" alt=""><figcaption><p>&#x27;지도&#x27; 탭에는 프로젝트에 포함된 모든 지오태그가 지정된 이미지가 표시됩니다</p></figcaption></figure>### 슈퍼 줌

{% hint style="success" %}
**슈퍼 줌**: 타일 제공자가 지원하는 최대 확대 수준에 도달해도 더 확대하면 타일이 멈추지 않고 계속 확대되므로, 서로 거의 겹쳐 있는 마커들을 구분할 수 있습니다.
{% endhint %}

* 슈퍼 줌은 해당 위치에 대해 제공업체의 최대 확대 배율에 **도달한** 상태에서 타일 로딩이 완료된 경우에만 활성화됩니다. 그 이하 배율에서는 확대 기능이 정상적으로 작동합니다.
* 적용 범위는 제공업체의 최대 확대 배율에 **1×에서 32×**까지 추가됩니다.
* 모서리에 있는 표시기는 현재 슈퍼 줌 수준을 백분율로 보여주며, 그 옆의 **×** 버튼을 클릭하면 한 번에 일반 줌 상태로 돌아갑니다.
* 축소할 때는 항상 지도 자체로 바로 이동하므로, 슈퍼 줌 상태에 갇히는 일은 절대 없습니다.
* 슈퍼 줌 상태에서 확대/축소 및 패닝을 수행하면 발생한 오프셋이 지도에 반영되므로, 이동한 중심에서 벗어난 영역이 텅 비지 않고 계속 타일을 요청합니다.
* 마커는 래스터화되지 않고 벡터 요소로 그려지므로, 모든 슈퍼 줌 수준에서 선명하게 유지됩니다.

## 지도 타일 제공자

{% hint style="success" %}
**자동 선택**: Chloros는 사용자의 이미지가 위치한 위치에 가장 적합한 확대/축소 수준을 제공하는 타일 서비스를 선택합니다. 언제든지 수동으로 전환할 수 있습니다.
{% endhint %}

| 제공업체        | 참고 사항                                                                                                                                                             |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Google Maps** | 전 세계적으로 광범위한 커버리지; 네 가지 타일 유형 모두 지원                                                                                                            |
| **Esri ArcGIS**| 특정 지역에서 종종 더 높은 해상도의 항공 이미지를 제공합니다. Esri의 경우**Terrain** 타일 유형이 제공되지 않으며, Esri가 선택된 상태에서는 해당 버튼이 비활성화됩니다 |***

## 지도 타일 유형

버튼을 사용하여 지도 레이어 유형을 선택하세요(왼쪽부터 오른쪽 순서):

![](&lt;../.gitbook/assets/image (14).png&gt;)

| 유형                 | 표시 내용                                                                |
| -------------------- | -------------------------------------------------------------------- |
| **지형**          | 지도 세부 정보(도로, 레이블)가 포함된 고도 음영 처리. Google에서만 제공       |
| **지도**              | 표준 도로 지도 타일 — 대역폭 요구량이 가장 적은 옵션              |
| **위성**        | 상세한 위성 이미지, 표기 없음 — 대역폭을 가장 많이 소모하는 옵션 |
| **하이브리드** (기본값) | 위성 이미지에 도로 및 표기가 중첩된 형태                |

&#x27;지도&#x27; 탭은 **하이브리드** 모드로 열립니다. 사용자가 선택한 설정은 해당 서비스 제공업체가 지원하는 경우 제공업체 전환 시에도 유지됩니다.***

## 지도 탐색

* **확대/축소**: 마우스 휠 또는 지도상의 확대/축소 버튼
* **이동**: 클릭 후 드래그
* **전체 화면**: 전체 화면 컨트롤을 사용하면 지도가 창 전체로 확대됩니다***

## 사용 사례

### 비행 경로 검토

* 드론 촬영 세션의 촬영 범위를 한눈에 확인
* 촬영을 놓친 구역을 파악
* 비행 경로가 계획된 패턴을 따랐는지 확인

### 지상 측량 검토

* 지상 촬영 이미지가 어떻게 분포되어 있는지 확인
* 측량 영역을 기준으로 보정 타겟 프레임의 위치를 파악
* 추가 촬영이 필요한 위치를 결정

### 품질 관리

* 예상치 못한 위치에서 촬영된 이미지를 찾아내어 처리 전에 제거할 수 있습니다.
* 고도별로 정렬하여 잘못된 높이에서 촬영된 프레임이나 GPS 위치 정보가 불확실한 프레임을 파악할 수 있습니다.
* 이미지 위치를 현장 기록과 대조하여 확인할 수 있습니다.

***

## 문제 해결

### 마커가 표시되지 않음

**가능한 원인**

* 이미지에 GPS 메타데이터가 포함되어 있지 않음
* 촬영 시 카메라에서 GPS가 비활성화되어 있었음
* 가져오기 전에 다른 소프트웨어에 의해 EXIF 데이터가 제거됨

**해결 방법**: 카메라에서 GPS가 활성화되어 있는지 확인하고 원본 파일을 다시 가져오십시오. ‘지도’ 탭의 파일 표에서 특정 파일을 찾아 좌표가 있는지 확인할 수 있습니다. 좌표가 없는 이미지는 해당 표에 행이 표시되지 않습니다.

### 마커가 잘못된 위치에 표시됨

**가능한 원인**: 촬영 시 위성 신호 수신이 불량했거나, 촬영 중 GPS 신호가 어긋난 경우입니다.**해결 방법**: 이는 촬영 시점의 문제로, Chloros가 사후에 수정할 수 있는 사항이 아닙니다. 정밀한 작업을 위해서는 PPK/RTK GPS 워크플로를 사용하십시오. [프로젝트 설정](../project-settings/project-settings.md)의**PPK 보정 적용** 설정을 참조하십시오.

### 지도가 비어 있거나 타일 로딩이 중단됨

타일 제공업체는 온라인 서비스입니다. 타일 전송이 중단되면 기기의 네트워크 연결 상태를 확인한 후, 제공업체를 변경해 보세요. 확대가 너무 많이 되어 있었다면, **×** 재설정 버튼을 눌러 일반 확대/축소 수준으로 되돌린 다음 지도가 타일을 다시 요청하도록 하세요.***
