# 이미지 전체 화면으로 열기

Chloros 이미지 뷰어는 다중 스펙트럼 이미지를 확인, 분석 및 편집할 수 있는 전용 전체 화면 인터페이스를 제공합니다. 원본 이미지이든 처리된 결과물이든, 이미지 뷰어는 검사 및 분석을 위한 강력한 도구를 제공합니다.

## 이미지 뷰어 실행

### 파일 브라우저에서

이미지 뷰어에서 이미지를 여는 가장 일반적인 방법:

1. **파일 브라우저** 탭에 있는지 확인하십시오 <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line">
2. 이미지 그리드에서 **이미지 썸네일**을 클릭합니다
3. 이미지가 **메인 미리보기 영역**(화면 중앙)에 열립니다
4. 이제 이미지가 로드되어 전체 화면으로 볼 준비가 되었습니다

### 이미지 뷰어 탭 열기

미리보기 영역에 이미지가 로드되면:

1. 왼쪽 사이드바에서 **이미지 뷰어** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 아이콘을 클릭합니다
2. 이미지 뷰어 탭이 열리며 선택한 이미지가 전체 화면으로 표시됩니다
3. 왼쪽 사이드바에 고급 보기 및 분석 도구가 표시됩니다

***

## 이미지 뷰어 인터페이스 개요

### 메인 표시 영역

화면의 가장 큰 부분은 이미지를 표시합니다:

* **전체 해상도**: 원본 해상도로 이미지가 표시됩니다
* **확대/축소 가능**: 컨트롤 또는 마우스 휠을 사용하여 확대/축소
* **이동 가능**: 확대된 상태에서 클릭하고 드래그하여 이동
* **가로세로비율 유지**: 이미지가 비례적으로 확대/축소됨***

## 보기 옵션

### 기본 이미지 탐색

#### 이미지 탐색

키보드 단축키 또는 버튼을 사용하여 이미지 세트를 탐색합니다:

* **다음 이미지**: → 버튼을 클릭하거나**→**(오른쪽 화살표) 키를 누르세요
* **이전 이미지**: ← 버튼을 클릭하거나**←**(왼쪽 화살표) 키를 누르세요
* **특정 이미지로 이동**: 파일 브라우저로 돌아가 원하는 썸네일을 클릭하세요

#### 확대/축소 컨트롤

확대/축소 비율을 조절하여 이미지 세부 사항을 확인하세요:

**확대:*** **+** (더하기) 버튼을 클릭합니다
* **+**또는**=** 키를 누릅니다
* 마우스 휠을 **위로** 스크롤합니다**축소:*** **−** (빼기) 버튼을 클릭합니다
* **−** (빼기) 키를 누릅니다
* 마우스 휠을 **아래로** 스크롤합니다

#### 확대 시 이동

화면 크기를 초과하여 확대된 경우:

1. 마우스 커서를 이미지 위로 이동
2. **마우스 왼쪽 버튼을 클릭한 상태로** 유지
3. **드래그**하여 이미지를 이동
4. 버튼을 놓으면 이동이 중지됨

**다른 방법**: 화살표 키를 사용하여 조금씩 이동***

## 픽셀 값 확인

### 커서 위치의 픽셀 값 확인

이미지 위에서 마우스 커서를 이동하면 픽셀 값이 실시간으로 표시됩니다:**값 표시 위치:*** **오른쪽 인덱스 LUT 그라데이션 범례의 플로팅 숫자 및 빨간색 선*** **더 확대하면 커서 근처 및 강조 표시된 픽셀의 플로팅 값*** **커서 아래 또는 강조 표시된** 픽셀의 값을 표시합니다
* 마우스 이동 시 업데이트됨

***

## 확인 가능한 이미지 유형

### JPG

**카메라에서 가져온 JPG 이미지:**

* 미리보기대로 JPG 데이터 표시
* 보정되지 않은 원본 값 표시
* 처리 전 이미지 품질 확인에 유용

### RAW (원본)

### RAW (반사율)

**처리 후:**

* 비네팅 보정
* 반사율 보정
* 다중 대역 TIFF (Red, Green, NIR 등)
* 분석 준비 완료된 과학 데이터

### RAW (지수)

**NDVI, NDRE, GNDVI 등 (\_NDVI.tif 파일):**

* 단일 대역 그레이스케일 이미지
* 픽셀 값은 지수 계산 결과를 나타냄
* 정규화된 지수의 경우 범위는 일반적으로 -1에서 +1 사이
* 시각화를 위해 색상 LUT 적용 가능

***

## 지수 및 LUT 적용

다중 스펙트럼 지수 및 색상 룩업 테이블(LUT) 적용:

1. **이미지 뷰어**에서**지수/LUT 샌드박스**를 찾습니다 <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 사이드바
2. 식생 지수(NDVI, NDRE 등)를 선택합니다
3. 다중 스펙트럼 공식을 선택하거나 사용자 정의 공식을 생성합니다(Chloros+ 전용)
4. 시각화를 위해 색상 LUT 그라데이션을 적용합니다
5. 값 범위와 임계값을 조정합니다

자세한 지침은 [지수/LUT 샌드박스](index-lut-sandbox.md)를 참조하십시오.

***

## 키보드 단축키

### 탐색

* **→** (오른쪽 화살표): 다음 이미지
* **←** (왼쪽 화살표): 이전 이미지
* **Home**: 목록의 첫 번째 이미지
* **End**: 목록의 마지막 이미지

### 확대/축소

* **+**또는**=**: 확대
* **−**: 축소
* **마우스 휠**: 확대/축소***

### 인덱스 계산 확인

인덱스가 올바르게 계산되었는지 확인하십시오:

1. NDVI 또는 다른 지수 이미지를 엽니다.
2. 식생 구역을 확인합니다:
   * **NDVI**: 건강한 식물의 경우 0.4~0.9가 표시되어야 합니다.
   * **NDRE**: 활발한 성장일수록 값이 높습니다.
   * **GNDVI**: NDVI와 유사하지만 엽록소에 민감함
3. 비식생 영역 확인:
   * **토양**: 0에 가깝거나 약간 음수
   * **물**: 음수 값 (-0.5 ~ 0)***

## 이미지 표시 문제 해결

### 이미지가 열리지 않음

**가능한 원인:**

* 처리 중 파일이 손상됨
* 지원되지 않는 파일 형식
* 대용량 이미지를 처리하기에 메모리가 부족함

**해결 방법:**

1. 외부 뷰어에서 열어 파일 무결성을 확인해 보세요
2. 파일 형식이 예상된 유형과 일치하는지 확인하세요
3. 다른 애플리케이션을 닫아 메모리를 확보하세요
4. 더 작은 이미지나 다른 이미지를 시도해 보세요

### 이미지가 검은색 또는 흰색으로 표시됨

**가능한 원인:**

* 표시 범위를 벗어난 값 범위
* 비정상적인 값을 가진 32비트 부동소수점 이미지
* 인덱스 계산 오류

**해결 방법:**

1. 픽셀 값 확인 - 모든 값이 매우 낮거나 높다면 표시 범위를 조정하십시오
2. QGIS 또는 자동 범위 조정 기능이 있는 유사한 프로그램에서 열어 보십시오
3. 처리 과정에서 발생한 오류가 있는지 디버그 로그를 확인하십시오

### 픽셀 값이 잘못된 것 같습니다

**가능한 원인:**

* 잘못된 이미지 열기 (원본 vs 처리된 이미지)
* 보정이 올바르게 적용되지 않음
* 입력 데이터에 광센서 데이터가 포함되지 않음
* 백분율 모드 설정이 잘못됨

**해결 방법:**

1. 처리된 출력물을 보고 있는지 확인(파일명 확장자 확인)
2. 백분율 모드 버튼 상태 확인
3. 동일한 데이터셋의 정상적인 이미지와 비교
