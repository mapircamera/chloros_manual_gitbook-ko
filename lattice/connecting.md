# 카메라 연결

<figure><img src="../.gitbook/assets/image (37).png" alt=""><figcaption><p>아무것도 연결되기 전의 ‘카메라’ 탭</p></figcaption></figure>Chloros는 링크에서 LATTICE 카메라를 자동으로 감지합니다. 이는 GUI의 &#x27;카메라&#x27; 탭, `chloros-cli lattice`, 또는 Python SDK를 통해 자동으로 LATTICE 카메라를 감지합니다. 카메라의 모델 문자열은 이후 모든 과정을 주도합니다: Chloros는 카메라의 `DeviceUserID` + `DeviceSerialNumber` 정보를 바탕으로 센서 프로필, 밴드 레이아웃 및 공장 보정 값을 파악하므로, **카메라별로 별도로 구성할 사항은 없습니다**.

연결하기 전에 호스트 네트워크가 제대로 설정되었는지 확인하십시오 — 링크 로컬 주소 지정, 점보 프레임, 그리고 어레이의 경우 NIC 수신 버퍼 설정 등입니다. 이는 하드웨어 측면의 설정이며, LATTICE 설명서 [**네트워크 설정**](https://mapir.gitbook.io/lattice-camera/setup/network-setup)에 나와 있습니다.

## GUI를 통한 연결

Chloros 사이드바에서 **카메라**탭을 열거나(백엔드 시작이 완료되면 하드웨어 탭이 표시됨), 메인 메뉴 →**카메라에 연결**을 사용하십시오. 두 방법 모두**카메라 연결** 대화 상자를 엽니다.

### **카메라 연결** 대화 상자

이 대화 상자는 열리자마자 네트워크를 스캔하며(&quot;네트워크 스캔 중...&quot;), 발견된 모든 카메라를 나열합니다. 각 행에는 카메라의 **모델**(예: `LATT-M3M-L41-F550`),**일련번호**및**IP 주소**가 표시됩니다.

* **행 하나를 클릭하여 선택합니다**(녹색으로 강조 표시됨).**여러 대의 카메라**를 선택하여 한 번에 연결할 수 있습니다. Chloros는 순서대로 연결합니다.
* **&quot;연결됨&quot;** 배지가 표시된 행은 이미 연결된 상태이므로 다시 선택할 수 없습니다.
* **&quot;어레이 포함&quot;** 배지가 표시된 행은 현재 연결된 카메라 어레이에 속합니다. 해당 카메라를 단독으로 사용하려면 먼저 어레이 연결을 해제하십시오.
* **연결** — 선택한 카메라를 연결합니다. 두 대 이상이 선택된 경우, 버튼에 개수(예: &quot;연결 (3)&quot;)가 표시됩니다.
* **재스캔** — 검색을 다시 실행합니다.
* **닫기** — 대화 상자를 닫습니다.
* 스캔 결과 아무것도 발견되지 않으면 대화 상자에 **&quot;네트워크에서 카메라를 찾을 수 없음&quot;**이 표시됩니다. 아래의 [문제 해결](connecting.md#troubleshooting)을 참조하십시오.

<figure><img src="../.gitbook/assets/image (38).png" alt=""><figcaption><p>카메라 연결 대화 상자 — 여기서는 네트워크에 카메라가 없는 상태로 표시됨</p></figcaption></figure>### 첫 연결: 보정 팩 다운로드

특정 카메라를 컴퓨터에 **처음**연결할 때, Chloros는 GigE를 통해 카메라 자체에서 카메라의 공장 출하 시 보정 팩(약 3.8 MB)을 가져옵니다. 이 과정이 진행되는 동안 대화 상자에는 시리얼 번호별 진행률 표시줄이 포함된 녹색**&quot;카메라에서 보정 데이터 다운로드 중&quot;**패널이 표시되며, 카메라당 약**70초**가 소요됩니다. 이 팩은 호스트에 캐시되므로, 동일한 카메라를 나중에 다시 연결할 때는 다운로드 과정이 완전히 생략됩니다(해당 패널도 표시되지 않음).

### 시스템 분석

대화 상자의 **시스템 분석** 버튼을 클릭하면 호스트와 네트워크를 검사하며(실행 중에는 &quot;분석 중...&quot;이라는 메시지가 표시됨), 진단 보고서를 출력합니다:

* **호스트** — CPU 코어 및 RAM; GPU 이름 및 메모리, 또는 &quot;GPU: 감지되지 않음&quot;.
* **네트워크 인터페이스** — 각 NIC의 이름, 링크 속도, MTU(활성화된 경우 &quot;jumbo&quot; 태그 포함), 업/다운 상태, 그리고 USB 버스에 연결되어 있는지 여부.
* **카메라**— 시리얼 번호, 모델, IP,**각 카메라가 연결된 NIC**.
* **성능** — 픽셀 형식별 카메라당 현재 fps와 이상적인 fps를 비교하며, 이상적인 값이 현재 값을 초과할 경우 녹색 &quot;잠재력: N배 개선 가능&quot; 줄이 표시됩니다.
* **경고 및 번호가 매겨진 권장 사항** — 수정할 사항이 없을 경우 “현재 카메라 수에 대해 시스템 상태가 양호합니다.”라는 메시지가 표시됩니다.

탐지 또는 스트리밍이 예기치 않게 작동할 때마다 이 기능을 실행하십시오. 대화 상자를 벗어나지 않고도 대부분의 NIC 관련 문제(잘못된 MTU, 잘못된 인터페이스에 연결된 카메라, USB 어댑터 제한 등)를 식별할 수 있습니다.

### 어레이 연결

두 대 이상의 카메라를 **동기화된 어레이**로 연결하려면 어레이 연결 마법사(**카메라 어레이 연결**)를 사용하십시오. 이 마법사는 마스터/슬레이브 선택(GPIO 배선 프로브를 통해 미리 입력됨), 디스플레이 모드 선택(별도 타일 vs. 결합 타일), 그리고 적용하기 전에 달성 가능한 fps와 배선 대역폭을 실시간으로 보여주는 어레이 설정 화면을 단계별로 안내합니다. 이 마법사와 어레이 워크플로는 본 설명서의 다중 카메라 어레이 섹션에서 다루고 있으며, CLI에 해당하는 내용은 [CLI 참조](../reference/cli-reference.md)의 “LATTICE 카메라 초기 연결 워크플로”입니다.

## CLI 및 SDK에서 연결하기

CLI 및 SDK에 액세스하려면 유료 Chloros+ 등급이 필요하며 로그인 상태여야 합니다; 이는 서버 측에서 강제 적용됩니다(로그인하지 않은 경우 `401 AUTH_REQUIRED`, 무료 티어의 경우 `403 PLAN_UPGRADE_REQUIRED`).

```bash
# List cameras on the network (vendor, model, serial, IP, MAC)
chloros-cli lattice info

# Single-camera smoke test: capture one frame (saves every applicable export type)
chloros-cli lattice capture -o output/

# Connect a synchronized array — same smart-prep flow as the GUI
chloros-cli lattice array-connect --serials 213800234,214000533
```

```python
import chloros_sdk

# Persistent live-camera session through the backend
with chloros_sdk.connect_camera("213800234") as cam:
    ...

# Array session (smart-prep: network probe, tier auto-pick, PTP, AE seeding, trigger config)
with chloros_sdk.connect_array(["213800234", "214000533"]) as array:
    ...
```

전체 시그니처, 옵션 및 캡처 워크플로: [CLI 참조](../reference/cli-reference.md) § `chloros-cli lattice`, [SDK 참조](../reference/sdk-reference.md) § `connect_camera()` / `connect_array()`.

## 연결 시 보정 처리 방식

모든 LATTICE 카메라는 **카메라 내부**에 공장 보정 팩을 탑재하고 있으며, Chloros는 카메라가 연결될 때 MAPIR의 클라우드도 확인합니다:

| 상황   | Chloros가 사용하는 것                                                                                                                                                                                                          |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **온라인**|**해당 일련번호에 대해 게시된 최신 보정 데이터** — 클라우드 사본이 카메라 내 사본보다 우선합니다. 따라서 MAPIR에 의해 재보정되거나 업데이트된 카메라는 자동으로 자체 업데이트되며, 사용자의 별도 조치가 필요하지 않습니다. |
| **오프라인**|**카메라 내부의 보정 데이터**가 있는 그대로 유지됩니다. 완전한 오프라인 워크플로는 계속 작동하며, 카메라가 한 번이라도 온라인 상태가 되거나(또는 공장 초기화 후 재플래시될 때까지) 최신 보정 데이터를 반영하지 않습니다.                                                  |

촬영 시점에 실제로 적용된 계수는 **각 이미지의 XMP 메타데이터에 고정**됩니다. 이후의 보정 업데이트는 이미 촬영한 이미지에 아무런 변경도 가하지 않습니다. 기존 촬영물을 재처리할 때는 오늘날 가장 최신 버전이 아닌, 해당 XMP에 기록된 계수가 사용됩니다.

## 문제 해결

* **&quot;네트워크에서 카메라를 찾을 수 없음&quot;**— [네트워크 설정](https://mapir.gitbook.io/lattice-camera/setup/network-setup)에서 링크 로컬 설정을 확인하십시오: 호스트 NIC 정적 주소 `169.254.x.x/16`, 카메라가 동일한 링크에 연결되어 있어야 하며, DHCP/게이트웨이는 사용되지 않아야 합니다. 그런 다음 연결 대화 상자의**시스템 분석**을 사용하여 각 카메라가 어느 NIC에서 표시되는지(또는 표시되지 않는지) 확인하십시오. 케이블 연결이나 NIC를 변경한 후에는**다시 검색**하십시오.
* **이전에 정상적으로 작동하던 시스템이 연결되지 않는 경우** (`FRAMES WILL DROP` / `Reduce ROI to enable`가 표시된 어레이 패널) — NIC 드라이버 업데이트로 인해 수신 링 설정이 자동으로 재설정되었을 수 있습니다. 해당 설정을 다시 적용하거나 관리자 권한 터미널에서 `chloros-cli lattice network --fix`를 실행하십시오. 자세한 내용은 [네트워크 설정](https://mapir.gitbook.io/lattice-camera/setup/network-setup)을 참조하십시오.
* **카메라에 &quot;In Array&quot;가 표시됨** — 이 카메라는 연결된 어레이 세션에 속해 있습니다. 카메라를 독립적으로 사용하려면 어레이 연결을 해제하십시오.
