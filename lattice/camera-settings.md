# 카메라 설정

**카메라**탭은 LATTICE 카메라를 위한 Chloros의 실시간 제어 화면입니다. 여기에는 연결된 모든 카메라를 실시간 타일로 표시하는 메인 피드 영역과,**카메라 목록**,**설정 패널**(카메라별, 어레이 또는 캡처 설정 — 한 번에 하나씩), 그리고**인덱스 계산기**로 구성됩니다. 이 페이지에서는 카메라 목록, 카메라별 설정 패널 및 어레이 설정 패널에 있는 모든 제어 기능을 설명합니다. 캡처 모드, 내보내기 유형 선택 및 ‘모두 캡처(Capture All)’ 흐름에 대한 내용은 관련 페이지 [캡처 설정 및 모드](capture.md)에서 확인할 수 있습니다.

Chloros 백엔드가 준비되면 사이드바에 ‘카메라’ 탭이 표시됩니다. 아래의 모든 제어 요소는 `127.0.0.1:5000`를 통해 로컬 백엔드와 통신하며, 별도로 명시되지 않는 한 변경 사항은 실시간 카메라에 즉시 적용됩니다.

## 이 페이지에서 사용되는 카메라 유형

제어 항목은 선택된 카메라 유형에 따라 표시되거나 숨겨집니다. 이 설명서에서는 다음 용어를 일관되게 사용합니다:

| 용어 | 의미 | 필터 채널 |
| --- | --- | --- |
| **RGB 카메라** | FRGB 필터가 장착된 LATTICE M3C (모델명에 `-FRGB` 포함) | Red / Green / Blue |
| **바이엘 다중 스펙트럼** | FRGN, FOCN 또는 FNGB 탑재 LATTICE M3C | FRGN: Red / Green / NIR · FOCN: Orange / Cyan / NIR · FNGB: NIR / Green / Blue |
| **모노 (M3M)** | LATTICE M3M — 협대역 필터 1개, 보정된 대역 1개 | 단일 대역 |
| **어레이 구성 요소** | 동기화된 어레이의 일부로 연결된 카메라 (통합 또는 개별 표시) | 해당 필터 기준 |

RGB 카메라는 광도 처리(화이트 밸런스, 색상 프로파일, 감마)를 적용받으며, 다중 스펙트럼 및 모노 카메라는 방사도 체인을 적용받고 광도 제어 단계는 건너뜁니다. 어레이 구성원은 스트림 수준의 설정 (픽셀 형식, 해상도, 비닝, 트리거, 프레임 속도)를 어레이로 전송합니다. 해당 행들은 카메라별 패널에서 읽기 전용으로 변경되며, 대신 어레이 설정 패널로 이동합니다.

## 메인 피드 영역

카메라가 연결되어 있지 않으면 피드 영역에 **&quot;시작하려면 카메라를 연결하세요&quot;**라는 시작 화면이 표시되며, 여기에는**카메라 연결**(녹색, 단일 카메라 연결 대화 상자 열기) 및**어레이 연결** (파란색, 어레이 연결 대화 상자를 엽니다). 연결 대화 상자에 대한 자세한 내용은 [카메라 연결](connecting.md)에 설명되어 있으며, 어레이 개념(동기화, 계층, 대역폭)은 [다중 카메라 어레이](arrays.md)에서 확인할 수 있습니다. 카메라가 포함된 저장된 프로젝트를 열면, 시작 화면에는 대신 &quot;저장된 N대의 카메라를 다시 여는 중…&quot;이라는 로딩 아이콘이 표시되며, Chloros는 마지막 세션의 스트림을 복원합니다.

### 상단 바

| 제어 | 기능 |
| --- | --- |
| **보기 모드 전환**|**그리드 보기**(모든 타일을 셀로 표시)와**목록 보기**(상단에 전체 너비의 어레이, 하단에 활성 카메라 1대 표시) 간을 전환합니다. 툴팁: &quot;그리드 보기로 전환&quot; / &quot;목록 보기로 전환&quot;. |
| **그리드 잠금**(자물쇠) | 기본값**잠김** — 타일이 제자리에 고정됩니다. 잠금을 해제하면 타일을 드래그하여 원하는 슬롯으로 재배열할 수 있습니다(공백은 유지됨). 새로운 카메라가 연결될 때마다 그리드가 자동으로 다시 잠깁니다. 툴팁: &quot;그리드 잠금 해제 (타일 드래그 활성화)&quot; / &quot;그리드 잠금 (타일 고정)&quot;. |
| **피드 확대/축소** 슬라이더 | 타일 크기, 60px부터 컨테이너 전체 너비까지. 셀은 4:3 화면비를 유지합니다. 셀 너비가 200 픽셀 미만이면 타일을 깔끔하게 유지하기 위해 이름과 fps 오버레이가 숨겨집니다. |

### 피드 타일

각 카메라는 합성된 라이브 타일을 렌더링하며, 카메라는 추가로 세 개의 그레이스케일 **채널별 분할** 타일을 표시할 수 있습니다 ([채널 분할](#display-overlays-drawn-over-the-live-feed) 참조)을 추가로 표시할 수 있으며, 어레이는 결합된 타일을 렌더링합니다. 활성 타일에는 카메라(또는 어레이)의 색상으로 된 선택 링이 표시됩니다.

타일 위에 마우스를 올리면 **X** 닫기 버튼이 나타납니다:

* 채널 분할 타일이 남아 있는 상태에서 **합성** 타일을 닫으면 합성 타일만 숨겨집니다.
* **독립형 카메라의 마지막으로 표시된 타일**을 닫으면 해당 카메라의 연결이 해제됩니다.
* **결합 어레이 구성원의 분할 타일은 카메라 연결을 해제하지 않으며**, 단지 숨길 뿐입니다.

그리드 잠금을 해제한 상태에서 타일을 원하는 슬롯으로 드래그하면 레이아웃이 프로젝트와 함께 저장됩니다.

## 사이드바 — 카메라 목록

<!-- SCREENSHOT-NEEDED: sidebar camera list pane showing a standalone camera row and an ARRAY group with indented member rows, the DAQ on/off pill visible on the array row, plus the Connect Camera / Connect Array / Capture All buttons at the top. -->

첫 번째 사이드바 페이지에는 연결된 모든 카메라와 어레이가 나열됩니다:

* **카메라 연결**(녹색) /**어레이 연결** (파란색, 스캔 중일 때 &quot;탐지 중...&quot;이 표시됨). 연결 대화 상자가 열려 있는 동안에는 두 기능 모두 비활성화됩니다.
* **모두 캡처** (빨간색) — [캡처 설정](capture.md)에서 선택한 내보내기 유형으로 나열된 모든 카메라의 영상을 캡처합니다. 프로젝트가 열려 있어야 합니다. 자세한 내용은 [캡처 설정 및 모드](capture.md)에서 확인할 수 있습니다.
* **캡처 설정 톱니바퀴** (모두 캡처 옆) — [캡처 설정 창](capture.md#the-capture-settings-pane)을 엽니다. 프로젝트가 없거나 캡처 중에는 비활성화됩니다.

### 카메라 행

각 카메라 행에는 색상으로 구분된 테두리(카메라의 사용자 지정 색상), “CAM” 레이블 — 어레이 구성원의 경우 파란색 **M**(마스터) 또는 녹색**S**(슬레이브) 역할 문자가 표시됨 — 및 표시 이름이 나타납니다. 기본 이름은 `LATTICE-MODEL (serial)`이며, 카메라별 설정 패널에서 이름을 변경할 수 있습니다. 행 버튼:

| 버튼 | 효과 |
| --- | --- |
| **눈**| 표시/숨김 전환. 숨겨진 카메라는 그리드에서 사라지며**&#x27;모두 캡처&#x27;에서 제외**됩니다. |
| **톱니바퀴** | 카메라별 설정 패널을 엽니다(다음 섹션). |
| **일시 정지 / 재생**|**디스플레이 측에서만** 실시간 미리보기를 정지합니다 — 백엔드 캡처는 계속 실행됩니다. 일시 정지된 카메라는 캡처할 수 없습니다. |
| **X** | 연결 해제. UI는 즉시 업데이트됩니다 (낙관적 추정); 백엔드 연결 해제가 완료되는 데 10~30초가 소요될 수 있습니다. |

### 어레이 행

어레이 행에는 어레이 색상의 &quot;ARRAY&quot; 배지, 어레이 이름(어레이 설정에서 이름 변경 가능), 그리고 **DAQ · 켜기/끄기**버튼이 표시됩니다 — 어레이 수준의 광 센서가 설정되어 있거나 구성원 중 하나라도 카메라별 센서를 가지고 있을 때**on**으로 표시됩니다. 툴팁에는 어떤 센서가 어떤 카메라에 신호를 전달하는지 정확히 나열됩니다. 구성원 카메라들은 그 아래에 들여쓰기되어 별도의 행으로 나열됩니다. 배열 행 버튼:**눈**(모든 구성원을 한꺼번에 숨기거나 표시),**톱니바퀴**(배열 설정 창),**X** (전체 어레이 연결 해제).

어레이 행과 어레이 설정 패널에서 사용되는 광센서(DLS) 상태는 **off**,**waiting**(아직 스펙트럼 없음),**active**(지난 3초 이내에 스펙트럼이 도착함),**stale** — 3초 동안 새로운 스펙트럼이 없으나, 마지막 측정값은 *여전히 사용 중*입니다(DAQ 측정값은 캡처 경로에서 만료되지 않습니다).

사이드바에서 독립형 카메라와 전체 어레이 그룹을 서로 위로 드래그하여 목록의 순서를 재정렬할 수 있습니다. 어레이 구성원은 개별적으로 드래그할 수 없습니다.

## 카메라별 설정 패널

카메라 행의 **톱니바퀴** 아이콘을 클릭하여 엽니다. 이 패널은 카메라 목록 위로 미끄러지듯 나타납니다.

**헤더**: 카메라의**색상 견본**(클릭하면 기본 색상 선택기가 열립니다 — 사이드바 테두리 및 타일 선택 링 색상을 설정합니다), 연필 모양의**이름 변경**버튼이 있는**이름**(빈 이름을 저장하면 기본값인 `MODEL (serial)`로 되돌아갑니다), 그리고 닫기 버튼인**×**가 있습니다.

### 실시간 히스토그램

패널 상단에는 JPEG 미리보기 화면을 기반으로 약 8 Hz의 주파수로 계산된 실시간 루마 히스토그램이 표시됩니다. 평균값은 카메라 자체의 AE 측광과 일치하도록 베이어 가중치(R+2G+B)/4가 적용됩니다.

* **Orange 점선**= AE 목표값입니다.**수평으로 드래그하여 목표값을 재설정할 수 있습니다** — 마우스를 놓을 때 명령이 한 번 전송되며, 드래그하는 동안 AE 목표 모드가 수동 모드로 전환됩니다.
* **Green 실선** = 실제 평균 루미나(현재 AE가 산출하는 값).
* **RGB 버튼** (오른쪽 상단): 카메라 필터에 따라 색상이 지정된 밴드별 오버레이 히스토그램을 표시/비표시합니다(예: FRGN 모드에서는 회색 NIR, 녹색, 빨간색). 모노(M3M) 카메라에서는 이 버튼에 “MONO”라고 표시되며 비활성화됩니다. 모노 모드에서는 항상 단일 대역 루마 히스토그램이 표시됩니다.
* X축 레이블은 현재 픽셀 형식의 센서 비트 심도에 따라 0..255, 0..1023, 0..4095 또는 0..65535로 표시됩니다.

### 예측 자동 노출 (DLS 기반)

이 섹션은 **DAQ 광 센서가 하나 이상 연결된 경우에만** 표시됩니다. 솔버는 이를 구동하기 위해 실시간 하향 스펙트럼이 필요합니다.

<!-- SCREENSHOT-NEEDED: Predictive Auto-Exposure (DLS-driven) section with a DAQ connected — Enable checkbox, Smoothing (α) slider at 0.30, and the "Recalibrate ρ" button. -->

| 제어 | 범위 | 기본값 | 기능 |
| --- | --- | --- | --- |
| **활성화** | 체크박스 | 켜짐 (독립형 카메라) | 닫힌 형태의 솔버가 DLS 스펙트럼과 카메라의 보정 팩 스칼라를 사용하여 가장 밝은 밴드를 포화 상태에 가깝게 맞추는 동시에 가장 어두운 밴드를 SNR 하한선 이상으로 유지합니다. — 솔버 실행당 단일 노출 기록, 정착 루프 없음. 모든 샷이 올바르게 노출되어야 하는 태양광 구동 타임랩스용으로 설계되었습니다. DLS 측정값이 오래되었거나 누락되었거나, 보정 팩이 로드되지 않은 경우 백엔드는 자동으로 반응형 AE로 전환됩니다. |
| **평활화 (α)** | 0.05–1.0, 0.05 단위 | 0.3 | 연속적인 예측 해의 평활화 (값이 낮을수록 더 부드럽게 처리됨). |
| **장면 반사율**|**ρ 재보정** 버튼 | — | 솔버가 사용하는 장면 반사율 계수를 재추정합니다. |

{% hint style="info" %}
**어레이 연결 시 예측 AE는 기본적으로 비활성화됩니다** — 어레이의 경우, Chloros의 스마트 AE와 카메라 측 자동 노출 기능이 노출을 처리하며(포화 방지 기능 포함), 예측 AE의 단일 장면 반사율 추정치는 혼합된 장면에서는 안전하지 않습니다. DLS 기반 방사계 노출을 특별히 원할 경우-DLS 기반 방사계 노출을 특별히 원할 경우, 여기서 카메라별로 이 기능을 다시 활성화할 수 있습니다.
{% endhint %}

**DAQ 기반 노출 상한 및 입사광 고정 AE.**위의 체크박스와는 별개로, DAQ 광 센서가 RGB 카메라에 할당된 경우, Chloros는 측정된 절대 하향 조도 값을 바탕으로 100% 반사율 표면이 클리핑되지 않는 최대 노출×이득을 계산하여, 이를**상한선**으로 로 적용합니다. 상한값이 활성화된 동안 카메라는**입사광 고정** 모드로 작동합니다. 즉, 게인을 0 dB로 설정하고 입사광 측정 노출값에 따라 개방 루프로 작동하며, 노출은 측정된 빛의 양을 따를 뿐, 장면 내용이 아닌 측정된 빛의 양을 따릅니다. 상한값은 노출 시간을 단축시킬 수만 있을 뿐, 그 자체로 클리핑을 유발할 수는 없습니다. DAQ 측정값이 누락되거나, 오래된 값(&gt;30초)이거나, 어두운 경우, 또는 고정된 노출에서 프레임의 15% 이상이 클리핑되는 경우 (즉, 센서와 카메라가 서로 다른 조도를 감지하는 경우) 자동으로 해제되며, 일반 장면 자동 노출(AE)이 재개됩니다. 별도의 GUI 설정은 없으며, RGB 카메라에 DAQ가 연결되어 있을 때 이는 표준 동작입니다.

### 레이어 표시 *(결합된 경우에만)** **활성화** 체크박스 (기본값: 꺼짐 — 마스터 카메라가 그대로 표시됨; 켜짐 = 레이어 합성).

### 분할 보기 *(결합 모드에서만)*

**&quot;구성원 카메라 표시&quot;**—**구성원 카메라 분할/숨기기** 버튼으로, 각 구성원의 라이브 피드를 합성 화면 옆의 별도 그리드 타일로 추가합니다. 타일은 어레이의 기존 프레임 버퍼를 읽습니다(별도의 카메라 연결 불필요). 그리드 보기 전용이며, 프로젝트와 함께 어레이별로 저장됩니다.

### 기능

5초마다 갱신되는 읽기 전용 패널:

* **계층 레이블**: “동시 캡처”(녹색) · &quot;동시 캡처 (FTD-시차 전송)&quot; (녹색) · &quot;시차 캡처 (100 ms 드리프트)&quot; (주황색) · &quot;구성이 너무 큽니다&quot; (빨간색).
* **프레임 상태**: &quot;x.xx % 미완료&quot; — 1% 미만 시 녹색, 5% 미만 시 황색, 5% 이상 시 빨간색.
* **링크 라인**: &quot;NIC {mbps} Mbps - 지속 {MB/s} MB/s&quot;.

이는 어레이의 실시간 대역폭 할당량입니다. 기본 fps 및 네트워크 모델, 그리고 티어가 황색 또는 적색으로 변할 때 변경해야 할 사항에 대해서는 [다중 카메라 어레이](arrays.md) 및 [CLI 참조](../reference/cli-reference.md)를 참조하십시오.

## 카메라별 설정 대 어레이 관리 설정

카메라가 어레이 구성원일 때 각 설정의 위치에 대한 빠른 참조:

| 어레이 관리 (카메라 창에서 읽기 전용) | 어레이 내에서도 여전히 카메라별 |
| --- | --- |
| 픽셀 형식, 해상도, 비닝 | 자동 노출(노출, 게인, 목표값, 스무딩, ROI) |
| 트리거 모드/소스, 프레임 속도 | 노이즈 제거, 선명도, 비네팅 |
| | 방향(미러/회전), 디스플레이 오버레이, 스팟 미터 |
| | 인덱스(별도 디스플레이 어레이), 광센서 바인딩 |

기타 전반에 걸친 동작:

* **통합 디스플레이 대 개별 디스플레이**는 어레이 연결 시 선택됩니다: 통합 = 정렬된 하나의 합성 타일 (구성원 피드는 Split View를 통해서만 전송됨); 개별 = 각 구성원이 자체적으로 동기화된 타일을 렌더링합니다. 어떤 카메라도 독립형 피드와 어레이 타일을 동시에 표시하지 않습니다.
* **자동 재연결**: 저장된 프로젝트를 열면 카메라와 어레이가 복원되며, 스트림이 재개되기 전에 저장된 모든 설정이 백엔드에 다시 적용됩니다.
* **캡처 게팅**: 숨겨지거나 일시 중지된 카메라는 ‘모두 캡처(Capture All)’에서 제외됩니다. 어레이는 모든 구성원이 숨겨지거나 일시 중지된 경우에만 완전히 차단됩니다. [캡처 설정 및 모드](capture.md)를 참조하십시오.

## 설정 유지 방식

카메라 탭의 상태는 브라우저가 아닌 **프로젝트와 함께** 저장됩니다:

* 반응형 변경이 발생할 때마다 카메라와 어레이의 상태가 프로젝트의 `cameras.json`에 스냅샷으로 저장됩니다(500ms 간격으로 중복 처리 제거). 여기에는 카메라 이름 및 색상, 노출/게인/AE 설정, 픽셀 형식/해상도/비닝, 트리거 속도, 미리보기 설정 (렌더 해상도, 노이즈 제거, 선명도, 비네팅, 색상 프로필, 채도/대비), 방향, 오버레이, 채널 분할, 인덱스 구성, 예측 AE 설정, AE ROI, 어레이 이름, 디스플레이 모드, 어레이 캡처 설정(ROI 자르기 위치 포함), 그리드 블록(피드 줌, 뷰 모드, 그리드 잠금, 수동 타일 순서, 숨겨진 카메라, 닫힌 타일, 활성 카메라)을 포함합니다.
* 광센서 바인딩 정보는 프로젝트의 `sensors.json` 파일에 저장됩니다.
* 프로젝트를 다시 열면 하드웨어가 재연결되고 모든 설정이 다시 적용됩니다.
* **프로젝트 미열람 = 세션 전용**: 프로젝트가 없는 경우, Chloros를 닫으면 어떤 설정도 유지되지 않습니다.
* 프로젝트와 관계없이 세션 전용: 일시 정지 상태, 스팟 미터 샘플, 카메라별 보정 대상(Calibration Target) 확인란(항상 비활성화 상태로 열림), 및 어레이 정렬 프로필 (설계상 세션마다 재계산됨)은 세션 전용입니다.
* 단 한 가지 예외: **캡처 설정** 내 내보내기 선택 사항과 캡처 모드는 `cameras.json`가 아닌 로컬 앱 저장소에 프로젝트별로 유지됩니다 — [캡처 설정 및 모드](capture.md)를 참조하십시오.</array></camera></serial>
