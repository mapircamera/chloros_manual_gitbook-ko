# 카메라 설정

**카메라** 탭은 Chloros의 LATTICE 카메라용 라이브 제어 화면입니다. 여기에는 연결된 모든 카메라를 라이브 타일로 표시하는 메인 피드 영역과, **카메라 목록**,**설정 패널**(카메라별, 어레이 또는 캡처 설정 — 한 번에 하나씩) 및**인덱스 계산기**로 구성됩니다. 이 페이지에서는 카메라 목록, 카메라별 설정 패널 및 어레이 설정 패널에 있는 모든 제어 기능을 설명합니다. 캡처 모드, 내보내기 유형 선택, ‘모두 캡처(Capture All)’ 흐름에 대한 내용은 관련 페이지 [캡처 설정 및 모드](capture.md)에서 확인할 수 있습니다.

Chloros 백엔드가 준비되면 사이드바에 ‘카메라’ 탭이 표시됩니다. 아래의 모든 제어 기능은 `127.0.0.1:5000`를 통해 로컬 백엔드와 통신하며, 별도로 명시되지 않는 한 변경 사항은 라이브 카메라에 즉시 적용됩니다.

## 이 페이지에서 사용되는 카메라 유형

제어 요소는 선택된 카메라의 종류에 따라 표시되거나 숨겨집니다. 이 설명서에서는 다음과 같은 용어를 일관되게 사용합니다:

| 용어 | 의미 | 필터 채널 |
| --- | --- | --- |
| **RGB 카메라** | FRGB 필터가 장착된 LATTICE M3C (모델명에 `-FRGB` 포함) | Red / Green / Blue |
| **바이엘 다중 스펙트럼** | FRGN, FOCN 또는 FNGB가 장착된 LATTICE M3C | FRGN: Red / Green / NIR · FOCN: Orange / Cyan / NIR · FNGB: NIR / Green / Blue |
| **모노 (M3M)** | LATTICE M3M — 협대역 필터 1개, 보정된 대역 1개 | 단일 대역 |
| **어레이 구성원** | 동기화된 어레이의 일부로 연결된 카메라(통합 또는 별도 표시) | 해당 필터 기준 |

RGB 카메라는 광도계 처리(화이트 밸런스, 색상 프로파일, 감마)를 거치며, 다중 스펙트럼 및 모노 카메라는 방사계 처리를 거치고 광도계 제어 단계는 건너뜁니다. 어레이 구성원은 스트림 수준 설정(픽셀 형식, 해상도, 비닝, 트리거, 프레임 속도)를 어레이에 위임합니다. 해당 행들은 카메라별 패널에서 읽기 전용으로 전환되며, 대신 어레이 설정 패널로 이동합니다.

## 메인 피드 영역



<!-- SCREENSHOT-NEEDED: Cameras tab with 2+ cameras connected in grid view — live tiles visible with name and fps overlays, sidebar camera list open on the right. -->

연결된 카메라가 없는 경우, 피드 영역에는 **"카메라를 연결하여 시작하세요"**라는 시작 화면과 두 개의 버튼이 표시됩니다:**카메라 연결**(녹색, 단일 카메라 연결 대화 상자 열기)와**어레이 연결** (파란색, 어레이 연결 대화 상자 열기)입니다. 연결 대화 상자에 대한 설명은 [카메라 연결](connecting.md)에서, 어레이 개념(동기화, 계층, 대역폭)에 대한 설명은 [다중 카메라 어레이](arrays.md)에서 설명합니다. 카메라가 포함된 저장된 프로젝트를 열면, Chloros가 마지막 세션의 스트림을 복원하는 동안 시작 화면에는 대신 "N개의 저장된 카메라를 다시 열고 있습니다…"라는 메시지와 함께 로딩 아이콘이 표시됩니다.

### 상단 바

| 제어 | 기능 |
| --- | --- |
| **보기 모드 전환**|**그리드 보기**(모든 타일을 셀로 표시)와**목록 보기**(전체 너비 행: 각 결합된 어레이를 하나의 복합 행으로,**별도의** 어레이 구성원은 각각 자체 피드와 보정 대상 표가 있는 행으로 표시한 뒤, 그 아래에 하나의 독립형 카메라(활성 카메라)를 표시) 간을 전환합니다. 도구 설명: "그리드 보기로 전환" / "목록 보기로 전환". |
| **그리드 잠금**(자물쇠) | 기본적으로**잠김** 상태 — 타일이 제자리에 고정됩니다. 잠금을 해제하면 타일을 드래그하여 원하는 슬롯으로 재배열할 수 있습니다(간격은 유지됨). 새로운 카메라가 연결될 때마다 그리드가 자동으로 다시 잠깁니다. 툴팁: "그리드 잠금 해제 (타일 드래그 활성화)" / "그리드 잠금 (타일 고정)". |
| **피드 확대/축소** 슬라이더 | 타일 크기, 60 픽셀부터 컨테이너 전체 너비까지. 셀은 4:3 화면비를 유지합니다. 셀 너비가 200px 미만이면 타일을 깔끔하게 유지하기 위해 이름과 fps 오버레이가 숨겨집니다. |

### 피드 타일

각 카메라는 합성된 라이브 타일을 렌더링하며, 카메라는 추가로 세 개의 그레이스케일 **채널별 분할** 타일을 표시할 수 있습니다([채널 분할](#display-overlays-drawn-over-the-live-feed)를 추가로 표시할 수 있으며, 어레이는 결합된 타일을 렌더링합니다. 활성 타일에는 카메라(또는 어레이)의 색상으로 된 선택 링이 표시됩니다.

타일 위에 마우스를 올리면 **X** 닫기 버튼이 나타납니다:

* 채널 분할 타일이 남아 있는 상태에서 **합성** 타일을 닫으면 합성 타일만 숨겨집니다.
* **단독 카메라의 마지막으로 표시된 타일**을 닫으면 해당 카메라의 연결이 끊어집니다.
* **결합 어레이 구성원 분할 타일은 카메라 연결을 끊지 않으며**, 단지 숨길 뿐입니다.

그리드 잠금이 해제된 상태에서 타일을 원하는 슬롯으로 드래그하면 레이아웃이 프로젝트와 함께 저장됩니다.

## 사이드바 — 카메라 목록

<!-- SCREENSHOT-NEEDED: sidebar camera list pane showing a standalone camera row and an ARRAY group with indented member rows, the DAQ on/off pill visible on the array row, plus the Connect Camera / Connect Array / Capture All buttons at the top. -->

첫 번째 사이드바 페이지에는 연결된 모든 카메라와 어레이가 나열됩니다:

* **카메라 연결**(녹색) /**어레이 연결** (파란색, 스캔 중일 때 "탐지 중..." 표시). 연결 대화 상자가 열려 있는 동안에는 둘 다 비활성화됩니다.
* **모두 캡처** (빨간색) — 캡처 설정에서 선택한 내보내기 유형으로 나열된 모든 카메라를 캡처합니다. 프로젝트가 열려 있어야 합니다. 자세한 내용은 [캡처 설정 및 모드](capture.md)에서 확인할 수 있습니다.
* **캡처 설정 톱니바퀴** (모두 캡처 옆) — [캡처 설정 패널](capture.md#the-capture-settings-pane)를 엽니다. 프로젝트가 없거나 캡처 중에는 비활성화됩니다.

### 카메라 행

각 카메라 행에는 색상으로 구분된 테두리(카메라의 사용자 지정 색상), "CAM" 레이블 — 배열 구성원에 대해 파란색 **M**(마스터) 또는 녹색**S** (슬레이브) 역할 문자가 표시된 “CAM” 레이블 — 및 표시명이 표시됩니다. 기본 이름은 `LATTICE-MODEL (serial)`이며, 카메라별 설정 패널에서 이름을 변경할 수 있습니다. 행 버튼:

| 버튼 | 효과 |
| --- | --- |
| **눈**| 표시/숨김 전환. 숨겨진 카메라는 그리드에서 사라지며**'모두 캡처'에서 제외**됩니다. |
| **기어** | 카메라별 설정 패널을 엽니다(다음 섹션). |
| **일시 정지 / 재생**|**화면 측에서만** 라이브 미리보기를 정지합니다 — 백엔드 캡처는 계속 실행됩니다. 일시 정지된 카메라는 캡처할 수 없습니다. |
| **X** | 연결 해제. UI는 즉시 업데이트됩니다(최상의 경우); 백엔드 연결 해제 자체는 완료되는 데 10~30초가 소요될 수 있습니다. |

### 어레이 행

어레이 행에는 어레이 색상의 "ARRAY" 배지, 어레이 이름(어레이 설정에서 이름 변경 가능), 그리고 **DAQ · 켜기/끄기**버튼이 표시됩니다. 어레이 수준의 광 센서가 설정되어 있거나 구성원 중 하나라도 카메라별 센서를 가지고 있을 때**켜짐**상태가 됩니다; 툴팁에는 어떤 센서가 어떤 카메라에 신호를 제공하는지 정확히 나열됩니다. 구성원 카메라는 그 아래에 들여쓰기되어 별도의 행으로 나열됩니다. 어레이 행 버튼:**눈**(모든 구성원을 한꺼번에 숨기거나 표시),**톱니바퀴**(어레이 설정 창),**X** (전체 어레이 연결 해제).

어레이 행과 어레이 설정 창에서 사용되는 광센서(DLS) 상태는 **off**,**대기 중**(아직 스펙트럼 없음),**활성**(지난 3초 이내에 스펙트럼 수신됨),**유효 기간 만료** — 3초 동안 새로운 스펙트럼이 없으나, 마지막 측정값은 *여전히 사용됨* (캡처 경로에서는 DAQ 측정값이 만료되지 않습니다).

정렬 순서를 변경하기 전까지 목록은 먼저 어레이를 표시하고, 그 다음 독립형 카메라를 표시하며, 카메라(및 각 어레이의 구성원)는 **카메라 순서**대로 나열됩니다: M3C(바이어)가 M3M(모노)보다 먼저 표시되며, M3C 내에서는 FRGB, FRGN, FOCN, FNGB 순으로, M3M은 필터 파장 순서대로, 가장 낮은 파장부터 먼저 표시됩니다. 그리드의 기본 레이아웃도 동일한 순서를 따릅니다. 사이드바에서 독립형 카메라와 전체 어레이 그룹을 서로 위로 드래그하여 목록의 순서를 재정렬할 수 있습니다. 어레이 구성 요소는 개별적으로 드래그할 수 없습니다.

## 카메라별 설정 패널

카메라 행의 **톱니바퀴** 아이콘을 클릭하여 엽니다. 패널이 카메라 목록 위로 미끄러지듯 나타납니다.

**헤더**: 카메라의**색상 견본**(클릭하면 기본 색상 선택기가 열립니다 — 사이드바 테두리 및 타일 선택 링 색상을 설정함), 연필 모양의**이름 변경**버튼이 있는**이름**(빈 이름을 저장하면 기본값인 `MODEL (serial)`로 되돌아가며), 그리고 닫기 버튼인**×**.

### 실시간 히스토그램

패널 상단에는 약 8Hz의 주파수로 JPEG 미리보기에서 계산된 실시간 루마 히스토그램이 표시됩니다. 평균값은 카메라 자체의 AE 측광과 일치하도록 베이어 가중치(R+2G+B)/4가 적용됩니다.

* **주황색(Orange) 점선**= AE 목표값.**수평으로 드래그하여 목표값을 재설정**할 수 있습니다. 마우스를 놓으면 명령이 한 번 전송되며, 드래그하는 동안 AE 목표 모드가 수동(Manual)으로 전환됩니다.
* **초록색(Green) 실선** = 실제 평균 루마(현재 AE가 산출하는 값).
* **RGB 버튼** (오른쪽 상단): 카메라 필터에 따라 색상이 지정된 밴드별 오버레이 히스토그램을 표시/숨김합니다(예: FRGN 모드에서: 회색 NIR, 녹색, 빨간색). 모노(M3M) 카메라에서는 버튼에 "MONO"라고 표시되며 비활성화됩니다. 모노 모드에서는 항상 단일 밴드 루미나 히스토그램이 표시됩니다.
* X축 레이블은 현재 픽셀 포맷의 센서 비트 심도에 따라 달라집니다: 0..255, 0..1023, 0..4095 또는 0..65535.

| **보정 타겟** 체크박스 | 라이브 피드(목록 보기) 하단에 패널별 NDVI 검증 테이블을 표시하여 ArUco 반사율 대상 감지를 활성화합니다 — [보정 대상 테이블](#the-calibration-target-table)를 참조하십시오. 세션 전용 — 항상 비활성화된 상태로 열립니다. |

#### 보정 타겟 테이블

이 테이블은 **검증용 판독값 전용**입니다("검증 전용 — 보정값 수정 불가"). 헤더에는 카메라 일련번호, 필터, 타겟 번호 및 픽셀 단위의 마커 크기가 표시되며, 패널당 한 행씩 구성됩니다:

* **패널**, 그 다음 각 대역별로 한 열씩 패널의 값이 표시됩니다. 베이어(Bayer) 카메라는 세 가지 대역을 이름과 파장(예: FRGN: Red 660 nm / Green 550 nm / NIR 850 nm); **모노(M3M) 카메라는 단일 밴드**를 표시하며(예: `F750`), NDVI 열이 없습니다.
* **Sat** — 포화 상태인 패널 픽셀의 비율(1%부터 황색, 5%부터 적색).
* **NDVI Meas**,**NDVI Theo**(패널의 기준 반사율 NDVI) 및 **Δ**— 베이어 다중 스펙트럼 카메라에만 해당합니다. “NDVI Meas” 뒤의 작은 표시는 측정된 NDVI가 무엇으로 계산되었는지를 나타냅니다:**ρ**(반사율 — 광 센서 측정값이 있음),**L**(복사도 — 광센서 측정값 없음) 또는**DN**(카메라 원시 값)입니다.**ρ** NDVI만이 NDVI Theo와 비교 가능합니다. L 및 DN의 경우 Δ 열이 회색으로 표시되며, 이에 대한 설명이 다음과 같이 표시됩니다 ("광 센서 측정값 없음: NDVI는 복사도에서 산출되었으므로 Δ는 보정 확인이 아닙니다" / "NDVI는 카메라 원시 값에서 산출되었으므로 Δ는 보정 확인이 아닙니다"). ρ의 경우, Δ는 0.02 미만이면 녹색, 0.05 미만이면 주황색, 그 외에는 빨간색으로 표시됩니다.

{% hint style="info" %}
**바이엘 다중 스펙트럼 카메라(RGN / OCN / NGB)의 조도 요구 사항:** 세 채널 모두에 충분한 빛이 있어야만 보정이 올바르게 작동합니다 — 단일 센서 노출로 세 가지 스펙트럼을 모두 커버합니다. DAQ 광 센서를 사용하여 조도를 측정하거나, 각 대역이 별도의 노출을 받도록 올-모노(M3M) 모드를 사용하십시오. 캡처 시 이 조건을 위반하면, Chloros가 이를 감지하여 경고합니다(언믹스 클램프 알림). 실시간 화면에서, 채널 분할 타일은 해당 밴드의 픽셀 중 25% 이상에서 언믹스 클램핑이 발생한 경우 **"신뢰도 낮은 밴드 데이터 · N%"**를 표시합니다.
{% endhint %}

{% hint style="info" %}
**자동 노출이 노출 시간과 게인을 어떻게 할당하는지 (1.3.0).** 게인을 ‘자동’으로 설정하면, Chloros는 노출이 허용되는 최대 값(AE 상한, 어레이의 트리거 주기 또는 DAQ 노출 상한)에 도달할 때까지 게인을 0 dB로 유지하며, 그 후에야 게인이 상승합니다. 어레이에서는 트리거 빈도가 우선시됩니다: 자동 노출은 해당 빈도가 제공하는 주기를 채운, 그 후에 게인을 높입니다. 따라서 장면이 어두워져도 더 이상 자동 트리거 속도가 낮아지지 않습니다(1.2.0 버전에서는 낮아졌습니다). 어레이 구성원 중 하나에서 트리거 주기보다 긴 **수동**노출을 설정하면, 어레이의 트리거 속도가 이에 맞춰 느려집니다; 트igger 속도를 늦췄던 모든 구성 요소가 다시 자동 노출로 전환되면 자동 트리거 속도가 복원됩니다.**노출**과**AE 목표 밝기**가 모두 '자동'으로 설정되어 있고 DAQ 광 센서가 측정값을 제공하는 경우, 측정된 빛의 양이 약 ±25% 범위 내에 머무르는 한 자동 노출이 안정화된 후 각 카메라의 노출은 유지됩니다; 더 크고 지속적인 광도 변화, 설정 재시작(예: ROI 변경) 또는 사용자가 직접 노출을 변경하면 자동 노출이 다시 활성화됩니다.
{% endhint %}

{% hint style="info" %}
**자동 노출의 작동 방식 (1.3.0).**

* 수동 노출을 설정해도 게인을 변경할 때까지 게인은 자동 상태로 유지됩니다.
* 작은 하이라이트는 장면을 어둡게 만들지 않습니다. 프레임의 최대 1%에 해당하는 스페큘러 반사는 무시되며, 알려진 보정 타겟의 패널에서는 패널 면적의 최대 0.5%까지 무시됩니다.
* DAQ 노출 상한은 보정 타겟이 화면에 표시되는 동안에만 적용됩니다. 패널이 보이지 않을 경우, 카메라는 장면에 맞춰 노출을 설정합니다.
* 일정한 조명 조건에서는 노출이 안정적으로 유지되며, 큰 변화가 발생하더라도 몇 초 이내에 안정화됩니다. 클리핑이 더 이상 노출을 영구적으로 제한하지 않으며, 관심 영역(ROI)이 변경되어도 노출이 다시 설정됩니다.
* 밝기 목표값은 카메라의범위를 벗어나지 않으므로, 빛이 다시 돌아와도 프레임에 플레어가 발생하지 않습니다.
* 밝은 햇빛 아래에서 자동 노출이 반응하지 않는 카메라는, 광 센서가 감지한 현재 조도 수준(광 센서가 연결되지 않은 경우 카메라 자체 프레임으로 측정)을 유지하다가, 조명이 변하면 해당 설정을 해제합니다. 빛 센서가 어두워지거나 가려져도 이 과정에는 영향을 미치지 않습니다.
{% endhint %}

**색상 프로파일 의미론** (RGB 카메라):

* **Raw** — 처리 체인을 완전히 우회합니다.
* **선형** — 다크 신호 + 플랫 필드 + 화이트 밸런스; 색상 행렬 및 감마 적용 없음.
* **내추럴** *(기본값)* — 리니어에 측정된 색 보정 행렬과 장면에 적응하는 톤 커브가 추가됩니다.
* **강화**— 내추럴에 비브런스 및 CLAHE 국소 대비가 추가됩니다. 추가 처리 비용은**라이브 미리보기에서만** 적용되며, 저장된 캡처 파일은 프로파일과 관계없이 항상 완전한 마무리 처리가 적용됩니다.
* **사용자 지정 색온도** — ‘자연’ 모드에 화이트 밸런스를 사용자가 선택한 켈빈 값으로 고정합니다.

{% hint style="warning" %}
'자연', '향상', '사용자 지정 색온도'의 경우, 패널에 톤 관련 참고 사항이 표시됩니다: 프레임은 각 장면의 특성에 따라 밝기가 조정되므로, 저장된 *디스플레이* 이미지는 프레임 간 비교가 불가능합니다. **측정을 위해 방사도 또는 반사도를 내보내십시오.**
{% endhint %}

### 예측 자동 노출(DLS 기반)

이 섹션은 **DAQ 광 센서가 하나 이상 연결된 경우**에만 표시됩니다. 솔버는 이를 구동하기 위해 실시간 하향 스펙트럼이 필요합니다.

<!-- SCREENSHOT-NEEDED: Predictive Auto-Exposure (DLS-driven) section with a DAQ connected — Enable checkbox, Smoothing (α) slider at 0.30, and the "Recalibrate ρ" button. -->



| 제어 | 범위 | 기본값 | 기능 |
| --- | --- | --- | --- |
| **활성화** | 체크박스 | 켜짐 (독립형 카메라) | 닫힌 형태의 솔버는 DLS 스펙트럼과 카메라의 보정 팩 스칼라를 사용하여 가장 어두운 밴드를 SNR 하한선 이상으로 유지하면서 가장 밝은 밴드가 포화 상태에 가까워지도록 조정합니다 — 솔버 실행당 단일 노출 기록, 안정화 루프 없음. 모든 샷이 올바르게 노출되어야 하는 태양광 구동 타임랩스용으로 설계되었습니다. DLS 측정값이 오래되었거나 누락되었거나 보정 팩이 로드되지 않은 경우, 백엔드는 자동으로 반응형 AE로 전환됩니다. |
| **평활화 (α)** | 0.05–1.0, 단계 0.05 | 0.3 | 연속적인 예측 해의 평활화 (값이 낮을수록 더 부드럽게 처리됨). |
| **장면 반사율**|**ρ 재보정** 버튼 | — | 솔버가 사용하는 장면 반사율 계수를 재추정합니다. |

{% hint style="info" %}
**어레이 연결 시 예측 AE는 기본적으로 비활성화됩니다** — 어레이의 경우, Chloros의 스마트 AE와 카메라 측 자동 노출 기능이 노출을 처리하며(포화 방지 기능 포함), 예측 AE의 단일 장면반사율 추정치는 혼합된 장면에서는 안전하지 않습니다. DLS 기반 방사계 노출을 특별히 원할 경우, 여기서 카메라별로 이 기능을 다시 활성화할 수 있습니다.
{% endhint %}

**DAQ 기반 노출 상한 및 입사광 고정 AE.** 위의 체크박스와는 별개로, DAQ 광 센서가 RGB 카메라에 할당된 경우, Chloros는 측정된 절대 하향 조도 값을 바탕으로 100% 반사율 표면이 클리핑되지 않는 최대 노출×이득을 계산하여, 이를 자동 노출의 **상한선**으로 적용합니다. 1.3.0 버전부터는 이 상한선이 해당 카메라의 시야 내에 보정 타겟이 있는 동안(지난 10초 이내에 프레임에 포착된 경우)에만 적용되며; 시야에 타겟이 없을 때는 카메라 고유의 하이라이트 보호 기능을 갖춘 일반적인 자동 노출이 대신 작동하므로, 장면의 나머지 부분이 필요 이상으로 어둡게 유지되지 않습니다. 상한값이 활성화된 동안 카메라는**입사광 고정** 상태로 작동합니다: 게인을 0 dB로 설정하고 입사광 측정 노출값에 따라 개방 루프 방식으로 작동하며, 노출은 장면의 내용이 아닌 측정된 빛의 양을 따릅니다. 상한값은 노출 시간을 단축시킬 수만 있을 뿐, 그 자체로는 클리핑을 유발할 수 없습니다. 버전 1.3.0부터는 천장값이 카메라의 보정 팩에 포함된 카메라 고유의 노출 상수를 사용하여 계산됩니다(팩에 해당 값이 포함되지 않은 경우에만 함대 평균값이 사용됨). 보정 대상이 화면에 보이지 않거나, DAQ 판독값이 누락되었거나, 오래된 (>30초)이거나, 어두운 경우, 또는 고정된 노출에서 프레임의 15% 이상이 클리핑되는 경우(센서와 카메라가 서로 다른 조도를 감지하고 있음을 의미)에는 천장 기능이 자동으로 해제되며 일반 장면 자동 노출(AE)이 재개됩니다. 별도의 GUI 스위치는 없으며, 이는 RGB 카메라에 DAQ가 바인딩되어 있을 때의 표준 동작입니다.

#### ROI 편집기

1.3.0 버전에서 새로 추가되었습니다. ROI 자르기 행과 그 아래의 맵은 함께 작동합니다:

* **ROI 켜기 / ROI 끄기**— 센서 자르기 기능을**즉시**켜거나 끕니다(카메라가 잠시 재시작되며, 어레이 타일에는 "설정 적용 중…"이 표시됩니다).**끄기**는 전체 센서 데이터를 읽으며**자르기 설정을 기억**합니다 — 입력란에 계속 표시됩니다;**켜기**는 설정을 다시 적용합니다. 자르기 설정이 없는 상태에서 ROI를 켜면 중앙에 위치한 절반 크기의 자르기가 적용됩니다("자르기 설정이 없으므로 중앙에 위치한 절반 크기의 자르기가 적용되었습니다. 입력란을 통해 조정하십시오.").
* **선택**— 지도에 크롭 영역을 그립니다: 영역을 가로질러 드래그하거나, 대각선으로 마주보는 두 모서리를 클릭하세요(Esc 키로 취소). 사각형은 W/H/X/Y 필드에 표시되며, 위의 단계에 맞춰 정렬됩니다.**적용**을 누르기 전까지는 아무것도 적용되지 않으므로, 먼저 필드 화살표를 사용하여 미세 조정할 수 있습니다.**선택**을 누를 때마다 하나의 사각형이 생성됩니다.
* **지도**는 전체 센서 상의 크롭 영역을 표시하므로, 이를 다시 넓힐 수 있습니다: 카메라가 전체 센서를 읽는 동안 “전체 센서, 라이브”, 또는 "{시간} 시점의 풀프레임 스냅샷. 카메라가 크롭된 영역만 읽음."으로 표시됩니다. 어레이가 크롭된 데이터만 스트리밍한 적이 있다면, 맵에는 "아직 풀프레임 뷰 없음: 이 어레이는 크롭된 데이터만 스트리밍했습니다."라고 표시되며,**전체 프레임 표시** 버튼을 통해 ROI를 해제할 수 있습니다. 크롭 영역의 `W×H @ X,Y` 레이블은 지도와 라이브 타일에서 상자 바깥쪽(상자 위쪽, 또는 상자가 상단과 닿을 경우 아래쪽)에 위치합니다.
* **적용**을 누르면 필드 설정이 확정됩니다: 크롭은 ROI를 켭니다; 풀 프레임(**재설정** 후)은 ROI를 끈 상태로 유지하며 이전 크롭 정보는 그대로 기억됩니다; ROI가 꺼져 있고 필드에 기억된 크롭이 여전히 표시되는 경우, 다른 변경 사항(포맷, 비닝, 속도)을 적용해도 ROI는 꺼진 상태로 유지됩니다.
* **정렬된 어레이의 경우, 각 구성원의 크롭 창은 정렬에 따라 배치되므로** 모든 카메라가 장면의 동일한 영역을 프레임에 담습니다. 정렬되기 전에 크롭된 어레이는 먼저 전체 센서 기준으로 정렬됩니다(크롭이 해제되고, 정렬이 해결된 후, 카메라별 창을 적용하여 크롭이 복원됨).
* 크롭 변경 후, 자동 노출은 새로운 프레임에 맞춰 재조정됩니다. 크롭이 적용된 상태에서도 구성원의 노출은 트리거 기간까지 계속 실행될 수 있습니다.
* ROI 활성화/비활성화 상태와 저장된 크롭 정보는 프로젝트와 함께 저장됩니다.

### 라이브 미리보기

* **히스토그램**확인란 + 너비 슬라이더(프레임의 0.10–0.90) — 모든 멤버의 타일(채널 분할 타일 포함)에 피드에 표시되는 히스토그램 스트립을 한 번에 표시하며, 전체 어레이에 대해 설정된 카메라별 [히스토그램 오버레이](#display-overlays-drawn-over-the-live-feed)가 전체 어레이에 대해 설정됩니다. 모든 멤버에 이미 이 기능이 적용된 경우 활성화 상태로 표시됩니다.**별도의** 어레이에서는 이 그룹에 이 행만 표시됩니다.
* *결합된 어레이에만 해당:* **인덱스**: 활성화 체크박스 + 톱니바퀴 —**모든** 구성원 카메라에서 추출된 밴드가 표시된 공유 [인덱스 계산기](#index-calculator-pane)를 엽니다. 하단의 표현식 미리보기 줄에는 현재 표현식("표현식 설정되지 않음 — 계산기를 열어 작성하세요")이 표시되며, 매초마다 갱신됩니다.
* *결합 모드 전용:* **렌더링 해상도**드롭다운(카메라별 설정과 동일한 사전 설정, 기본값 720p): 라이브 뷰 스트림의 높이**및** 저장된 합성 출력 크기. 패널 내 참고 사항: "미리보기 + 저장된 합성 크기. 카메라별 이미지는 항상 전체 해상도로 내보내집니다."

### 디스플레이 레이어 *(결합 모드에서만)** **활성화** 확인란 (기본값: 비활성화 — 마스터 카메라가 그대로 표시됨; 활성화 = 레이어드 합성).
* **전경**/**배경**드롭다운: 각 구성원 카메라(이름별) 또는**인덱스**. 전경이 인덱스로 설정된 경우, LUT 최소/최대 범위를 벗어난 픽셀 영역에는 배경 레이어가 표시됩니다.

### 분할 보기 *(결합 모드에서만)*

**"구성원 카메라 표시"**—**구성원 카메라 분할/숨기기** 버튼으로, 각 구성원의 라이브 피드를 합성 화면 옆의 별도 그리드 타일로 추가합니다. 타일은 어레이의 기존 프레임 버퍼를 읽습니다(별도의 카메라 연결 불필요). 그리드 보기 전용이며, 프로젝트와 함께 어레이별로 저장됩니다.

### 기능

5초마다 갱신되는 읽기 전용 패널:

* **계층 레이블**: "동시 캡처" (녹색) · "동시 캡처 (FTD-시차 방출)" (녹색) · "시차 캡처 (100 ms 드리프트)" (황색) · "구성이 너무 큼" (빨간색).
* **프레임 상태**: "x.xx % 미완료" — 1% 미만 시 녹색, 5% 미만 시 주황색, 5% 이상 시 빨간색.
* **링크 라인**: "NIC {mbps} Mbps - 지속 {MB/s} MB/s".

이는 어레이의 실시간 대역폭 할당량입니다. 기본 fps 및 네트워크 모델에 대한 정보와, 티어가 황색 또는 적색으로 변할 때 변경해야 할 사항에 대해서는 [다중 카메라 어레이](arrays.md) 및 [CLI 참조](../reference/cli-reference.md)를 참조하십시오.

## 카메라별 설정 대 어레이 관리 설정

카메라가 어레이 구성원일 때 각 설정이 어디에 위치하는지에 대한 빠른 참조:

| 어레이 관리 (카메라 패널에서 읽기 전용) | 어레이 내에서도 여전히 카메라별 |
| --- | --- |
| 픽셀 형식, 해상도, 비닝 | 자동 노출(노출, 게인, 목표값, 스무딩, ROI) |
| 트리거 모드/소스, 프레임 속도 | 노이즈 제거, 선명도, 비네팅 |
| | 방향(미러/회전), 디스플레이 오버레이(어레이 설정 → 라이브 미리보기에서 모든 구성원의 히스토그램을 한 번에 설정), 스팟 미터 |
| | 인덱스(별도 디스플레이 어레이), 광센서 바인딩 |

기타 전반에 걸친 동작:

* **통합 표시 대 개별 표시**는 어레이 연결 시 선택됩니다: 통합 = 정렬된 하나의 합성 타일(멤버 피드는 분할 보기(Split View)를 통해서만 제공됨); 개별 = 각 멤버가 자체적으로 동기화된 타일을 렌더링합니다. 카메라는 독립형 피드와 어레이 타일을 동시에 표시하지 않습니다.
* **자동 재연결**: 저장된 프로젝트를 열면 카메라와 어레이가 복원되며, 스트림이 재개되기 전에 저장된 모든 설정이 백엔드에 다시 적용됩니다.
* **캡처 게이트**: 숨겨지거나 일시 중지된 카메라는 ‘모두 캡처(Capture All)’에서 제외됩니다. 어레이는 모든 구성원이 숨겨지거나 일시 중지된 경우에만 완전히 차단됩니다. [캡처 설정 및 모드](capture.md)를 참조하십시오.

## 설정 유지 방식

카메라 탭의 상태는 브라우저가 아닌 **프로젝트와 함께** 저장됩니다:

* 반응형 변경이 발생할 때마다 카메라와 어레이의 상태가 프로젝트의 `cameras.json`(500ms 디바운스)에 스냅샷으로 저장됩니다. 여기에는 카메라 이름 및 색상, 노출/게인/AE 설정, 픽셀 형식/해상도/비닝, 트리거 속도, 미리보기 설정(렌더링 해상도, 노이즈 제거, 선명도, 비네팅, 색상 프로필, 하이라이트, 채도/대비), 방향, 오버레이, 채널 분할, 인덱스 구성, 예측 AE 설정, AE ROI, 어레이 이름, 디스플레이 모드, 어레이 캡처 설정(ROI 자르기, ROI 활성화 여부, 비활성화 시 기억된 자르기 포함), 어레이의 와이어 예산, 그리드 블록(피드 줌, 뷰 모드, 그리드 잠금, 수동 타일 순서, 숨겨진 카메라, 닫힌 타일, 활성 카메라).
* 광센서 바인딩은 프로젝트의 `sensors.json` 파일에 저장됩니다.
* 프로젝트를 다시 열면 하드웨어가 재연결되고 모든 설정이 다시 적용됩니다.
* **프로젝트 미열람 = 세션 전용**: 프로젝트가 없는 경우, Chloros를 종료하면 어떤 설정도 유지되지 않습니다.
* 프로젝트와 관계없이 세션 전용: 일시 정지 상태, 스팟 미터 샘플, 카메라별 보정 대상(Calibration Target) 확인란(항상 비활성화 상태로 열림), 배열 정렬 프로필(설계상 세션마다 재계산됨).
* 단 한 가지 예외: **캡처 설정** 내 내보내기 선택 항목과 캡처 모드는 `cameras.json`가 아닌 로컬 앱 저장소에 프로젝트별로 유지됩니다 — [캡처 설정 및 모드](capture.md)를 참조하십시오.</array></camera></serial>
