# LATTICE 카메라

LATTICE는 농업 및 과학 영상 촬영을 위한 MAPIR의 모듈형 다중 스펙트럼 카메라 시스템입니다. 모든 LATTICE 카메라는 Sony IMX265 글로벌 셔터 센서(**

3.1 MP, 3.45 µm 픽셀**)를 기반으로 제작되었으며,**GigE Vision** 장치로 이더넷을 통해 연결됩니다.

Chloros 1.3.0은 다음 세 가지 인터페이스를 통해 LATTICE 카메라를 실시간으로 제어합니다(탐지, 실시간 미리보기, 캡처 및 동기화된 멀티 카메라 어레이):

| 인터페이스    | 위치                                                          | 지원 플랫폼                                                |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| GUI        | Chloros 사이드바의 **카메라** 탭                         | Windows 10/11 x64                                        |
| CLI        | `chloros-cli lattice` 명령어 계열                           | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (Jetson) |
| Python SDK | `chloros_sdk.connect_camera()` / `chloros_sdk.connect_array()` | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (Jetson) |

> **하드웨어를 찾고 계신가요?**카메라 모듈, 렌즈, 필터 및 밴드, 프레임 및 마운팅, 케이블, PoE 및 트리거 배선에 대한 내용은 [**LATTICE 사용자 설명서**](https://mapir.gitbook.io/lattice-camera)에 설명되어 있습니다. 이 장에서는 Chloros를 통해 카메라를 제어하는 방법을 다룹니다.

LATTICE 캡처 파일은 표준 `.tif`/`.tiff` 파일 형식이며, Chloros는 항상 원시 캡처 데이터를 기반으로 이를 처리합니다. 전체 명령어 및 API 목록은 [CLI 참조](../reference/cli-reference.md)와 [SDK 참조](../reference/sdk-reference.md)를 참조하십시오.

## 두 가지 센서 구성

| 구성 | 센서       | 필터                                | 한 대의 카메라가 제공하는 정보                                          |
| ------------- | ------------ | ------------------------------------- | ----------------------------------------------------------------- |
| **M3C**| 베이어 컬러 | 3중 대역 통과 필터                |**단일 노출로 얻은 3개의 보정된 대역**                 |
| **M3M**| 단색     | 단일 협대역 간섭 필터 |**교정된 1개 대역**; 지수 산출을 위해 여러 대의 M3M 카메라를 결합 |

M3M 카메라는 단일 필터 뒤에 단색 센서가 장착되어 있으므로, 각 대역마다 별도의 노출이 이루어집니다. 반면 M3C 카메라는 하나의 센서 노출로 세 대역 모두를 포착합니다.

## 모델 문자열 및 명명 규칙

모든 카메라는 GenICam `DeviceUserID` 형식의 모델 문자열로 자신의 식별 정보를 저장합니다:

```
<sensor>-<lens>-F<filter>       e.g.  M3C-L41-FRGN,  M3M-L87-F450
```

Chloros는 이를 `LATT-` 접두사와 함께 표시합니다(예: `LATT-M3M-L87-F450`). 동일한 `LATT-…` 문자열이 모든 내보내기 파일의 EXIF `Model` 태그에 기록되며, 처리된 프로젝트에서 카메라의 출력 폴더 이름으로 사용됩니다.

| 구성 요소 | 값                                                   | 의미                                                                                            |
| --------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 센서    | `M3C` / `M3M`                                            | 베이어 컬러 / 흑백                                                                          |
| 렌즈      | `L41` / `L87`                                            | 이 숫자는 **도 단위의 수평 시야각**을 나타냅니다: L41 = 좁은 시야 (41°), L87 = 넓은 시야 (87°)    |
| 필터    | `FRGB` / `FRGN` / `FOCN` / `FNGB` (M3C) 또는 `F<nm>` (M3M) | [필터 및 스펙트럼 대역](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands) 참조 |

모델 문자열은 후속 모든 과정을 제어합니다: Chloros는 `DeviceUserID` + `DeviceSerialNumber`로부터 센서 프로파일, 밴드 레이아웃 및 공장 보정 정보를 파악합니다. 카메라별로 별도로 설정할 사항은 없습니다 — [카메라 연결](connecting.md)을 참조하십시오.

## 필터 및 대역

대역 중심, FWHM 경계 및 전체 23개 SKU의 M3M 카탈로그는 제품 사양에 해당하므로 하드웨어 설명서에 수록되어 있습니다: [**필터 및 스펙트럼 대역**](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands).

소프트웨어 측면에서 중요한 점은 모델 문자열에 포함된 필터 코드가 Chloros가 생성할 수 있는 제품을 결정한다는 것입니다. RGB 필터 카메라(`FRGB`)는 디베이어링 처리된 제품과 미리보기 제품만 출력합니다. 광대역 센서의 경우 대역별 복사도 및 반사도는 의미가 없으므로, Chloros는 이를 생략하며 그 사실을 명시합니다. 그 외 모든 필터는 복사도 → 반사도 → 지수 변환의 전체 체인을 생성합니다.

## 방사계 교정 개요

모든 LATTICE 카메라는 공장에서 NIST 추적 가능한 체인을 기준으로 개별적으로 교정되며, 카메라별 인증서와 함께 출하됩니다. 이 교정이 포함하는 내용, 측정 방법 및 인용할 수 있는 정확도는 하드웨어 설명서인 [**공장 방사계 교정**](https://mapir.gitbook.io/lattice-camera/calibration/factory-radiometric-calibration)에 나와 있습니다.

소프트웨어 측면에서는, 카메라가 연결될 때 Chloros가 올바른 보정 값을 적용하고, 적용된 계수를 모든 내보내기 결과에 고정시키는 것이 중요합니다 — [카메라 연결](connecting.md)을 참조하십시오.
