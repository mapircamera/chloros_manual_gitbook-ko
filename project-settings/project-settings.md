# 프로젝트 설정

Chloros

의 ‘프로젝트 설정’<img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line">

사이드바를 통해 프로젝트의 이미지 처리, 보정 대상 감지, 다중 스펙트럼 지수 계산 및 내보내기 옵션 등 모든 측면을 구성할 수 있습니다. 이러한 설정은 프로젝트와 함께 저장되며, 템플릿으로 저장하여 여러 프로젝트에서 재사용할 수 있습니다.

## 프로젝트 설정에 접근하기

프로젝트 설정에 접근하려면:

1.Chloros

에서 프로젝트를 엽니다.
2. 왼쪽 사이드바에서 **프로젝트 설정**<img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line">

탭을 클릭합니다.
3. 설정 패널에 카테고리별로 정리된 모든 구성 옵션이 표시됩니다.

## 표시

### 이미지 썸네일 해상도

* **유형**: 드롭다운 선택
* **옵션**: `Default (512 px)`, `1024 px`, `2048 px`, `Full resolution`
* **기본값**: 기본값 (512 픽셀)
* **설명**: 이미지 그리드 썸네일이 렌더링되는 해상도(가장 긴 변, 픽셀 단위). 값이 높을수록 확대 시 더 선명하게 보이지만, 로딩 속도가 느려지고 메모리 사용량이 증가합니다. 전체 해상도는 원본 이미지 크기를 그대로 사용합니다.
* **참고**: 표시 전용 — 이 설정은 처리 과정이나 내보낸 파일에 전혀 영향을 미치지 않습니다.***

## 타겟 감지

이 설정들은Chloros

가 이미지 내의 보정 타겟을 감지하고 처리하는 방식을 제어합니다. 두 설정 모두 **반사율 보정 / 화이트 밸런스**가 활성화된 경우에만 작동합니다(그 외의 경우에는 타겟 감지가 완전히 건너뛰어지므로 비활성화 상태로 표시됩니다).

### 최소 보정 샘플 영역 (px)

* **유형**: 숫자
* **범위**: 0~10,000 픽셀
* **기본값**: 25 픽셀
* **설명**: 감지된 영역이 유효한 보정 대상 샘플로 간주되기 위해 필요한 최소 영역(픽셀 단위)을 설정합니다. 값을 작게 설정하면 더 작은 대상을 감지할 수 있지만, 오탐이 증가할 수 있습니다. 값을 크게 설정하면 감지를 위해 더 크고 선명한 대상 영역이 필요합니다.
* **조정 시점**:
  * 작은 이미지 아티팩트에서 오탐지가 발생하는 경우 값을 늘리십시오.
  * 이미지에서 보정 대상이 작게 나타나고 감지되지 않는 경우 값을 줄이십시오.

### 최소 대상 클러스터링 (0-100)

* **유형**: 숫자
* **범위**: 0~100
* **기본값**: 60
* **설명**: 보정 대상을 감지할 때 유사한 색상의 영역을 그룹화하는 클러스터링 임계값을 제어합니다. 값이 높을수록 더 유사한 색상만 그룹화되므로, 표적 탐지가 더 보수적으로 이루어집니다. 값이 낮을수록 표적 그룹 내의 색상 변동이 더 허용됩니다.
* **조정 시점**:
  * 보정 타겟이 여러 개의 탐지 결과로 분할되는 경우 값을 높입니다.
  * 색상 변동이 있는 보정 타겟이 완전히 탐지되지 않는 경우 값을 낮춥니다.

## 처리

이 설정들은Chloros

이 이미지를 처리하고 보정하는 방식을 제어합니다.

### 비네팅 보정

* **유형**: 체크박스
* **기본값**: 활성화됨 (체크됨)
* **설명**: 이미지 가장자리의 렌즈 어두워짐 현상을 보정하기 위해 비네팅 보정을 적용합니다. 비네팅은 렌즈 특성으로 인해 이미지의 모서리와 가장자리가 중앙보다 어둡게 보이는 일반적인 광학적 현상입니다.
* **부작용**: 이 스위치는 또한 실행 시 어떤 *보정되지 않은 대체 결과물*을 기록할지 선택합니다(아래 참조).

### 반사율 보정 / 화이트 밸런스

* **유형**: 체크박스
* **기본값**: 활성화됨(체크됨)
* **설명**: 반사율 보정을 활성화합니다. 카메라 및 사용 가능한 데이터에 따라, 프레임 내에서 감지된 보정 타깃 및/또는 DAQ 광센서의 하향 광 데이터가 사용됩니다. 이를 통해 데이터 세트 전반에 걸쳐 반사율 값을 정규화하고, 조명 조건에 관계없이 일관된 측정값을 보장합니다.
* **비활성화 시**: 타겟 감지가 완전히 건너뛰어지며,**어떤 카메라로도 반사율 산출물을 생성할 수 없습니다** — 타겟 기반Survey3

및 DAQ 기반 LATTICE 모두 해당됩니다. 관련 설정(*반사율 내보내기*, *최소 재보정 간격*, 타겟 감지 임계값)은 회색으로 표시되어 선택할 수 없습니다.

### 보정되지 않은 대체 결과: 센서 응답 내보내기 / 비네팅 보정 내보내기

* **유형**: 두 개의 확인란
* **기본값**: 둘 다 활성화됨(체크됨)
* **설명**: 프레임에 대해 반사율 보정이 불가능한 경우(보정 타겟이 발견되지 않았거나 반사율 보정이 비활성화된 경우), 해당 프레임은 대신 *보정되지 않은 대체 결과물*로 기록됩니다. **각 카메라 모델별로 실행당 두 가지 대체 결과물 중 정확히 하나만 생성되며**, 이는 *비네트 보정* 스위치에 따라 선택됩니다:
  * 비네트 보정 **켜짐**→ `Vignette_Corrected_Images/` (**비네트 보정된 데이터 내보내기**에 의해 제어됨)
  * 비네트 보정 **꺼짐**→ `Sensor_Response_Images/` (**센서 응답 내보내기**에 의해 제어됨)
* 현재 적용되지 않는 대체 제품은 회색으로 표시됩니다. 적용 중인 제품의 선택을 해제하면 해당 파일이 전혀 생성되지 않습니다.

### 반사율 소스 (프로젝트 설정,CLI

/SDK

을 통해 설정)

이 프로젝트는 LATTICE 반사율 산출물이 사용하는 **반사율 기준**도 저장합니다. 설정 패널에는 전용 제어 항목이 없으며, 해당 값은 프로젝트 구성에 `Processing → "Target reflectance source"`로 저장되며, `chloros-cli process --reflectance-source {auto,target,daq}` 또는SDK

의 `reflectance_source` 매개변수를 통해 설정됩니다:

* **`auto`** (기본값): QA를 통과한 인프레임 보정 타겟이 절대 기준이 되며, 타겟이 없거나 QA에 실패한 경우에는 DAQ 하향 분할값(ρ = πL/E)으로 대체됩니다.
* **`auto`**: 엄격한 타겟 기반 반사율 — DAQ 대체 없음.
* **`daq`**: DAQ 우선 반사율; 프레임 내 타겟은 기준값으로 사용되지 않습니다.

저장된 값은 대소문자를 구분하지 않고 일치되며, 몇 가지 철자 변형은 별칭으로 허용됩니다: `target`, `target_image`, `empirical` 및 `empirical_line`는 모두 **target**을 의미합니다. `daq`, `dls`, `light_sensor` 및 `sensor`는 모두**daq**를 의미합니다. 그 외의 모든 항목(존재하지 않는 키 포함)은**auto**로 해석됩니다.

단위별 **측정** 대상 스캔은 대상 단위의 일련번호/QR을 기준으로(예: `<serial>.csv`) 다음 세 곳에서 조회됩니다: `--target-reflectance-dir`로 지정된 디렉터리(`Processing → "Target reflectance dir"`로 저장됨), 프로젝트 자체의 `target_reflectance/` 폴더, 그리고 `CHLOROS_TARGET_REFLECTANCE_DIR` 환경 변수에 지정된 경로입니다. 해당 유닛에 대한 측정 스캔이 존재하지 않을 경우, 대신 대상 모델의 공시된 명목 곡선이 사용됩니다.

### 디베이어 방법

* **유형**: 드롭다운 선택
* **옵션**:
  * 표준 (빠름, 중간 품질)
  * 텍스처 인식 (느림, 최고 품질) \[Chloros

+]
* **기본값**: 표준 (빠름, 중간 품질)
* **설명**: 베이어 패턴 센서의 원시 데이터를 풀컬러 이미지로 변환하는 데 사용되는 디모자이징 알고리즘을 선택합니다. &quot;표준 (빠름, 중간 품질)&quot; 방식은 처리 속도와 이미지 품질 간의 최적의 균형을 제공합니다. &quot;텍스처 인식 (느림, 최고 품질)&quot; \[Chloros

+]는 고품질의 에지 인식 디베이어링 알고리즘과 AI/ML 노이즈 제거 모델을 결합하여 디베이어링 과정에서 발생하는 노이즈를 거의 모두 제거합니다. 텍스처 인식 모델은 실행에 GPU 메모리(VRAM)가 필요합니다. 더 빠른 처리를 위해 4GB 이상의 VRAM이 확보된 경우 이 모드를 사용하는 것을 권장합니다.
* **해당 행이 드롭다운 목록인 경우**: 두 가지 옵션이 있는 드롭다운은**두 조건**이 모두 충족될 때만 나타납니다. 즉, 적격한Chloros

+ 구독으로 로그인되어 있고, **또한** 프로젝트에 LATTICE 캡처가 포함되어 있지 않은 경우입니다. 그렇지 않으면 해당 행은 선택할 항목이 없는 `Standard (Fast, Medium Quality)`라는 일반 텍스트로 표시됩니다.
* **LATTICE 참고 사항**: LATTICE용으로 훈련된 Texture Aware 모델은 없으며, 파이프라인은 저장된 값과 관계없이 LATTICE 프레임에 대해 표준 디모자이크를 강제 적용합니다. 이미 Texture Aware가 선택된 프로젝트에 LATTICE 폴더를 추가하는 경우,Chloros

는 `project.json`에 오래된 값을 남겨두지 않고 설정을 다시 &#x27;표준(Standard)&#x27;으로 재설정합니다.

### 최소 재보정 간격

* **유형**: 숫자
* **범위**: 0 ~ 3,600초
* **기본값**: 0초
* **설명**: 보정 타겟을 사용하는 데 걸리는 최소 시간 간격(초 단위)을 설정합니다. 0으로 설정하면Chloros

는 감지된 모든 보정 타겟을 사용합니다. 더 큰 값으로 설정하면Chloros

는 이 값만큼의 시간이 지난 후에만 보정 타겟을 사용하므로, 보정 타겟이 빈번하게 캡처되는 데이터 세트의 처리 시간을 단축할 수 있습니다.
* **조정 시점**:
  * 조명 조건이 변동이 심한 경우, 보정 정확도를 극대화하려면 0으로 설정하십시오.

### PPK 보정 적용

* **유형**: 선택 상자
* **기본값**: 비활성화됨(선택 해제됨)
* **설명**: GPS(GNSS)가 내장된MAPIR

DAQ 레코더의 PPK(Post-Processed Kinematic) 보정 기능을 활성화합니다. 이 기능을 활성화하면,Chloros

### 노출 핀 1

* **유형**: 드롭다운 선택
* **표시 조건**: “PPK 보정 적용”이 활성화되어 있고, 핀 1에 대한 노출 데이터가 있는 경우에만 표시됩니다.

* **옵션**:
  * 프로젝트에서 감지된 카메라 모델명
  * “사용 안 함” - 이 노출 핀을 무시합니다

## 어레이 정렬

이 섹션은 프로젝트 내 최소 한 장의 이미지에 LATTICE 어레이가 촬영 시에 찍어두는 모듈 간 정렬 변환 정보(XMP `Chloros:Alignment*` 태그)가 포함되어 있을 때 **오직** 표시됩니다. 이 섹션에서는 정렬 태그가 포함된 이미지 수, 기준이 되는 카메라(`REF` 배지), 그리고 카메라별 이미지 수 표를 보여줍니다.

### 어레이 정렬 적용

* **유형**: 체크박스
* **기본값**: 활성화됨 (선택됨)

* **기본값**: 이선형
* **저장 형식**: `Processing → "Array alignment interpolation"`
* **설명**: 정렬 워프에 사용되는 보간법입니다. ‘가장 가까운(Nearest)’은 정확한 소스 값을 보존하며(픽셀 간 혼합 없음픽셀 혼합 없음)을 유지하여 엄격한 방사계 분석을 수행합니다. 이차선형은 매핑 및 시각화 용도로 가장 적합합니다.

이 세 가지 옵션은 `chloros-cli process --array-alignment`, `--array-alignment-crop`, `--array-alignment-interp {bilinear,nearest,cubic}`로 제공됩니다.

* **만드는 방법**:
  1. 지수 구성 패널에서 사용자 정의 공식 계산기를 엽니다.
  2. 밴드 이름이 아닌 **밴드 슬롯 기호**를 사용하여 공식을 작성합니다.
  3. 설명이 포함된 이름으로 공식을 저장하면, 공식 드롭다운 메뉴 하단에 표시되며, 내장 프리셋과 똑같이 카메라의 채널 원을 해당 슬롯으로 드래그하여 적용할 수 있습니다.

(8비트)**: 웹 열람 및 일반적인 시각화에 적합합니다. 무손실 압축으로 파일 크기가 작지만, 다이나믹 레인지는 감소합니다.
  * **JPG(8비트)**: 파일 크기가 가장 작으며, 미리보기 및 웹 표시에만 가장 적합합니다. 손실 압축을 사용하므로 과학적 분석에는 적합하지 않습니다.
* **참고**: 이 설정과 관계없이 LATTICE 방사도는 항상 32비트 부동소수점TIFF

으로 내보내집니다.

## 프로젝트 템플릿 저장

이 기능을 사용하면 현재 프로젝트 설정을 재사용 가능한 템플릿으로 저장할 수 있습니다.

* **유형**: 텍스트 입력 + 저장 버튼
* **설명**: 설정 템플릿에 대한 설명적인 이름을 입력하고 저장 아이콘을 클릭하십시오. 템플릿에는 현재 프로젝트의 모든 설정(표적 감지, 처리 옵션, 인덱스 및 내보내기 형식)이 저장되어 향후 프로젝트에서 쉽게 재사용할 수 있습니다. 템플릿은 프로젝트 저장 폴더 내의 `Project Templates/` 폴더에 저장되며, 메인 메뉴의 (*템플릿 선택* / *템플릿 저장* / *템플릿 내보내기*)에서 선택하거나 내보낼 수 있습니다.
* **사용 사례**:
  * 다양한 카메라 시스템(RGB

, 다중 스펙트럼,NIR

)용 템플릿 생성
  * 특정 작물 유형이나 분석 워크플로우에 대한 표준 구성 저장
  * 팀 전체에서 일관된 설정 공유
* **사용 방법**:
  1. 원하는 모든 프로젝트 설정을 구성합니다.
  2. 템플릿 이름을 입력합니다(예: &quot;RedEdge

Survey3

NDVI

Standard&quot;).
  3. 저장 아이콘을 클릭합니다.
  4. 이제 새 프로젝트를 생성할 때 해당 템플릿을 불러올 수 있습니다.

## 프로젝트 저장 폴더

이 설정은 새 프로젝트가 기본적으로 저장될 위치를 지정합니다.

* **유형**: 디렉터리 경로 표시 + 편집 버튼
* **기본값 (Windows

)**: `C:\Users\[Username]\Chloros Projects`
* **기본값 (Linux

)**: `~/Chloros Projects`
* **설명**: 새로운Chloros

프로젝트가 생성되는 현재 기본 디렉터리를 표시합니다. 편집 아이콘을 클릭하여 다른 디렉터리를 선택하십시오. 이 재정의 설정은 `~/.chloros/working_directory.txt` 파일에 한 줄의 텍스트로 저장됩니다(Windows

에서는 `C:\Users\<Username>\.chloros\working_directory.txt`). 해당 파일이 없거나 더 이상 존재하지 않는 경로를 지정하는 경우,Chloros

는 위의 기본값으로 돌아갑니다.CLI

는 동일한 파일을 읽고 쓰므로, `chloros-cli`와 GUI는 프로젝트의 위치에 대해 항상 일치합니다.
* **프로젝트 템플릿**은 이 디렉터리의 `Project Templates/` 하위 폴더에 저장됩니다.
* **변경 시점**:
  * 팀 협업을 위해 네트워크 드라이브로 설정
  * 대용량 데이터 세트의 경우 저장 공간이 더 많은 드라이브로 변경
  * 연도, 고객 또는 프로젝트 유형별로 프로젝트를 구분하여 별도의 폴더에 정리
* **참고**: 이 설정을 변경해도 기존 프로젝트에는 영향을 미치지 않습니다. 기존 프로젝트는 원래 위치에 그대로 유지됩니다.***

## 설정 유지

Chloros

프로젝트는 **폴더**입니다. 모든 프로젝트 설정은 해당 폴더 내의 `project.json`에 저장되며, 연결된 하드웨어 정보는 `cameras.json` 및 `sensors.json`에 함께 저장되며, 따라서 프로젝트를 다시 열면 카메라와 광 센서도 다시 연결됩니다. 프로젝트를 다시 열면 모든 설정이 마지막으로 저장된 상태 그대로 복원됩니다. 저장된 프로젝트는 `chloros-cli project` 또는SDK

의 `open_project`를 사용하여 헤드리스 모드로 구동할 수도 있습니다.

### 설정 계층 구조

설정은 다음 순서대로 적용됩니다:

1. **시스템 기본값** -Chloros

에서 정의한 내장 기본값 2. **템플릿 설정** - 프로젝트 생성 시 템플릿을 불러온 경우
3. **저장된 프로젝트 설정** - 프로젝트 파일과 함께 저장된 설정
4. **수동 조정** - 현재 세션 중에 사용자가 변경한 모든 사항

### 설정 및 이미지 처리

처리 실행이 시작될 때 처리 설정이 읽힙니다. 설정을 변경하더라도 이미 디스크에 저장된 결과물은 소급 적용되지 않으므로, 새 설정을 적용하려면 처리를 다시 실행해야 합니다. 다음과 같은 몇 가지 설정은 처리 과정에 전혀 영향을 미치지 않습니다:

* 이미지 썸네일 해상도 (표시용)
* 프로젝트 템플릿 저장
* 프로젝트 폴더 저장
