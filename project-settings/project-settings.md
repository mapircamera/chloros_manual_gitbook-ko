# 프로젝트 설정

Chloros의 <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> 사이드바를 통해 이미징 처리, 보정 타겟 감지, 다중 스펙트럼 지수 계산 및 프로젝트 내보내기 옵션 등 프로젝트의 모든 측면을 구성할 수 있습니다. 이러한 설정은 프로젝트와 함께 저장되며, 여러 프로젝트에서 재사용할 수 있도록 템플릿으로 저장할 수 있습니다.

## 프로젝트 설정 열기

프로젝트 설정에 액세스하려면:

1. Chloros에서 프로젝트를 엽니다.
2. 왼쪽 사이드바의 **프로젝트 설정**  <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> 탭을 클릭합니다
3. 설정 패널에 카테고리별로 정리된 모든 구성 옵션이 표시됩니다

***

## 타겟 감지

이 설정은 Chloros가 이미지에서 보정 타겟을 감지하고 처리하는 방식을 제어합니다.

### 최소 보정 샘플 영역 (px)

* **유형**: 숫자
* **범위**: 0~10,000 픽셀
* **기본값**: 25 픽셀
* **설명**: 감지된 영역이 유효한 보정 타겟 샘플로 간주되기 위해 필요한 최소 면적(픽셀 단위)을 설정합니다. 값을 작게 설정하면 더 작은 타겟을 감지할 수 있지만 오탐이 증가할 수 있습니다. 값을 크게 설정하면 감지를 위해 더 크고 선명한 타겟 영역이 필요합니다.
* **조정 시점**:
  * 작은 이미지 아티팩트에서 오탐지가 발생하는 경우 값을 늘립니다.
  * 이미지에서 보정 대상이 작게 나타나 감지되지 않는 경우 값을 줄입니다.

### 최소 대상 클러스터링 (0-100)

* **유형**: 숫자
* **범위**: 0~100
* **기본값**: 60
* **설명**: 보정 타겟을 감지할 때 유사한 색상의 영역을 그룹화하는 클러스터링 임계값을 제어합니다. 값이 높을수록 더 많은 유사한 색상이 함께 그룹화되어야 하므로, 타겟 감지가 더 보수적으로 이루어집니다. 값이 낮을수록 타겟 그룹 내의 색상 변동이 더 허용됩니다.
* **조정 시점**:
  * 보정 타겟이 여러 개의 탐지 결과로 분할되는 경우 값을 높입니다.
  * 색상 변동이 있는 보정 타겟이 완전히 탐지되지 않는 경우 값을 낮춥니다.

***

## 처리

이 설정들은 Chloros가 이미지를 처리하고 보정하는 방식을 제어합니다.

### 비네팅 보정

* **유형**: 체크박스
* **기본값**: 활성화됨 (체크됨)
* **설명**: 이미지 가장자리의 렌즈 어두워짐을 보정하기 위해 비네팅 보정을 적용합니다. 비네팅은 렌즈의 특성으로 인해 이미지의 모서리와 가장자리가 중앙보다 어둡게 보이는 일반적인 광학 현상입니다.
* **비활성화 시점**: 사용 중인 카메라/렌즈 조합에서 이미 비네팅 보정이 적용되어 있거나, 후처리 단계에서 비네팅을 수동으로 보정하려는 경우에만 비활성화하십시오.

### 반사율 보정 / 화이트 밸런스

* **유형**: 체크박스
* **기본값**: 활성화됨 (체크됨)
* **설명**: 이미지에서 감지된 보정 타깃을 사용하여 자동 반사율 보정을 활성화합니다. 이를 통해 데이터 세트 전반의 반사율 값을 정규화하여 조명 조건에 관계없이 일관된 측정 결과를 보장합니다.
* **비활성화 시점**: 보정되지 않은 원본 이미지를 처리하려는 경우나 다른 보정 워크플로를 사용하는 경우에만 비활성화하십시오.

### 디베이어 방식

* **유형**: 드롭다운 선택
* **옵션**:
  * 표준 (빠름, 중간 품질)
  * 텍스처 인식 (느림, 최고 품질) \[Chloros+]
* **기본값**: 표준 (빠름, 중간 품질)
* **설명**: 원시 베이어 패턴 센서 데이터를 풀컬러 이미지로 변환하는 데 사용되는 디모자이징 알고리즘을 선택합니다. &quot;표준 (빠름, 중간 품질)&quot; 방식은 처리 속도와 이미지 품질 간의 최적의 균형을 제공합니다. &quot;텍스처 인식 (느림, 최고 품질)&quot; \[Chloros+]은 고품질 에지 인식 디베이어링과 AI/ML 노이즈 제거 모델을 결합하여 디베이어링 과정에서 발생하는 노이즈를 거의 모두 제거합니다. 텍스처 인식 모델은 실행에 GPU 메모리(VRAM)가 필요합니다. 더 빠른 처리를 위해 4GB 이상의 VRAM이 확보된 경우 이 모델을 사용하는 것을 권장합니다.
* **참고**: 향후 Chloros 버전에서는 추가적인 디베이어링 방식이 추가될 수 있습니다.

### 최소 재보정 간격

* **유형**: 숫자
* **범위**: 0~3,600초
* **기본값**: 0초
* **설명**: 보정 타겟을 사용하는 사이의 최소 시간 간격(초 단위)을 설정합니다. 0으로 설정하면 Chloros는 감지된 모든 보정 타겟을 사용합니다. 더 큰 값으로 설정하면 Chloros는 이 값만큼의 간격이 있는 보정 타겟만 사용하므로, 보정 타겟이 빈번하게 포착되는 데이터셋의 처리 시간을 단축할 수 있습니다.
* **조정 시점**:
  * 조명 조건이 변동이 심한 경우, 보정 정확도를 극대화하려면 0으로 설정하십시오.
  * 조명이 일정하고 보정 타겟 이미지가 빈번하게 있는 경우, 처리 속도를 높이려면 값을 늘리십시오(예: 60~300초).

### 광센서 시간대 오프셋

* **유형**: 숫자
* **범위**: -12~+12시간
* **기본값**: 0시간
* **설명**: 광 센서 데이터 타임스탬프의 시간대 오프셋(UTC 기준 시간)을 지정합니다. 이는 PPK(사후 처리 기동학) 데이터 파일을 처리할 때 이미지 캡처와 GPS 데이터 간의 정확한 시간 동기화를 보장하기 위해 사용됩니다.
* **조정 시점**: PPK 데이터가 UTC 대신 현지 시간을 사용하는 경우, 이 값을 현지 시간대 오프셋으로 설정하십시오. 예:
  * 태평양 표준시: -8 또는 -7 (일광 절약 시간제 적용 여부에 따라 다름)
  * 동부 표준시: -5 또는 -4 (일광 절약 시간제 적용 여부에 따라 다름)
  * 중부 유럽 표준시: +1 또는 +2 (일광 절약 시간제 적용 여부에 따라 다름)

### PPK 보정 적용

* **유형**: 체크박스
* **기본값**: 비활성화됨 (체크 해제)
* **설명**: GPS(GNSS)를 탑재한 MAPIR DAQ 레코더의 사후 처리 운동학(PPK) 보정 기능을 활성화합니다. 이 기능이 활성화되면, Chloros는 프로젝트 디렉터리에 있는 노출 핀 데이터가 포함된 모든 .daq 로그 파일을 사용하여 이미지에 정확한 위치 보정을 적용합니다.
* **필수 조건**: 프로젝트 디렉터리에 노출 핀 항목이 포함된 .daq 로그 파일이 있어야 합니다.
* **활성화 시점**: .daq 로그 파일에 노출 피드백 항목이 있는 경우 항상 PPK 보정을 활성화하는 것이 좋습니다.

### 노출 핀 1

* **유형**: 드롭다운 선택
* **표시 상태**: &quot;PPK 보정 적용&quot;이 활성화되어 있고 핀 1에 대한 노출 데이터가 있을 때만 표시됨
* **옵션**:
  * 프로젝트에서 감지된 카메라 모델명
  * &quot;사용 안 함&quot; - 이 노출 핀을 무시함
* **기본값**: 프로젝트 구성에 따라 자동 선택됨
* **설명**: PPK 시간 동기화를 위해 노출 핀 1에 특정 카메라를 할당합니다. 노출 핀은 카메라 셔터가 작동하는 정확한 시점을 기록하며, 이는 정확한 PPK 위치 추정을 위해 매우 중요합니다.
* **자동 선택 동작**:
  * 카메라 1대 + 핀 1개: 카메라를 자동으로 선택합니다
  * 카메라 1대 + 핀 2개: 핀 1이 카메라에 자동으로 할당됩니다
  ** **설명**: PPK 시간 동기화를 위해 특정 카메라를 노출 핀 1에 할당합니다. 노출 핀은 카메라 셔터가 작동하는 정확한 시점을 기록하며, 이는 정확한 PPK 위치 추정에 매우 중요합니다.
* **자동 선택 동작**:
  * 단일 카메라 + 단일 핀: 카메라를 자동으로 선택합니다
  * 단일 카메라 + 두 개의 핀: 핀 1이 해당 카메라에 자동으로 할당됩니다
  *
  * 다중 카메라: 수동 선택이 필요합니다

### 노출 핀 2

* **유형**: 드롭다운 선택
* **표시 상태**: &quot;PPK 보정 적용&quot;이 활성화되어 있고 핀 2에 대한 노출 데이터가 있는 경우에만 표시됩니다
* **옵션**:
  * 프로젝트에서 감지된 카메라 모델명
  * &quot;사용 안 함&quot; - 이 노출 핀을 무시합니다
* **기본값**: 프로젝트 구성에 따라 자동 선택
* **설명**: 듀얼 카메라 설정을 사용할 때 PPK 시간 동기화를 위해 노출 핀 2에 특정 카메라를 할당합니다.
* **자동 선택 동작**:
  * 단일 카메라 + 단일 핀: 핀 2가 자동으로 &quot;사용 안 함&quot;으로 설정됨
  * 단일 카메라 + 두 개의 핀: 핀 2가 자동으로 &quot;사용 안 함&quot;으로 설정됨
  * 다중 카메라: 수동 선택 필요
* **참고**: 동일한 카메라를 핀 1과 핀 2에 동시에 할당할 수 없습니다.***

## 지수

이 설정을 통해 분석 및 시각화를 위한 다중 스펙트럼 지수를 구성할 수 있습니다.

### 지수 추가

* **유형**: 특수 지수 구성 패널
* **설명**: 이미지 처리 중에 계산할 다중 스펙트럼 식생 지수(NDVI, NDRE, EVI 등)를 선택하고 구성할 수 있는 대화형 패널을 엽니다. 각각 고유한 시각화 설정을 가진 여러 지수를 추가할 수 있습니다.
* **사용 가능한 지수**: 시스템에는 다음을 포함하여 30개 이상의 사전 정의된 다중 스펙트럼 지수가 포함되어 있습니다:
  * NDVI (정규화 식생 지수)
  * NDRE (정규화 차분 RedEdge)
  * EVI (향상된 식생 지수)
  * GNDVI, SAVI, OSAVI, MSAVI2
  * 그 외 다수 (전체 목록은 [다중 스펙트럼 지수 공식](multispectral-index-formulas.md) 참조)
* **기능**:
  * 미리 정의된 지수 공식 중에서 선택
  * 시각화 색상 그라데이션 구성 (LUT - 조회 테이블)
  * 분석을 위한 임계값 설정
  * 사용자 지정 지수 공식 생성

### 사용자 지정 공식 (Chloros+ 기능)

* **유형**: 사용자 정의 공식 정의 배열
* **설명**: 밴드 연산을 사용하여 사용자 정의 다중 스펙트럼 지수 공식을 생성하고 저장할 수 있습니다. 사용자 정의 공식은 프로젝트 설정과 함께 저장되며 내장 지수와 동일하게 사용할 수 있습니다.
* **생성 방법**:
  1. 지수 구성 패널에서 사용자 정의 공식 옵션을 찾습니다.
  2. 밴드 식별자(예: NIR, Red, Green, Blue)를 사용하여 공식을 정의합니다.
  3. 설명적인 이름을 지정하여 수식을 저장합니다
* **수식 구문**: 다음을 포함한 표준 수학 연산이 지원됩니다:
  * 산술 연산: `+`, `-`, `*`, `/`
  * 연산 순서를 위한 괄호
  * 밴드 참조: NIR, Red, Green, Blue, RedEdge, Cyan, Orange, NIR1, NIR2

## 내보내기

이 설정은 내보내는 처리된 이미지의 형식과 품질을 제어합니다.

### 보정된 이미지 형식

* **유형**: 드롭다운 선택
* **옵션**:
  * **TIFF (16비트)** - 비압축 16비트 TIFF 형식
  * **TIFF (32비트, 백분율)** - 반사율 값을 백분율로 표시하는 32비트 부동 소수점 TIFF
  * **PNG (8비트)** - 압축된 8비트 PNG 형식
  * **JPG (8비트)** - 압축된 8비트 JPEG 형식
* **기본값**: TIFF (16비트)
* **설명**: 처리 및 보정된 이미지를 저장할 파일 형식을 선택합니다.
* **권장 형식**:
  * **TIFF (16비트)**: 과학적 분석 및 전문적인 워크플로우에 권장됩니다. 압축 아티팩트 없이 데이터 품질을 최대한 보존합니다. 다중 스펙트럼 분석 및 GIS 소프트웨어에서의 추가 처리에 가장 적합합니다.
  * **TIFF (32비트, 백분율)**: 반사율 값을 백분율(0-100%)로 요구하는 워크플로우에 가장 적합합니다. 방사계 측정에 있어 최대 정밀도를 제공합니다.
  * **PNG (8비트)**: 웹 보기 및 일반적인 시각화에 적합합니다. 무손실 압축으로 파일 크기가 작지만, 다이나믹 레인지가 줄어듭니다.
  * **JPG (8비트)**: 파일 크기가 가장 작으며, 미리보기 및 웹 표시용으로만 적합합니다. 손실 압축을 사용하므로 과학적 분석에는 적합하지 않습니다.***

## 프로젝트 템플릿 저장

이 기능을 사용하면 현재 프로젝트 설정을 재사용 가능한 템플릿으로 저장할 수 있습니다.

* **유형**: 텍스트 입력 + 저장 버튼
* **설명**: 설정 템플릿에 대한 설명적인 이름을 입력하고 저장 아이콘을 클릭하십시오. 템플릿에는 현재 프로젝트의 모든 설정(타겟 감지, 처리 옵션, 지수, 내보내기 형식)이 저장되어 향후 프로젝트에서 쉽게 재사용할 수 있습니다.
* **사용 사례**:
  * 다양한 카메라 시스템용 템플릿 생성 (RGB, 다중 스펙트럼, NIR)
  * 특정 작물 유형이나 분석 워크플로우에 대한 표준 구성 저장
  * 팀 전체에서 일관된 설정 공유
* **사용 방법**:
  1. 원하는 모든 프로젝트 설정을 구성합니다
  2. 템플릿 이름을 입력합니다(예: &quot;RedEdge Survey3 NDVI Standard&quot;)
  3. 저장 아이콘을 클릭합니다
  4. 이제 새 프로젝트를 생성할 때 이 템플릿을 불러올 수 있습니다

***

## 프로젝트 폴더 저장

이 설정은 새 프로젝트가 기본적으로 저장될 위치를 지정합니다.

* **유형**: 디렉터리 경로 표시 + 편집 버튼
* **기본값 (Windows)**: `C:\Users\[Username]\Chloros Projects`
* **기본값 (Linux)**: `~/.local/share/chloros/projects`
* **설명**: 새 Chloros 프로젝트가 생성되는 현재 기본 디렉터리를 표시합니다. 편집 아이콘을 클릭하여 다른 디렉터리를 선택하십시오.
* **변경 시점**:
  * 팀 협업을 위해 네트워크 드라이브로 설정
  * 대용량 데이터 세트를 위해 저장 공간이 더 많은 드라이브로 변경
  * 연도, 고객 또는 프로젝트 유형별로 프로젝트를 다른 폴더에 정리
* **참고**: 이 설정을 변경해도 기존 프로젝트에는 영향을 미치지 않습니다. 기존 프로젝트는 원래 위치에 그대로 유지됩니다.***

## 설정 유지

모든 프로젝트 설정은 프로젝트 파일(`.mapir` 프로젝트 형식)과 함께 자동으로 저장됩니다. 프로젝트를 다시 열면 모든 설정이 마지막으로 저장된 상태 그대로 복원됩니다.

### 설정 계층 구조

설정은 다음 순서대로 적용됩니다:

1. **시스템 기본값** - Chloros에서 정의된 기본값
2. **템플릿 설정** - 프로젝트 생성 시 템플릿을 불러온 경우
3. **저장된 프로젝트 설정** - 프로젝트 파일과 함께 저장된 설정
4. **수동 조정** - 현재 세션 중에 사용자가 변경한 모든 설정

### 설정 및 이미지 처리

대부분의 설정 변경(특히 &#x27;처리&#x27; 및 &#x27;내보내기&#x27; 범주)은 새로운 설정을 반영하기 위해 이미지 재처리를 유발합니다. 그러나 일부 설정은 &quot;내보내기 전용&quot;이며 즉시 재처리가 필요하지 않습니다:

* 프로젝트 템플릿 저장
* 작업 디렉터리
* 보정된 이미지 형식(내보낼 때 적용됨)

## 권장 사항

1. **기본값으로 시작하기**: 기본 설정은 대부분의 MAPIR 카메라 시스템과 일반적인 워크플로우에 적합합니다.
2. **템플릿 생성**: 특정 워크플로우나 카메라에 대한 설정을 최적화한 후에는 템플릿으로 저장하여 프로젝트 전반에 걸쳐 일관성을 유지하십시오.
3. **전체 처리 전에 테스트하기**: 새로운 설정을 시도할 때는 전체 데이터 세트를 처리하기 전에 소량의 이미지 샘플로 먼저 테스트하십시오.
4. **설정 기록하기**: 카메라 시스템, 처리 유형 및 용도를 나타내는 설명적인 템플릿 이름을 사용하십시오(예: &quot;Survey3\_RGB\_NDVI\_Agriculture&quot;).
5. **내보내기 형식 선택**: 최종 용도에 따라 내보내기 형식을 선택하십시오:
   * 과학적 분석 → TIFF (16비트 또는 32비트)
   * GIS 처리 → TIFF (16비트)
   * 빠른 시각화 → PNG (8비트)
   * 웹 공유 → JPG (8비트)
