# 캡 프로파일 및 보정 범위

> 캡 자체에 관한 정보(어떤 센서에 어떤 캡이 함께 제공되는지, 장착 방식, 광학적 특성 등)는 **[DAQ 사용자 설명서](https://mapir.gitbook.io/daq)**에 기재되어 있습니다. 이 페이지에서는 Chloros에 장착된 캡을 *선언*하는 방법을 다루며, 이를 통해 보정이 정확하게 이루어집니다.

모든 DAQ 광 센서의 공장 방사계 보정은 *노출된* 센서에 대한 설명입니다. 디퓨저 위에 장착된 물리적 캡은 센서가 수집하는 빛의 성질을 변화시키므로, Chloros는 보정 번들 위에 공장 측정된 **캡 보정 프로파일**을 적용합니다. 올바른 캡을 지정하는 것은 보정된 데이터를 얻기 위한 필수 과정입니다. 이 페이지에서는 모델별 캡 종류, 지정 방법, 그리고 센서의 실제 보정 스펙트럼 범위에 대해 다룹니다.

## 모델별 캡 제공 현황

| 캡 프로파일 (`cap_id`) | 물리적 캡 | DAQ-U | DAQ-M | DAQ-E |
| --- | --- | --- | --- | --- |
| `sunshine_cosine` | 선샤인 코사인 보정 캡 (**모든 모델의 기본값**) | 예 | 예 | 예 |
| `fov_15` / `fov_45` / `fov_90` | 시야 제한 콘 (15° / 45° / 90°) | 예 | — | 예 |
| `fov_30` / `fov_60` | 시야 제한 콘 (30° / 60°) | 예 | — | — |
| `none` | 캡 미장착 | — | — | 예 |

모델별 참고 사항:

* **DAQ-M에는 하나의 캡 프로파일(`sunshine_cosine`)이 있습니다.** &#x27;베어-플러스-선샤인 캡&#x27;이 해당 제품의 정의이며, 베어 DAQ-M에는 기하학적 프로파일이 필요하지 않습니다.
* **베어 DAQ-U는 완전한 베어 제품입니다** — 기하학적 프로파일이 전혀 필요하지 않으므로, 이에 해당하는 `none` 프로파일은 존재하지 않습니다.
* **DAQ-E에 적용된 `none`는 무작위 설정(no-op)이 아닙니다.** DAQ-E의 오목하고 유리로 덮인 디퓨저는 고유한 기하학적 보정 기능을 갖추고 있으므로, 이 모델에서 “캡 없음”은 그 자체로 측정된 프로파일입니다.
* **커버가 없는 DAQ-E는 어떤 고도에서도 직사광선을 측정할 수 없습니다** — 선샤인 캡이 현장 구성입니다. 커버가 없는 DAQ-E를 사용하여 야외 작업을 계획하지 마십시오.

GUI의 센서별 설정(‘Light Sensors’ 탭의 톱니바퀴 아이콘)에서 **Cap** 드롭다운 메뉴는 DAQ-U 및 DAQ-M 모델에서도 “None (bare sensor)” 옵션을 제공합니다. 앞서 언급한 바와 같이, 이 두 모델에서 “bare”는 단순히 캡 보정이 적용되지 않음을 의미합니다. 캡이 물리적으로 제거된 경우에만 이 옵션을 선택하십시오.

## 캡 선언 — 그리고 그 중요성

**선언된 `cap_id`는 센서에 물리적으로 장착된 캡과 일치해야 합니다.** 센서나 소프트웨어 모두 장착된 캡을 감지할 수 없습니다. 캡 선언은 다음 두 가지에 영향을 미칩니다:

1. 모든 스펙트럼에 적용되는 **실시간 보정**.
2. **모든 `.daq` 기록에 기록되는 캡 스탬프**. 이는 후속 반사율 처리 과정에서 신뢰하는 정보입니다.

Sunshine 캡은 **설계상 약 12배**의 감쇠 효과를 가지므로, 잘못된 캡을 선언하고 기록할 경우 스펙트럼의 스케일이 그 정도 비율만큼 왜곡됩니다. 캡 변경 사항은 즉시 선언하십시오.

### 캡 설정

GUI: Light Sensors 탭 → 센서 행의 톱니바퀴 아이콘 → **Cap** 드롭다운 메뉴. 모든 모델의 기본값은 `sunshine_cosine`이며(모든 DAQ 센서에는 코사인 보정기가 설치된 상태로 출하됨), 이 선택 사항은 프로젝트에 따라 유지됩니다.

<!-- SCREENSHOT-NEEDED: DAQ tab per-sensor settings modal (gear icon) scrolled to the Cap dropdown, open to show the per-model choices with "Sunshine (cosine corrector)" selected. Use a connected DAQ-E so the Hostname/Firmware/PTP rows are also visible above it. -->

CLI (백엔드가 실행 중이어야 함):

```bash
# Declare at connect time
chloros-cli daq pool-connect --eth-host daq-e-def330.local --cap-id sunshine_cosine

# Swap at runtime (after physically changing the cap)
chloros-cli daq pool-set-cap --sensor-id daq-e-def330 --cap-id fov_45
```

CLI는 구문상 전체 `cap_id` 목록(`{none, fov_15, fov_30, fov_45, fov_60, fov_90, sunshine_cosine}`)을 허용합니다; 각 프로필은 연결 시 센서 모델에 대해 유효성 검증이 이루어지므로, 사용할 수 없는 캡 ID(예: DAQ-U에서 E 전용 ID)의 경우 잘못된 보정이 이루어지는 대신 명확한 오류 메시지와 함께 실패합니다. 아무것도 전달되지 않을 때의 백엔드 기본값은 `sunshine_cosine`입니다.

Python SDK 참고: `cap_id`는 **SDK** 노브가 아닙니다 — `connect_daq_sensor()` / `DAQSensorSession`는 캡 매개변수를 노출하지 않습니다. 위의 CLI 명령어나 GUI 드롭다운 메뉴를 통해 캡을 선택하십시오. [SDK 참조](../reference/sdk-reference.md)를 참조하십시오.

고급: 프로파일은 Chloros 설치 파일 내에 포함되어 `daq/cap_profiles/<u|m|e>/<cap_id>.json`에 위치하며, `~/.chloros/daq_cap_profiles/<u|m|e>/<cap_id>.json`에서 사용자별로 재정의할 수 있습니다.

상한값과는 별도로, 재보정된 적이 없는 센서에는 자동으로 소규모 함대 데이터를 기반으로 한 미세한 다크 오프셋 보정이 적용되며, 이 과정에서 사용자의 개입은 필요하지 않습니다.

## 선샤인 캡 성능 (실외 구성)

절차 수립에 활용할 수 있는 수치:

| 속성 | 값 |
| --- | --- |
| 시야각 | 180° 반구형 |
| 코사인 응답 오차 | 입사각 60°까지 ≤ ±4 %; 70°까지 ≤ ±4.5 % |
| 저고도 태양 한계 | 태양 고도 ~15° 미만에서는 권장하지 않음 |
| 감쇠 | ~12배 (설계상) |
| 캡 재장착 반복성 | ≈ 1.5 % |
| 정량적 조도 | 평균 **≥ 15초** 측정값 (기기 특성이며 결함이 아님) |

정량적 조도 수치(반사율 기준 포함)의 경우, 단일 프레임 대신 최소 15초간의 측정값 평균을 사용하십시오.

## 교정된 스펙트럼 범위

| 속성 | 값 |
| --- | --- |
| 스펙트럼 샘플링 | 5 nm 간격으로 340–1010 nm (135개 점) |
| 방사계학적 보정 범위 | **~374–974 nm** (소프트웨어에서 강제 적용) |

센서는 340–1010 nm 전체 그리드를 보고하지만, NIST 추적 가능한 방사계학적 게인은 ~374–974 nm에 해당합니다. Chloros는 해당 범위 내 스펙트럼 가중치의 절반 미만을 차지하는 카메라 대역에 대해서는 **절대 반사율 나눗셈을 거부**하며, 보정되지 않은 결과를 생성하는 대신 건너뛰기 사유 `dls-uncalibrated-band-<nm>`를 보고합니다. 현재 판매 중인 카메라 SKU 중에서는 F988 필터만이 이 범위를 벗어나며, 이 경우 반사율 패널 워크플로를 대신 사용합니다 — [반사율 워크플로](reflectance.md)를 참조하십시오.

센서 모델, 전송 방식 및 센서 ID에 대해서는 [DAQ 개요](README.md)를 참조하십시오. 처리 과정에서 캡 스탬프가 어떻게 사용되는지에 대해서는 [기록 및 .daq 형식](recording.md)을 참조하십시오.
