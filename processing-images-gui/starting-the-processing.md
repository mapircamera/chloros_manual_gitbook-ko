# 처리 시작

이미지를 가져오고, 보정 대상을 표시하고, 프로젝트 설정을 구성했다면 이제 처리를 시작할 준비가 된 것입니다. 이 페이지는 Chloros 처리 파이프라인을 시작하는 과정을 안내합니다.

## 전처리 체크리스트

시작 버튼을 클릭하기 전에 모든 준비가 완료되었는지 확인하십시오:

* [ ] **파일 가져오기 완료** - 파일 브라우저에 모든 이미지가 표시됨
* [ ] **표적 이미지 표시** - 보정 이미지의 표적 열이 선택됨
* [ ] **카메라 모델 감지** - 카메라 모델 열에 올바른 카메라가 표시됨
* [ ] **설정 구성** - 프로젝트 설정을 검토하고 조정함
* [ ] **지수 선택** - 필요한 경우 원하는 다중 스펙트럼 지수 추가
* [ ] **내보내기 형식 선택** - 워크플로우에 적합한 출력 형식 선택

{% hint style="info" %}
**팁**: 처리 전에 파일 브라우저에서 몇 개의 이미지를 클릭하여 올바르게 로드되었는지 확인하십시오.
{% endhint %}

***

## 처리 시작

### 시작 버튼 찾기

시작/재생 버튼은 Chloros의 상단 헤더 바에 있습니다:

* 위치: 창 상단 중앙
* 아이콘: **재생/시작 버튼** <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line">
* 상태: 처리 준비가 되면 버튼이 활성화(밝게)됩니다

### 클릭하여 시작

1. 상단 헤더의 **재생/시작 버튼**을 클릭합니다
2. 처리가 즉시 시작됩니다
3. 처리 중에는 버튼이 비활성화(회색)됩니다
4. 진행률 표시줄이 업데이트되어 처리 상태를 보여줍니다

{% hint style="success" %}
**처리 시작**: 클릭하면 Chloros가 대상 감지, 디베이어링, 보정, 인덱스 계산 및 내보내기를 포함한 모든 처리 단계를 자동으로 처리합니다.
{% endhint %}

## 처리 모드 이해

Chloros는 라이선스에 따라 두 가지 다른 처리 모드로 작동합니다:

### 무료 모드 (순차 처리)

**모든 사용자가 이용 가능**

**작동 방식:**

* 이미지를 한 번에 하나씩 순차적으로 처리합니다
* 단일 스레드 작업
* 메모리 사용량이 적습니다

**진행률 표시줄은 2단계를 보여줍니다:**

1.**타겟 감지** - 보정 타겟 스캔
2. **처리** - 보정 적용 및 이미지 내보내기**처리 시간:**

* Chloros+ 병렬 모드보다 훨씬 느림
* 중소 규모 데이터셋(200장 미만)에 적합

### Chloros+ 모드 (병렬 처리)

**Chloros+ 라이선스 필요**

**작동 방식:**

* [4스레드 처리 파이프라인](../processing-architecture/processing-pipeline.md)을 사용하여 여러 이미지를 동시에 처리합니다
* [동적 컴퓨팅 적응](../processing-architecture/dynamic-compute-adaptation.md) 기능이 하드웨어에 최적화된 전략을 자동으로 선택합니다
* NVIDIA 그래픽 카드(데스크톱 및 Jetson)를 통한 GPU(CUDA) 가속 지원
* Jetson Nano(1개 워커)부터 12GB 이상 GPU를 탑재한 데스크톱(3~4개 워커)까지 확장 가능

**진행률 표시줄은 4단계로 표시됩니다** (4개의 파이프라인 스레드에 해당):

1. **탐지** (스레드 1) - 보정 대상 찾기
2. **분석** (스레드 2) - 이미지 메타데이터 검토 및 보정 계산
3. **보정** (스레드 3) - GPU 디베이어링, 비네팅 보정, 인덱스 계산
4. **내보내기** (스레드 4) - 처리된 이미지와 인덱스 저장**진행률 표시줄 상호작용:*** **마우스를** 표시줄 위에 올리면 4단계 상세 드롭다운 패널이 표시됩니다
* **진행률 표시줄을 클릭**하면 드롭다운 패널이 고정됩니다
* **다시 클릭**하면 패널이 해제되고 숨겨집니다**처리 시간:**

* 무료 모드보다 훨씬 빠름
* CPU 코어 수에 따라 처리 속도가 향상됨
* GPU 가속을 통해 속도가 더욱 향상됨

{% hint style="info" %}
**Chloros+ 속도**: 대규모 데이터셋의 경우 병렬 처리가 순차 모드보다 5~10배 더 빠를 수 있습니다. 무료 모드에서 2시간이 소요되는 500장 이미지 프로젝트가 Chloros+를 사용하면 15~20분 내에 완료될 수 있습니다.
{% endhint %}

## 처리 과정

### 1단계: 대상 탐지

**Chloros의 기능:**

* 표시된 대상 이미지를 스캔합니다(표시된 이미지가 없는 경우 모든 이미지를 스캔함)
* 각 타겟 내 4개의 보정 패널을 식별합니다
* 타겟 패널에서 반사율 값을 추출합니다
* 보정 일정을 위해 타겟 타임스탬프를 기록합니다

**소요 시간:** 1~30초(표시된 타겟의 경우), 5~30분 이상(표시되지 않은 경우)

### 2단계: 디베이어링(RAW 변환)

**Chloros의 기능:**

* RAW 베이어 패턴 데이터를 완전한 RGB 이미지로 변환
* 고품질 디모자이징 알고리즘 적용
* 최대 이미지 품질 및 디테일 유지

**소요 시간:** 이미지 수 및 CPU 속도에 따라 다름

### 3단계: 보정

**Chloros의 기능:*** **비네팅 보정**: 가장자리의 렌즈 어두워짐 현상 제거
* **반사율 보정**: 기준 반사율 값을 사용하여 정규화
* 모든 대역/채널에 보정 적용
* 타임스탬프에 따라 각 이미지에 적합한 보정 타겟 사용

**소요 시간:** 전체 처리 시간의 대부분

### 4단계: 지수 계산

**Chloros의 기능:**

* 구성된 다중 스펙트럼 지수(NDVI, NDRE 등)를 계산합니다
* 보정된 이미지에 밴드 연산을 적용합니다
* 선택된 각 지수에 대한 지수 이미지를 생성합니다

**소요 시간:** 이미지당 몇 초

### 5단계: 내보내기

**Chloros의 기능:**

* 보정된 이미지를 선택한 형식으로 저장합니다
* 구성된 LUT 색상을 적용하여 지수 이미지를 내보냅니다
* 파일을 카메라 모델 하위 폴더에 저장합니다
* 접미사를 추가하여 원본 파일명을 유지합니다

**소요 시간:** 내보내기 형식과 파일 크기에 따라 다름***

## 처리 동작

### 자동 처리 파이프라인

시작되면 전체 파이프라인이 자동으로 실행됩니다:

* 사용자 개입이 필요하지 않습니다
* 구성된 모든 단계가 순차적으로 실행됩니다
* 진행 상황이 실시간으로 표시됩니다

### 처리 중 컴퓨터 사용량

**자유 모드:**

* 비교적 낮은 CPU 사용량 (단일 스레드)
* 다른 작업 수행 시 컴퓨터 반응 속도 유지
* Chloros 창을 최소화하고 다른 애플리케이션에서 작업해도 안전함

**Chloros+ 병렬 모드:**

* 높은 CPU 사용량 (멀티 스레드, 최대 16코어)
* GPU 가속 사용 시: 높은 GPU 사용량
* 처리 중 컴퓨터 반응이 느려질 수 있음
* 다른 CPU 집약적인 작업 실행을 피하십시오

{% hint style="warning" %}
**성능 팁**: 최상의 Chloros+ 성능을 위해 다른 응용 프로그램을 닫고 Chloros가 시스템 자원을 모두 사용할 수 있도록 하십시오.
{% endhint %}

### 처리는 일시 중지할 수 없습니다

**중요한 제한 사항:**

* 처리가 시작되면 일시 중지할 수 없습니다
* 처리를 취소할 수는 있지만 진행 상황은 사라집니다
* 부분적인 결과는 저장되지 않습니다
* 취소 시 처음부터 다시 시작해야 합니다

**계획 팁:** 매우 큰 프로젝트의 경우, 더 나은 제어를 위해 일괄 처리하거나 CLI를 사용하는 것을 고려하십시오.***

## 처리 모니터링

처리가 실행되는 동안 다음을 수행할 수 있습니다:

* **진행률 표시줄 확인** - 전체 완료율 확인
* **현재 단계 보기** - 검출, 분석, 보정 또는 내보내기
* **로그 탭 확인** - 자세한 처리 메시지와 경고 확인
* **완료된 이미지 미리 보기** - 처리 중에 일부 내보내기 파일이 표시될 수 있음

모니터링에 대한 자세한 내용은 [처리 모니터링](monitoring-the-processing.md)을 참조하십시오.

## 처리 취소

처리를 중지해야 하는 경우:

### 취소 방법

1. **중지/취소 버튼**을 찾습니다(처리 중에는 시작 버튼으로 표시됨).
2. 중지 버튼을 클릭합니다.
3. 처리가 즉시 중단됩니다.
4. 부분적인 결과는 삭제됩니다.

### 취소 시점

**취소할 수 있는 타당한 사유:**

* 잘못된 설정이 사용되었음을 확인한 경우
* 대상 이미지를 표시하는 것을 잊은 경우
* 잘못된 이미지를 가져온 경우
* 시스템이 너무 느리거나 응답하지 않는 경우

**취소 후:**

* 문제를 검토하고 수정하십시오
* 필요에 따라 설정을 조정하십시오
* 처음부터 처리를 다시 시작하십시오
* 가장 원활한 환경을 위해 Chloros를 완전히 종료하고 다시 시작하십시오

{% hint style="warning" %}
**부분 결과 없음**: 취소를 하면 진행 상황이 모두 삭제됩니다. Chloros는 부분적으로 처리된 이미지를 저장하지 않습니다.
{% endhint %}

## 예상 처리 시간

실제 처리 시간은 다음 요소에 따라 크게 달라집니다:

* 이미지 수
* 이미지 해상도
* RAW 대 JPG 입력 형식
* 처리 모드 (무료 버전 vs Chloros+)
* CPU 속도 및 코어 수
* GPU 사용 가능 여부 (Chloros+ 전용)
* 계산해야 할 인덱스 수
* 내보내기 형식의 복잡도

### 대략적인 예상 시간 (Chloros+, 12MP 이미지, 최신 CPU 기준)

| 이미지 수 | 무료 모드 | Chloros+ (CPU) | Chloros+ (GPU) |
| ----------- | --------- | -------------- | -------------- |
| 50개 이미지   | 15-20분 | 5-8분        | 3-5분        |
| 100개 이미지  | 30-40분 | 10-15분      | 5-8분        |
| 200개 이미지  | 1-1.5시간 | 20-30분      | 10-15분      |
| 500개 이미지  | 2~3시간   | 45~60분      | 20~30분      |
| 1000개 이미지 | 4~6시간   | 1.5~2시간      | 40~60분      |

{% hint style="info" %}
**첫 실행**: Chloros가 캐시와 프로필을 구축하는 동안 초기 처리 시간이 더 오래 걸릴 수 있습니다. 이후 유사한 데이터셋을 처리할 때는 속도가 빨라집니다.
{% endhint %}

## 시작 시 자주 발생하는 문제

### 시작 버튼 비활성화(회색으로 표시됨)

**가능한 원인:**

* 이미지가 가져오지 않음
* 백엔드가 완전히 시작되지 않음
* 이전 처리가 아직 실행 중임
* 프로젝트가 완전히 로드되지 않음

**해결 방법:**

1. 백엔드가 완전히 초기화될 때까지 기다립니다(메인 메뉴 아이콘 확인).
2. 파일 브라우저에서 이미지가 가져오기되었는지 확인합니다.
3. 버튼이 여전히 비활성화되어 있다면 Chloros를 다시 시작합니다.
4. 디버그 로그에서 오류 메시지를 확인합니다.

### 처리가 시작되자마자 즉시 실패함

**가능한 원인:**

* 프로젝트에 유효한 이미지가 없음
* 이미지 파일이 손상됨
* 디스크 공간 부족
* 메모리(RAM) 부족

**해결 방법:**

1. 디버그 로그에서 <img src="../.gitbook/assets/icon_log.JPG" alt="" data-size="line"> 2. 사용 가능한 디스크 공간 확인
3. 더 적은 수의 이미지 집합으로 처리 시도
4. 이미지가 손상되지 않았는지 확인

### &quot;타겟 감지되지 않음&quot; 경고

**가능한 원인:**

* 타겟 이미지를 표시하는 것을 잊음
* 타겟 이미지에 가시적인 타겟이 없음
* 타겟 감지 설정이 너무 엄격함

**해결 방법:**

1. [타겟 이미지 선택](choosing-target-images.md)을 검토하십시오
2. &#x27;타겟&#x27; 열에서 적절한 이미지를 표시하십시오
3. 표시된 이미지에서 타겟이 보이는지 확인하십시오
4. 필요한 경우 타겟 감지 설정을 조정하십시오

## 성공적인 처리를 위한 팁

### 시작 전

1. **먼저 소량의 이미지로 테스트** - 10~20장의 이미지를 처리하여 설정을 확인하십시오
2. **사용 가능한 디스크 공간 확인** - 데이터셋 크기의 2~3배에 해당하는 여유 공간을 확보하십시오
3. **불필요한 애플리케이션 종료** - 시스템 리소스를 확보하십시오
4. **대상 이미지 확인** - 표시된 대상을 미리 보아 품질을 확인하십시오
5. **프로젝트 저장** - 프로젝트는 자동 저장되지만, 수동으로 저장하는 것이 좋습니다

### 처리 중

1. **시스템 절전 모드 방지** - 절전 모드를 비활성화하십시오
2. **Chloros를 전경에 두십시오** - 또는 최소한 작업 표시줄에 보이도록 하십시오
3. **진행 상황을 수시로 확인하십시오** - 경고나 오류가 있는지 확인하십시오
4. **다른 리소스 소모가 큰 애플리케이션 실행 금지** - 특히 Chloros+ 병렬 모드 사용 시

### Chloros+ GPU 가속

NVIDIA GPU 가속을 사용하는 경우:

1. NVIDIA 드라이버를 최신 버전으로 업데이트
2. GPU에 4GB 이상의 VRAM이 있는지 확인
3. GPU를 많이 사용하는 애플리케이션(게임, 동영상 편집)을 종료하십시오
4. GPU 온도를 모니터링하십시오(적절한 냉각 상태 유지)
