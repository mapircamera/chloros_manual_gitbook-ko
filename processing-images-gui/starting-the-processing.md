# 처리 시작

이미지를 가져오고, 보정 대상을 표시하고, 프로젝트 설정을 완료했다면 이제 처리를 시작할 준비가 된 것입니다. 이 페이지에서는 Chloros 처리 파이프라인을 시작하는 방법을 안내합니다.

## 전처리 체크리스트

시작 버튼을 클릭하기 전에 모든 준비가 완료되었는지 확인하십시오:

* [ ] **파일 가져오기 완료** - 모든 이미지가 파일 브라우저에 표시됨
* [ ] **타겟 이미지 표시** - 보정 이미지의 ‘타겟’ 열이 선택되어 있음(또는 LATTICE용 `.daq` 기록 파일 가져오기 완료)
* [ ] **카메라 모델 감지** - ‘카메라 모델’ 열에 올바른 카메라가 표시됨
* [ ] **설정 구성 완료** - 프로젝트 설정을 검토하고 조정했습니다
* [ ] **지수 선택 완료** - 필요한 경우 원하는 다중 스펙트럼 지수를 추가했습니다
* [ ] **내보내기 형식 선택 완료** - 워크플로우에 적합한 출력 형식을 선택했습니다

{% hint style="info" %}
**팁**: 처리하기 전에 파일 브라우저에서 몇 개의 이미지를 클릭하여 올바르게 로드되었는지 확인하십시오.
{% endhint %}

***

## 처리 시작

### 시작 버튼 찾기

시작/재생 버튼은 Chloros의 상단 헤더 바에 있습니다:

* 위치: 창 상단 중앙
* 아이콘: **재생/시작 버튼** <img src="../.gitbook/assets/image (2) (1) (1).png" alt="" data-size="line">
* 상태: 처리 준비가 되면 버튼이 활성화(밝게 표시)됩니다

### 클릭하여 시작하기

1. 상단 헤더의 **재생/시작 버튼**을 클릭합니다.
2. 처리가 즉시 시작됩니다.
3. 처리 중에는 버튼이 **중지** 버튼으로 바뀝니다.
4. 진행률 표시줄이 업데이트되어 처리 상태를 보여줍니다.

{% hint style="success" %}
**처리 시작**: 클릭하면 Chloros가 대상 감지, 디베이어링, 보정, 인덱스 계산 및 내보내기 등 모든 처리 단계를 자동으로 처리합니다. 프로젝트가 Survey3, LATTICE 또는 혼합형인지 자동으로 감지하여 각 카메라에 적합한 파이프라인을 적용합니다.
{% endhint %}

## 처리 모드 이해

Chloros는 라이선스에 따라 두 가지 다른 처리 모드로 작동합니다:

### 무료 모드 (순차 처리)

**모든 사용자가 이용 가능**

**작동 방식:**

* 이미지를 한 번에 하나씩 순차적으로 처리합니다.
* 단일 스레드 방식으로 작동합니다.
* 메모리 사용량이 적습니다.

**진행률 표시줄은 다음 두 단계를 보여줍니다:**

1.**타겟 감지** - 보정 타겟 스캔
2. **처리** - 보정 적용 및 이미지 내보내기**처리 시간:**

* Chloros+ 병렬 모드보다 훨씬 느림
* 중소 규모 데이터셋(200장 미만)에 적합

### Chloros+ 모드 (병렬 처리)

**Chloros+ 라이선스가 필요합니다**

**작동 방식:**

* [4스레드 처리 파이프라인](../processing-architecture/processing-pipeline.md)을 사용하여 여러 이미지를 동시에 처리합니다
* [동적 연산 적응(Dynamic Compute Adaptation)](../processing-architecture/dynamic-compute-adaptation.md) 기능이 실행 시작 시 하드웨어에 최적화된 전략을 자동으로 선택합니다
* NVIDIA 그래픽 카드(데스크톱 및 Jetson)를 활용한 GPU(CUDA) 가속
* **워커 수는 하드웨어에 따라 자동으로 조정됩니다**: GPU 전략은**1~4개의 동시 워커**를 실행합니다(VRAM 용량에 따라 조정됨 — 메모리가 적은 Jetson은 1개, 12GB 이상의 데스크톱 GPU는 최대 4개까지 실행). CPU 전용 시스템은 물리적 코어당 1개의 워커를 실행하며, 여기서 1개를 뺍니다**진행률 표시줄은 4단계로 표시됩니다** (4개의 파이프라인 스레드에 해당):

1. **탐지** (스레드 1) - 보정 대상 찾기
2. **분석** (스레드 2) - 이미지 메타데이터 검토 및 보정 계산
3. **보정** (스레드 3) - 디베이어링, 비네팅 보정, 보정, 인덱스 계산
4. **내보내기** (스레드 4) - 처리된 이미지와 인덱스 저장**진행률 표시줄 상호작용:*** 진행률 바 위에 **마우스를 올리기**: 4단계로 구성된 상세 드롭다운 패널이 표시됩니다.
* 진행률 바를 **클릭**: 드롭다운 패널을 고정합니다.
* **다시 클릭**: 패널 고정 해제 및 숨기기**처리 시간:**

* 무료 모드보다 훨씬 빠릅니다.
* GPU 가속을 통해 속도가 더욱 향상됩니다

{% hint style="info" %}
**Chloros+ 속도**: 대용량 데이터셋의 경우 병렬 처리가 순차 모드보다 5~10배 더 빠를 수 있습니다. 무료 모드에서 2시간이 소요되는 500장 규모의 프로젝트도 Chloros+를 사용하면 15~20분 내에 완료될 수 있습니다.
{% endhint %}

## 처리 과정

### 1단계: 대상 탐지

**Chloros의 기능:**

* ‘대상(Target)’ 열에서 선택한 이미지를 스캔합니다(선택한 이미지가 없는 경우 모든 이미지를 스캔합니다).
* 각 타겟에서 보정 패널을 식별합니다
* 타겟 패널에서 반사율 값을 추출합니다
* 보정 일정을 위해 타겟 타임스탬프를 기록합니다

**소요 시간:** 1~30초(타겟이 표시된 경우), 5~30분 이상(타겟이 표시되지 않은 경우)

### 2단계: 디베이어링 (RAW 변환)

**Chloros의 기능:**

* RAW 베이어 패턴 데이터를 완전한 3채널 이미지로 변환합니다(LATTICE 모노 모듈은 단일 대역으로 유지되며, 이 경우 데베이어링이 건너뛰어지고 로그에 관련 메모가 남습니다)
* 선택된 디모자이징 알고리즘을 적용합니다
* 최대의 이미지 품질과 디테일을 보존합니다

**소요 시간:** 이미지 수와 CPU/GPU 속도에 따라 다름

### 3단계: 보정

**Chloros의 기능:*** **비네팅 보정**: 가장자리의 렌즈 어두워짐 현상 제거
* **반사율 보정**: 목표 반사율 값 및/또는 DAQ 하향 데이터(downwelling data)를 사용하여 정규화
* 모든 대역/채널에 보정 적용
* 타임스탬프를 기반으로 각 이미지에 적합한 보정 기준 사용

**소요 시간:** 처리 시간의 대부분을 차지함

### 4단계: 지수 계산

**Chloros의 기능:**

* 구성된 다중 스펙트럼 지수(NDVI, NDRE 등)를 계산합니다.
* 보정된 이미지에 밴드 연산을 적용합니다.
* 선택된 각 지수에 대한 지수 이미지를 생성합니다.

**소요 시간:** 이미지당 몇 초

### 5단계: 내보내기

**Chloros의 기능:**

* 처리된 이미지를 선택한 형식으로 저장합니다
* **LATTICE 팬아웃**: 각 원시 LATTICE 프레임은 한 번의 처리 과정으로 활성화된 모든 산출물(디베이어링, 미리보기, 방사도(항상 float32), 반사도)로 내보내집니다.
* 프로젝트 출력 트리에 파일을 작성합니다: `<project>/<camera>/<format>/<Product>_Images/`
* **원본 파일명을 유지** — 폴더명이 산출물을 식별하므로 접미사가 추가되지 않습니다**소요 시간:** 내보내기 형식과 파일 크기에 따라 다름***

## 처리 방식

### 자동 처리 파이프라인

시작되면 전체 파이프라인이 자동으로 실행됩니다:

* 사용자 개입이 필요하지 않습니다
* 구성된 모든 단계가 순차적으로 실행됩니다
* 진행 상황이 실시간으로 표시됩니다
* 내보낸 파일은 완료되는 대로 디스크에 저장됩니다 — 실행이 계속되는 동안에도 완료된 출력 파일을 열 수 있습니다

### 처리 중 컴퓨터 사용 현황

**자유 모드:**

* CPU 사용량이 비교적 낮음 (단일 스레드)
* 다른 작업을 수행하는 데 컴퓨터 반응성이 유지됩니다
* Chloros 창을 최소화하고 다른 애플리케이션에서 작업해도 안전합니다

**Chloros+ 병렬 모드:**

* 전략의 워커 풀 전반에 걸쳐 CPU 사용량이 높음
* GPU 가속 사용 시: GPU 사용량이 높음
* 처리 중에는 컴퓨터 반응 속도가 느려질 수 있음
* 다른 CPU 집약적 작업의 실행을 피하십시오

{% hint style="warning" %}
**성능 팁**: Chloros+의 성능을 최적화하려면 다른 애플리케이션을 닫고 Chloros가 시스템 자원을 온전히 사용할 수 있도록 하십시오.
{% endhint %}

### 처리는 일시 중지할 수 없습니다(단, 중지는 정상적으로 수행됩니다)

* 일단 시작되면 처리를 일시 중지했다가 나중에 다시 재개할 수 없습니다
* **중지**를 클릭하면 첫 번째 클릭 시 실행이 정상적으로 중지됩니다
* 중지 전에 이미 내보낸 결과물은 디스크에 남아 있습니다
* 중지된 실행은 완료된 내용을 정확히 보고합니다 (로그의 `[RUN-SUMMARY]` 줄 참조)
* 새로운 실행은 파이프라인을 처음부터 시작합니다

**계획 시 참고 사항:** 매우 큰 프로젝트의 경우, 더 나은 제어를 위해 일괄 처리하거나 CLI를 사용하는 것을 고려하십시오.***

## 처리 모니터링

처리 실행 중에는 다음 작업을 수행할 수 있습니다:

* **진행률 표시줄 확인** - 전체 완료율을 확인합니다
* **현재 단계 확인** - 탐지, 분석, 보정 또는 내보내기
* **로그 탭 확인** - 자세한 처리 메시지와 경고 사항을 확인합니다
* **완료된 이미지 미리 보기** - 처리 중에 내보낸 파일이 디스크에 표시됩니다

모니터링에 대한 자세한 내용은 [처리 모니터링](monitoring-the-processing.md)을 참조하십시오.

## 처리 중지

처리를 중지해야 하는 경우:

### 중지 방법

1. **중지 버튼**을 찾습니다(처리 중에는 시작 버튼으로 대체됨).
2. 버튼을 한 번 클릭하면, 진행 바에 **&quot;중지 중...&quot;**이 표시되며, 처리 중인 이미지가 완료됩니다
3. 실행이 완전히 중지된 상태로 종료되며, 로그에는 완료된 작업에 대한 정확한 `[RUN-SUMMARY]` 정보가 출력됩니다

### 중지해야 할 때

**중지해야 할 타당한 사유:**

* 잘못된 설정이 사용되었음을 확인한 경우
* 대상 이미지를 표시하는 것을 잊은 경우
* 잘못된 이미지를 가져온 경우
* 시스템이 너무 느리거나 응답하지 않는 경우

**중지 후:**

* 중지 전에 내보낸 결과물은 디스크에 그대로 남아 있습니다
* 문제를 검토 및 수정하고, 필요에 따라 설정을 조정하십시오
* 처리를 다시 시작하면 — 처리가 처음부터 시작됩니다

## 예상 처리 시간

실제 처리 시간은 다음 요인에 따라 크게 달라집니다:

* 이미지 수
* 이미지 해상도
* 입력 형식(RAW 대 JPG)
* 처리 모드(Free 대 Chloros+)
* CPU 속도 및 코어 수
* GPU 사용 가능 여부 (Chloros+ 전용)
* 계산할 인덱스 수
* 활성화된 내보내기 제품 수 (LATTICE)

### 대략적인 예상 시간 (Chloros+, 12MP 이미지, 최신 CPU 기준)

| 이미지 수 | 무료 모드 | Chloros+ (CPU) | Chloros+ (GPU) |
| ----------- | --------- | -------------- | -------------- |
| 50개 이미지   | 15~20분 | 5~8분        | 3~5분        |
| 100장   | 30~40분 | 10~15분      | 5~8분        |
| 200장   | 1~1.5시간 | 20~30분      | 10~15분      |
| 이미지 500장  | 2~3시간   | 45~60분      | 20~30분      |
| 이미지 1000장 | 4~6시간   | 1.5~2시간      | 40~60분      |

{% hint style="info" %}
**첫 실행**: Chloros가 캐시와 프로필을 생성하는 과정에서 초기 처리 시간이 더 오래 걸릴 수 있습니다. 이후 유사한 데이터 세트를 처리할 때는 속도가 빨라집니다.
{% endhint %}

## 시작 시 자주 발생하는 문제

### 시작 버튼이 비활성화됨(회색으로 표시됨)

**가능한 원인:**

* 이미지가 가져오지 않음
* 백엔드가 완전히 시작되지 않음
* 이전 처리가 아직 진행 중임
* 프로젝트가 완전히 로드되지 않음

**해결 방법:**

1. 백엔드가 완전히 초기화될 때까지 기다립니다(메인 메뉴 아이콘 확인).
2. 파일 브라우저에서 이미지가 가져와졌는지 확인합니다.
3. 버튼이 여전히 비활성화된 상태라면 Chloros를 다시 시작합니다.
4. 디버그 로그에서 오류 메시지를 확인합니다.

### 처리가 시작되지만 즉시 실패함

**가능한 원인:**

* 프로젝트에 유효한 이미지가 없음
* 이미지 파일이 손상됨
* 디스크 공간이 부족함
* 메모리(RAM)가 부족함

**해결 방법:**

1. 디버그 로그<img src="../.gitbook/assets/icon_log.JPG" alt="" data-size="line">에서 오류 메시지 확인
2. 사용 가능한 디스크 공간 확인
3. 더 적은 수의 이미지 집합으로 처리를 시도
4. 이미지가 손상되지 않았는지 확인

### 실행은 완료되었으나 이미지가 기록되지 않음

이미지 산출물을 요청했으나 아무것도 기록하지 않은 실행은 **성공이 아닌 실패**로 간주됩니다. Chloros 오류 코드가 이를 명확히 알립니다:

* GUI 로그에는 `[RUN-SUMMARY]`와 같은 메시지가 출력되며, 이는 가능한 원인(이미지 가져오기 실패, 대상 미탐지, 또는 요청된 모든 산출물이 해당되지 않아 건너뛴 경우 등)을 암시합니다(예: RGB 전용 카메라에서 복사율/반사율 산출을 요청한 경우).
* CLI에 해당하는 버전(`chloros-cli process`)은 `Processing finished but wrote no image products.`를 출력하고 **0이 아닌 종료 코드**를 반환하므로, 스크립트를 통해 이를 감지할 수 있습니다
* 의도적으로 메타데이터만 처리하는 실행(모든 내보내기 결과물 비활성화, 인덱스 없음)도 성공으로 간주됩니다.

전체 의미론에 대해서는 [CLI 참조 문서](../reference/cli-reference.md#a-run-that-writes-no-images-fails)를 참조하십시오.

### &quot;표적 미탐지&quot; 경고

**가능한 원인:**

* 표적 이미지를 표시하는 것을 잊었습니다.
* 표적 이미지에 가시적인 표적이 포함되어 있지 않습니다.
* 표적 탐지 설정이 너무 엄격합니다.

**해결 방법:**

1. [타겟 이미지 선택](choosing-target-images.md)을 검토하세요.
2. &#x27;타겟&#x27; 열에서 적절한 이미지에 표시를 하세요.
3. 표시된 이미지에서 타겟이 가시적으로 확인되는지 확인하세요.
4. 필요한 경우 타겟 감지 설정을 조정하세요.

## 성공적인 처리를 위한 팁

### 시작 전

1. **먼저 소규모 데이터 세트로 테스트하기** - 10~20장의 이미지를 처리하여 설정을 확인하십시오
2. **사용 가능한 디스크 공간 확인하기** - 데이터 세트 크기의 2~3배에 해당하는 여유 공간을 확보하십시오(모든 LATTICE 제품이 활성화된 경우 더 많은 공간이 필요함)
3. **불필요한 애플리케이션 닫기** - 시스템 리소스를 확보하십시오
4. **표적 이미지 확인** - 표시된 표적을 미리 보아 품질을 확인하십시오
5. **프로젝트 저장** - 프로젝트는 자동 저장되지만, 수동으로 저장하는 것이 좋습니다

### 처리 중

1. **시스템 절전 모드 방지** - 절전 모드를 비활성화하십시오
2. **Chloros를 전경에 유지** - 또는 최소한 작업 표시줄에 보이도록 하십시오
3. **진행 상황을 수시로 확인** - 경고나 오류가 있는지 확인하십시오
4. **다른 리소스 소모가 큰 응용 프로그램을 실행하지 마십시오** - 특히 Chloros+ 병렬 모드 사용 시

### Chloros+ GPU 가속

NVIDIA GPU 가속을 사용하는 경우:

1. NVIDIA 드라이버를 최신 버전으로 업데이트하십시오
2. GPU에 4GB 이상의 VRAM이 있는지 확인하십시오 (동시 텍스처 인식 디베이어링의 경우 7GB 이상)
3. GPU 부하가 큰 애플리케이션(게임, 동영상 편집)을 닫으십시오
4. GPU 온도를 모니터링하십시오 (적절한 냉각이 이루어지도록 하십시오)
