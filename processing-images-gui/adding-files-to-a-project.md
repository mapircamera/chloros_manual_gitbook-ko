# 프로젝트에 파일 추가하기

Chloros에서 프로젝트를 생성하거나 열었다면, 다음 단계는 다중 스펙트럼 이미지를 추가하여 처리를 시작하는 것입니다. ‘파일 브라우저’<img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> 탭을 사용하면 이미지를 쉽게 가져오고 데이터 세트를 관리할 수 있습니다.

## 파일 브라우저 열기

1. Chloros에서 프로젝트를 열거나 생성합니다.
2. 왼쪽 사이드바에서 **파일 브라우저** <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> 아이콘을 클릭합니다
3. 파일 브라우저 패널에 프로젝트의 파일 목록이 표시됩니다

{% hint style="info" %}
**지원되는 파일 형식**: Chloros는 MAPIR, Survey3W 및 Survey3N 카메라의 RAW+JPG 및 JPG 이미지 파일을 지원합니다. RAW+JPG 형식만 권장됩니다.
{% endhint %}

***

## 프로젝트에 이미지 추가하기

프로젝트에 이미지를 추가하는 주요 방법은 두 가지입니다:

### 방법 1: 파일 추가

이 옵션을 사용하여 개별 이미지 파일이나 소량의 파일을 가져올 수 있습니다.

1. 파일 브라우저 패널 상단의 **&quot;파일 추가&quot;** <img src="../.gitbook/assets/image.png" alt="" data-size="line"> 버튼을 클릭합니다
2. 이미지가 있는 폴더로 이동합니다
3. 하나 이상의 이미지 파일을 선택합니다(**Ctrl** 키를 누른 상태에서 여러 파일을 선택)
4. **&quot;열기&quot;**를 클릭하여 선택한 파일을 가져옵니다

### 방법 2: 폴더 추가

이 옵션을 사용하여 폴더에 있는 모든 이미지를 한 번에 가져옵니다.

1. 파일 브라우저 패널 상단의 **&quot;폴더 추가&quot;** <img src="../.gitbook/assets/image (1).png" alt="" data-size="line"> 버튼을 클릭하세요
2. 촬영 세션 이미지가 들어 있는 폴더로 이동하여 선택하세요
3. **&quot;폴더 선택&quot;**을 클릭하여 해당 폴더의 지원되는 모든 이미지를 가져오세요***

## 파일 브라우저 테이블 이해하기

이미지가 가져오면 다음 열로 구성된 테이블에 표시됩니다:

### 파일 이름

* 카메라의 원본 파일 이름
* 카메라의 명명 규칙을 유지합니다(예: IMG\_0001.RAW)

### 타임스탬프

* 이미지가 촬영된 날짜 및 시간
* 이미지 EXIF 메타데이터에서 추출됨
* PPK 동기화 및 보정 타겟 감지에 사용됨

### 카메라 모델

* 카메라 및 필터 구성을 자동으로 감지
* 예시: Survey3W\_RGN, Survey3N\_OCN, Survey3W\_RGB
* 올바른 처리 프로필을 적용하는 데 사용

### 타겟 열 (체크박스)

* 보정 타겟이 포함된 이미지의 경우 이 상자를 선택하십시오
* 처리 중 타겟 감지 속도를 크게 높여줍니다
* 자세한 내용은 [타겟 이미지 선택](choosing-target-images.md)을 참조하십시오

### 이미지 메타데이터 보기

표 상단 오른쪽 모서리에 있는 토글 버튼을 클릭하면 이미지 그리드 영역에 선택한 이미지의 메타데이터가 표시됩니다.

## 프로젝트 내 파일 관리

### 파일 제거

프로젝트에서 원하지 않는 이미지를 제거하려면:

1. 파일 브라우저 테이블에서 하나 이상의 이미지를 선택합니다
2. **&quot;선택 항목 제거&quot;** <img src="../.gitbook/assets/image (2).png" alt="" data-size="line"> 버튼을 클릭합니다
3. 제거를 확인합니다(파일은 디스크에서 삭제되지 않고 프로젝트에서만 제거됩니다)

### 정렬 및 필터링

* **열별 정렬**: 열 머리글을 클릭하여 이미지를 정렬합니다
* **타임스탬프 정렬**: 촬영 시계열을 정리하는 데 유용합니다
* **카메라 모델 필터**: 여러 대의 카메라를 사용하는 경우 카메라 유형별로 이미지를 그룹화합니다***

## 이미지 미리 보기

### 전체 이미지 보기

파일 브라우저에서 이미지 썸네일을 클릭하면 메인 미리 보기 영역에 표시됩니다:

1. 이미지가 중앙 미리 보기 패널에 나타납니다
2. 확대/축소 컨트롤을 사용하여 이미지 세부 사항을 확인합니다
3. 화살표 키를 사용하여 이미지를 이동합니다

### 빠른 탐색

* **이전 이미지**: 왼쪽 화살표 클릭 또는 ← 키 누르기
* **다음 이미지**: 오른쪽 화살표를 클릭하거나 → 키를 누르세요
* **확대/축소**: 마우스 휠이나 확대/축소 버튼을 사용하세요
* **이동**: 확대된 상태에서 이미지를 클릭하고 드래그하세요***

## 중복 파일 처리

Chloros는 중복 파일을 자동으로 감지하여 무시합니다:

* 파일 이름이 동일한 파일은 건너뜁니다
* 실수로 인한 중복 처리를 방지합니다
* 중복 파일이 감지되면 경고 메시지가 표시됩니다

{% hint style="warning" %}
**중요**: 가져오기 전에 원본 이미지 파일의 이름을 변경하거나 수정하지 마십시오. Chloros는 올바른 처리를 위해 원본 파일 이름과 메타데이터에 의존합니다.
{% endhint %}

***

## 다양한 카메라로 구성된 데이터 세트

프로젝트에 여러 대의 MAPIR 카메라에서 촬영된 이미지가 포함된 경우:

1. Chloros는 각 카메라 모델을 자동으로 감지합니다
2. 각 카메라 유형은 해당 보정 프로필을 사용하여 처리됩니다
3. 파일 브라우저의 &#x27;카메라 모델&#x27; 열에 카메라 모델이 표시됩니다
4. 처리 과정에서 각 카메라 유형에 맞는 올바른 설정이 적용됩니다

**예시 시나리오**: Survey3W RGN + Survey3N OCN 듀얼 카메라 구성***

## 모범 사례

### 가져오기 전 정리

* 보정 타겟 이미지를 측량 이미지와 동일한 폴더에 보관하십시오
* 카메라/SD 카드의 원래 폴더 구조를 유지하십시오
* 서로 다른 세션의 데이터 세트를 하나의 프로젝트에 혼합하지 마십시오

### 파일 이름 지정

* 원래 카메라 파일 이름(IMG\_0001.RAW 등)을 유지하십시오
* 가져오기 전에 파일 이름을 변경하지 마십시오
* 원본 이름에는 중요한 메타데이터가 포함되어 있습니다

### 보정 타겟 이미지

* 세션당 항상 1~2장의 보정 타겟 이미지를 포함하십시오
* 촬영 세션 전후에 타겟을 촬영하십시오
* 타겟을 촬영 영역과 동일한 조명 조건에 배치하십시오
* 처리 속도를 높이기 위해 &#x27;타겟&#x27; 체크박스를 사용하여 타겟 이미지를 표시하십시오

## 일반적인 문제 및 해결 방법

### 가져오기 후 이미지가 표시되지 않는 경우

**가능한 원인:**

* 지원되지 않는 파일 형식 (MAPIR 카메라의 RAW+JPG 및 JPG만 지원)
* MAPIR 카메라가 아닌 다른 카메라에서 촬영된 이미지 (참조: [지원되는 카메라](../supported-cameras.md))
* 파일 손상 또는 SD 카드에서 전송이 완료되지 않음

**해결 방법**: 파일 형식과 카메라 모델 호환성 확인

### 카메라 모델이 감지되지 않음

**가능한 원인:**

* 수정된 EXIF 메타데이터
* 외부 소프트웨어에서 편집된 이미지
* 파일 전송이 완료되지 않음

**해결 방법**: 카메라/SD 카드에서 수정되지 않은 원본 파일을 다시 가져오기

### 타임스탬프 누락

**가능한 원인:**

* 카메라 시계가 올바르게 설정되지 않음
* 외부 소프트웨어에 의해 EXIF 데이터가 제거됨

**해결 방법**: 촬영 당시 카메라 시간 설정이 올바른지 확인***

## 다음 단계

파일을 가져온 후:

1. **파일 목록 확인** - 모든 이미지가 올바르게 로드되었는지 확인
2. **카메라 모델 확인** - 카메라가 올바르게 인식되었는지 확인
3. **대상 이미지 표시** - [대상 이미지 선택](choosing-target-images.md) 참조
4. **설정 조정** - [프로젝트 설정](adjusting-project-settings.md)에서 처리 옵션 구성
5. **처리 시작** - [처리 시작하기](starting-the-processing.md) 참조

프로젝트 구성에 대한 자세한 내용은 [프로젝트 설정 조정하기](adjusting-project-settings.md)를 참조하십시오.
