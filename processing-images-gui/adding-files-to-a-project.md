# 프로젝트에 파일 추가하기

Chloros에서 프로젝트를 생성하거나 열었다면, 다음 단계는 다중 스펙트럼 이미지를 추가하여 처리를 시작하는 것입니다. ‘파일 브라우저’<img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> 탭을 사용하면 이미지를 쉽게 가져오고 데이터 세트를 관리할 수 있습니다.

## 파일 브라우저 열기

1. Chloros에서 프로젝트를 열거나 생성합니다.
2. 왼쪽 사이드바에서 **파일 브라우저** <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> 아이콘을 클릭합니다.
3. 파일 브라우저 패널에 프로젝트의 파일 목록이 표시됩니다.

{% hint style="info" %}
**지원되는 파일 형식**:

* **Survey3W / Survey3N**: RAW+JPG 쌍 및 JPG 이미지 (RAW+JPG 권장)
* **LATTICE**: `.tif` / `.tiff` 캡처 파일 — Chloros 카메라 제어 또는 LATTICE 허브를 통해 기록된 파일
* **광센서 데이터**: `.daq` 기록 데이터(DAQ-U/M/E) 및 DAQ-M `.csv` 하향 복사 로그 — 반사율 보정을 위해 이미지와 함께 가져옴
{% endhint %}

***

## 프로젝트에 이미지 추가하기

프로젝트에 이미지를 추가하는 주요 방법은 두 가지가 있습니다:

### 방법 1: 파일 추가

이 옵션을 사용하여 개별 이미지 파일이나 소량의 파일을 가져올 수 있습니다.

1. 파일 브라우저 패널 상단의 **&quot;파일 추가&quot;**<img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> 버튼을 클릭합니다.
2. 이미지가 포함된 폴더로 이동합니다.
3. 하나 이상의 이미지 파일을 선택합니다(**Ctrl** 키를 누른 상태에서 여러 파일을 선택할 수 있습니다).
4. **&quot;열기&quot;**를 클릭하여 선택한 파일을 가져옵니다.

### 방법 2: 폴더 추가

이 옵션을 사용하여 폴더에 있는 모든 이미지를 한 번에 가져올 수 있습니다. 하나의 대화 상자에서 **여러 폴더**를 선택할 수 있습니다.

1. 파일 브라우저 패널 상단의 **&quot;폴더 추가&quot;**<img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> 버튼을 클릭합니다.
2. 캡처 세션 이미지가 들어 있는 폴더로 이동하여 선택합니다.
3. **&quot;폴더 선택&quot;**을 클릭하여 지원되는 모든 이미지를 가져옵니다.

{% hint style="info" %}
**로드에 실패한 파일은 보고됩니다.** 폴더에 Chloros가 인식하지만 로드할 수 없는 파일이 포함된 경우, 경고 메시지가 표시됩니다. 이미지가 그리드에서 아무런 알림 없이 사라지는 일은 없습니다.
{% endhint %}

***

## LATTICE 캡처 폴더 가져오기

LATTICE 캡처는 **내보내기 수준별로 하나의 하위 폴더**에 저장됩니다. 예를 들어 `raw/`, `debayered/`, `radiance/`, `reflectance/`, `preview/` — 루트 디렉터리에는 이에 대응하는 `.daq` 다운웰링 파일이 있습니다:

```
output/
├── raw/           capture_<timestamp>_SN<serial>_raw.tif
├── debayered/     capture_<timestamp>_SN<serial>_debayered.tif
├── preview/       capture_<timestamp>_SN<serial>_display.tif
└── *.daq          the downwelling reading matched to the capture
```

**&#x27;폴더 추가&#x27;를 캡처 파일의 루트 디렉터리로 지정하십시오** (위의 `output/` 참조). 선택한 폴더 자체에는 이미지가 없지만 하위 폴더가 있는 경우, Chloros는 해당 하위 폴더로 자동으로 탐색합니다. 즉, 해당 수준의 하위 폴더와 루트 `.daq`가 한 번에 모두 가져옵니다.**캡처 가져오기 방식:*** 각 캡처는 캡처 단위로 그룹화된 **단일 이미지**로 가져오며(레벨당 하나의 항목이 아닌), 동일한 캡처의 다른 레벨은 해당 이미지의 보기 모드로 표시됩니다.
* **처리는 항상 원본 프레임에서 시작됩니다.** 다른 레벨들도 볼 수는 있지만, 파이프라인을 통과하는 것은 오직 `raw`뿐입니다. 이미 처리된 결과물을 다시 처리하면 보정 처리가 중복 적용되므로, Chloros는 처리 대상에서 제외됩니다. 재수입된 내보내기 파일은 캡처의 원본 슬롯을 절대 차지할 수 없습니다.
* 원본 파일 수입 없이 저장된 캡처 폴더는 정상적으로 표시되지만, 처리 과정에서 건너뛰어지며 로그에 해당 내용이 기록됩니다. (CLI 플래그 `--input-level`를 사용하면 이 경우의 진입점을 강제할 수 있습니다 — [CLI 참조](../reference/cli-reference.md#what-a-captures-folder-looks-like).)

**LATTICE 허브 세션**도 동일한 방식으로 가져옵니다: 허브에서 복사한 세션 폴더(이 폴더에는 `raw/`와 `previews/`가 포함되어 있음)를 ‘폴더 추가’에 지정하고, DAQ-M `.csv` 다운웰링 로그도 함께 지정합니다. 카메라나 DAQ의 보정 데이터가 아직 컴퓨터에 캐시되어 있지 않은 경우, Chloros는 가져오기 시 일련번호를 기반으로 자동으로 해당 데이터를 가져옵니다(한 번만 인터넷 연결 필요).***

## 파일 브라우저 표 이해하기

이미지가 가져오기 완료되면 다음 열로 구성된 표에 표시됩니다.

### 파일 이름

* 카메라의 원본 파일 이름
* 카메라의 명명 규칙을 유지합니다(예: IMG\_0001.RAW 또는 capture\_20260816\_101500\_SN213800234\_raw.tif)

### 타임스탬프

* 이미지가 촬영된 날짜 및 시간
* 이미지 EXIF 메타데이터에서 추출됨
* 광센서 매칭, PPK 동기화 및 보정 타겟 스케줄링에 사용됨

### 카메라 모델

* 카메라 및 필터 구성을 자동으로 감지함
* Survey3 예시: Survey3W\_RGN, Survey3N\_OCN, Survey3W\_RGB
* LATTICE 예시: LATT-M3M-L41-F550, LATT-M3C-L87-FRGN
* 올바른 처리 프로필을 적용하는 데 사용됩니다

### 타겟 열 (선택 상자)

* 보정 타겟이 포함된 이미지의 경우 이 상자를 선택하십시오
* 하나 이상의 이미지가 선택된 경우, **선택된 이미지만** 타겟 검색 대상이 됩니다
* 자세한 내용은 [타겟 이미지 선택](choosing-target-images.md)을 참조하십시오

### 이미지 메타데이터 보기

표 위쪽 오른쪽 모서리에 있는 토글 버튼을 클릭하면 이미지 그리드 영역에 선택한 이미지의 메타데이터가 표시됩니다.

## 프로젝트 내 광센서 파일

* `.daq` 및 `.csv` 파일은 파일 브라우저 목록에 표시되지만 클릭할 수 있는 이미지가 아닙니다. 이 파일들은 반사율 보정을 위한 하향 조도를 제공합니다.
* 가져온 모든 `.daq`/`.csv` 파일은 **프로젝트 설정 → DAQ 광 센서**에 나열되며, 여기서 각 파일에 적용된 디퓨저 캡 보정 값을 확인할 수 있습니다. [프로젝트 설정 조정](adjusting-project-settings.md)을 참조하십시오.
* **광 센서** 탭에서 생성한 기록은 열려 있는 프로젝트에 자동으로 추가되므로 수동으로 가져올 필요가 없습니다.***

## 프로젝트 내 파일 관리

### 파일 제거

프로젝트에서 원하지 않는 이미지를 제거하려면:

1. 파일 브라우저 테이블에서 하나 이상의 이미지를 선택합니다.
2. **&quot;선택 항목 제거&quot;**<img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line"> 버튼을 클릭합니다.
3. 제거를 확인합니다(파일은 디스크에서 삭제되지 않고 프로젝트에서만 제거됩니다).

### 정렬 및 필터링

* **열별 정렬**: 열 머리글을 클릭하여 이미지를 정렬합니다.
* **타임스탬프 정렬**: 촬영 시계열 순서대로 이미지를 정리할 때 유용합니다.
* **카메라 모델 필터**: 여러 대의 카메라를 사용하는 경우 카메라 유형별로 이미지를 그룹화할 수 있습니다.***

## 이미지 미리보기

### 전체 이미지 보기

파일 브라우저에서 이미지 썸네일을 클릭하면 메인 미리보기 영역에 이미지가 표시됩니다:

1. 이미지가 중앙 미리보기 패널에 나타납니다
2. 확대/축소 컨트롤을 사용하여 이미지 세부 사항을 확인합니다
3. 화살표 키를 사용하여 이미지를 이동합니다

### 빠른 탐색

* **이전 이미지**: 왼쪽 화살표를 클릭하거나 ← 키를 누릅니다
* **다음 이미지**: 오른쪽 화살표를 클릭하거나 → 키를 누릅니다
* **확대/축소**: 마우스 휠이나 확대/축소 버튼을 사용합니다
* **이동**: 확대된 상태에서 이미지를 클릭하고 드래그합니다***

## 중복 파일 처리

Chloros는 중복 파일을 자동으로 감지하여 무시합니다:

* 파일 이름이 동일한 파일은 건너뜁니다
* 실수로 인한 중복 처리를 방지합니다
* 중복 파일이 감지되면 경고 메시지가 표시됩니다

{% hint style="warning" %}
**중요**: 가져오기 전에 원본 이미지 파일의 이름을 변경하거나 수정하지 마십시오. Chloros는 올바른 처리를 위해 원본 파일 이름과 메타데이터에 의존합니다.
{% endhint %}

***

## 다양한 카메라로 구성된 데이터 세트

프로젝트에 여러 대의 MAPIR 카메라에서 촬영된 이미지가 포함된 경우:

1. Chloros는 각 카메라 모델(Survey3, LATTICE 또는 혼합)을 자동으로 감지합니다.
2. 각 카메라 유형은 해당 보정 프로필을 사용하여 처리됩니다.
3. 파일 브라우저의 ‘카메라 모델’ 열에 카메라 모델이 표시됩니다.
4. 처리 시 각 카메라마다 고유한 출력 폴더 구조가 생성됩니다.

**예시 시나리오**: Survey3W, RGN + Survey3N, OCN로 구성된 듀얼 카메라 설정, 또는 RGB 마스터와 여러 개의 협대역 모듈로 구성된 LATTICE 어레이***

## 모범 사례

### 가져오기 전 정리

* 보정 대상 이미지를 측량 이미지와 동일한 폴더에 보관하십시오
* 각 촬영 세션의 `.daq` / `.csv` 광센서 파일을 해당 세션의 이미지와 함께 보관하십시오
* 카메라/SD 카드/허브의 원래 폴더 구조를 유지하십시오
* 서로 다른 세션의 데이터 세트를 하나의 프로젝트에 혼합하지 마십시오

### 파일 이름 지정

* 원본 카메라 파일 이름(IMG\_0001.RAW, capture\_... 등)을 유지하십시오
* 가져오기 전에 파일 이름을 변경하지 마십시오
* 원본 이름에는 중요한 메타데이터가 포함되어 있습니다

### 보정 대상 이미지

* 세션당 항상 1~2장의 보정 대상 이미지를 포함하십시오(Survey3; LATTICE의 경우 DAQ 기록으로 대체 가능 — [보정 대상 이미지 선택](choosing-target-images.md) 참조)
* 촬영 세션 전후에 타겟 이미지를 촬영하십시오
* 타겟 이미지를 촬영 영역과 동일한 조명 조건에 배치하십시오
* ‘타겟(Target)’ 확인란을 사용하여 타겟 이미지를 표시하십시오

## 일반적인 문제 및 해결 방법

### 가져오기 후 이미지가 표시되지 않는 경우

**가능한 원인:**

* 지원되지 않는 파일 형식 (이 페이지 상단의 지원되는 파일 형식 목록 참조)
* MAPIR가 아닌 카메라에서 촬영된 이미지 ([지원되는 카메라](../supported-cameras.md) 참조)
* 파일 손상 또는 SD 카드에서 전송이 불완전함

**해결 방법**: 파일 형식과 카메라 모델의 호환성을 확인하고, 실패한 특정 파일에 대한 파일 불러오기 경고 메시지를 확인하십시오

### 카메라 모델이 감지되지 않음

**가능한 원인:**

* 수정된 EXIF 메타데이터
* 외부 소프트웨어에서 편집된 이미지
* 파일 전송 불완전

**해결 방법**: 카메라/SD 카드에서 수정되지 않은 원본 파일을 다시 가져오십시오.

### 타임스탬프 누락

**가능한 원인:**

* 카메라 시계가 올바르게 설정되지 않음
* 외부 소프트웨어에 의해 EXIF 데이터가 제거됨

**해결 방법**: 촬영 당시 카메라 시간 설정이 올바른지 확인하십시오.

### 프로젝트를 다시 열었을 때 누락된 파일이 보고됨

프로젝트를 마지막으로 열었을 때부터 소스 파일이 이동되거나 삭제된 경우, Chloros 오류는 빈 그리드가 표시되는 대신 **어떤** 파일이 누락되었는지 알려줍니다. 파일을 원래 경로에 복원하거나, 누락된 항목을 제거한 후 다시 가져오십시오.***

## 다음 단계

파일이 가져오기 완료되면:

1. **파일 목록 검토** - 모든 이미지가 올바르게 로드되었는지 확인
2. **카메라 모델 확인** - 카메라가 올바르게 인식되었는지 확인
3. **대상 이미지 표시** - [대상 이미지 선택](choosing-target-images.md) 참조
4. **설정 조정** - [프로젝트 설정](adjusting-project-settings.md)에서 처리 옵션 구성
5. **처리 시작** - [처리 시작하기](starting-the-processing.md) 참조

프로젝트 구성에 대한 자세한 내용은 [프로젝트 설정 조정](adjusting-project-settings.md)을 참조하십시오.
