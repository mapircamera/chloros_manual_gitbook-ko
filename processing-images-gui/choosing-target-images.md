# 타겟 이미지 선택

보정 타겟이 포함된 이미지를 표시하는 것은 Chloros 처리 파이프라인의 속도를 크게 높여주는 중요한 단계입니다. 타겟 이미지를 미리 선택해 두면, Chloros가 데이터셋의 모든 이미지를 일일이 스캔하여 보정 타겟을 찾을 필요가 없어집니다.

## 타겟 이미지를 표시해야 하는 이유

### 처리 속도

타겟 이미지를 표시하지 않으면, Chloros는 다음 작업을 수행해야 합니다:

* 프로젝트 내의 모든 이미지를 스캔
* 각 이미지에 대해 타겟 탐지 알고리즘 실행
* 수백 또는 수천 개의 이미지를 불필요하게 확인

**결과**: 특히 대규모 데이터셋의 경우 처리 시간이 상당히 길어질 수 있습니다.

### 타겟 이미지 표시 시

특정 이미지의 &#x27;타겟(Target)&#x27; 열을 선택하면:

* Chloros는 선택된 이미지만 대상으로 스캔합니다
* 대상 탐지가 훨씬 더 빠르게 완료됩니다
* 전체 처리 시간이 대폭 단축됩니다

{% hint style="success" %}
**속도 향상**: 500장 규모의 데이터셋에서 2~3장의 대상 이미지를 지정하면 대상 탐지 시간이 30분 이상에서 1분 미만으로 단축될 수 있습니다.
{% endhint %}

***

## 타겟 이미지 표시 방법

### 1단계: 타겟 이미지 식별

파일 브라우저에서 가져온 이미지를 살펴보고, 어떤 이미지에 보정 타겟이 포함되어 있는지 확인하십시오.

**일반적인 사례:*** **촬영 전 타겟**: 세션 시작 전에 촬영된 타겟
* **촬영 후 타겟**: 세션 완료 후 촬영된 타겟
* **현장 타겟**: 촬영 영역 내에 배치된 타겟
* **다중 타겟**: 세션당 2~3개의 타겟 이미지 (권장)

### 2단계: 타겟 열 확인

보정 타겟이 포함된 각 이미지에 대해:

1. 파일 브라우저 테이블에서 해당 이미지를 찾습니다.
2. **타겟** 열(가장 오른쪽 열)을 찾습니다.
3. 해당 이미지의 타겟 열에 있는 체크박스를 클릭합니다.
4. 타겟이 포함된 모든 이미지에 대해 이 과정을 반복합니다.

### 3단계: 선택 내용 확인

처리하기 전에 다음 사항을 다시 한 번 확인하십시오:

* [ ] 보정 타겟이 포함된 모든 이미지가 선택되어 있는지
* [ ] 타겟이 아닌 이미지가 실수로 선택되지 않았는지
* [ ] 선택된 이미지에서 타겟이 선명하게 보이는지

***

## 타겟 이미지 모범 사례

### 타겟 촬영 지침

**시점:**

* 촬영 세션 직전과 촬영 중 내내 타겟 이미지를 촬영하십시오
* DAQ 광 센서와 동일한 조명 조건에서 촬영하십시오
* 최상의 결과를 얻으려면 가능한 한 자주 타겟 이미지를 촬영하는 것이 이상적입니다. 그렇지 않을 경우, 시간이 지남에 따라 광 센서 데이터를 사용하여 보정을 조정하게 됩니다.

**카메라 위치:**

* 타겟이 중앙에 위치하고 이미지 중앙의 약 40~60%를 차지하도록 카메라를 타겟 위에 들어주세요.
* 카메라를 타겟 표면과 평행하거나 수직(나디르)으로 유지하세요

**조명:**

* DAQ 광 센서와 동일한 주변 조명
* 대상 표면에 그림자가 생기지 않도록 하십시오
* 신체, 차량 또는 식물로 광원을 가리지 마십시오
* 흐린 날씨가 가장 일관된 결과를 제공합니다

**대상 상태:**

* 대상 패널을 깨끗하고 건조하게 유지하십시오
* 4개의 패널 모두 선명하게 보이고 가려지지 않아야 합니다
* 가능하면 대상을 광원과 수직 또는 정수직으로 배치하십시오

### 대상 이미지 수:

**최소:**세션당 표적 이미지 1장.**권장:** 세션당 표적 이미지 3~5장.**최적의 일정:**

* 광 센서 녹화 시작 직후 3~5장의 이미지를 촬영하십시오
* 최상의 결과를 위해 촬영 사이에 카메라 위치를 번갈아 가며 변경하십시오
* 선택 사항: 조명 조건이 지속적으로 변하는 경우 세션 도중 주기적으로 촬영하십시오

## 여러 대의 카메라 사용

### 듀얼 카메라 설정

두 대의 MAPIR 카메라를 동시에 사용하는 경우(예: Survey3W RGN + Survey3N OCN):

1. **두 대의 카메라**로 동시에 대상 이미지를 촬영합니다.
2. 두 카메라 모두에 **동일한 물리적 대상**을 사용합니다.
3. 파일 브라우저에서 **두 카메라 유형** 모두에 대한 대상 이미지를 표시합니다.
4. Chloros는 각 카메라의 보정에 적합한 대상을 사용합니다.

### 카메라 모델 열

**카메라 모델** 열은 어떤 이미지가 어떤 카메라에서 촬영된 것인지 식별하는 데 도움이 됩니다:

* Survey3W\_RGN
* Survey3N\_OCN
* Survey3W\_RGB
* 등

이 열을 사용하여 프로젝트 내 각 카메라 유형에 대해 타깃을 올바르게 지정했는지 확인하십시오.

***

## 타깃 감지 설정

### 감지 민감도 조정

Chloros가 타깃을 올바르게 감지하지 못하는 경우, [프로젝트 설정](adjusting-project-settings.md)에서 다음 설정을 조정하십시오:**최소 보정 샘플 영역:*** **기본값**: 25 픽셀
* 작은 아티팩트에서 오탐지가 발생하면 **값을 늘리세요*** 타겟이 감지되지 않으면 **값을 줄이세요**

**최소 타겟 클러스터링:*** **기본값**: 60
* 타겟이 여러 개의 감지 결과로 분할되면 **값을 늘리세요*** 색상 변화가 있는 타겟이 완전히 감지되지 않는 경우 **값을 줄이세요**

***

## 일반적인 타겟 이미지 문제

### 문제: 타겟이 감지되지 않음

**가능한 원인:**

* 파일 브라우저에서 타겟 이미지가 표시되지 않음
* 프레임 내 타겟이 너무 작음(이미지의 30% 미만)
* 조명 상태 불량(그림자, 눈부심)
* 타겟 감지 설정이 너무 엄격함

**해결 방법:**

1. 올바른 이미지에 대해 &#x27;타겟&#x27; 열이 선택되어 있는지 확인
2. 미리보기에서 타겟 이미지 품질 검토
3. 품질이 좋지 않은 경우 타겟 재촬영
4. 필요한 경우 타겟 감지 설정 조정

### 문제: 잘못된 타겟 감지

**가능한 원인:**

* 흰색 건물, 차량 또는 지면 피복이 타겟으로 오인됨
* 식생 내 밝은 부분
* 감지 민감도가 너무 낮음

**해결 방법:**

1. 실제 표적 이미지만 표시하여 탐지 범위를 제한하십시오
2. 최소 보정 샘플 영역을 늘리십시오
3. 최소 표적 클러스터링 값을 높이십시오
4. 표적 이미지에 표적만 표시되도록 하십시오(배경 잡음 최소화)

***

## 검증 체크리스트

처리 시작 전에 표적 이미지 선택을 확인하십시오:

* [ ] 세션당 최소 1개의 표적 이미지가 표시됨
* [ ] 모든 대상 이미지의 &#x27;대상&#x27; 열 체크박스가 선택되어 있음
* [ ] 대상 이미지가 조사 시기와 동일한 시간대에 촬영됨
* [ ] 클릭 시 미리보기에서 대상이 선명하게 보임
* [ ] 각 대상 이미지에서 4개의 보정 패널이 모두 보임
* [ ] 대상에 그림자나 가림물이 없음
* [ ] 듀얼 카메라의 경우: 두 카메라 유형 모두에 대해 대상이 표시됨

***

## 대상 없이 처리

### 보정 대상 없이 처리하기

과학적 연구에는 권장되지 않지만, 대상 없이 처리할 수 있습니다:

1. 모든 대상 열의 체크박스를 선택 해제합니다
2. 프로젝트 설정에서 &quot;반사율 보정&quot;을 **비활성화**합니다
3. 비네팅 보정은 여전히 적용됩니다
4. 출력물은 절대 반사율에 대해 보정되지 않습니다

{% hint style="warning" %}
**권장하지 않음**: 반사율 보정이 없으면 픽셀 값은 상대적 밝기만을 나타낼 뿐, 과학적인 반사율 측정값은 아닙니다. 정확하고 재현 가능한 결과를 얻으려면 보정 타겟을 사용하십시오.
{% endhint %}
