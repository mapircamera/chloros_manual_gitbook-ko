# 대상 이미지 선택

보정 대상이 포함된 이미지를 표시하면 Chloros가 해당 이미지를 정확히 어디에서 찾아야 하는지 알 수 있습니다. ‘대상(Target)’ 열에서 하나 이상의 이미지가 선택되어 있으면, Chloros는 **선택된 이미지만** 스캔합니다. 따라서 대상을 표시하는 것은 처리 속도를 높일 뿐만 아니라, 측량 이미지가 대상 이미지로 오인되는 것을 방지하는 방법이기도 합니다.

<figure><img src="../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>

## 왜 대상 이미지를 표시해야 할까요?

### 표시는 스캔을 제어합니다

특정 이미지의 ‘대상(Target)’ 열을 선택하면:

* Chloros는 선택된 이미지만 대상으로 스캔합니다
* 대상 탐지가 훨씬 더 빠르게 완료됩니다
* 측량 이미지로 인해 잘못된 대상 탐지가 발생하지 않습니다

**아무** 이미지도 선택하지 않으면, Chloros는 프로젝트 내 모든 이미지를 스캔하는 방식으로 전환됩니다:

* 각 이미지에 대해 표적 탐지 알고리즘이 실행됩니다
* 수백 또는 수천 장의 이미지가 불필요하게 검사됩니다
* 특히 대용량 데이터 세트의 경우 처리 시간이 상당히 길어집니다

{% hint style="success" %}
**속도 향상**: 500장의 이미지로 구성된 데이터셋에서 2~3장의 표적 이미지를 표시하면 표적 탐지 시간이 30분 이상에서 1분 미만으로 단축될 수 있습니다.
{% endhint %}

***

## 표적 이미지 표시 방법

### 1단계: 표적 이미지 식별

파일 브라우저에서 가져온 이미지를 살펴보고, 어떤 이미지에 보정 표적이 포함되어 있는지 확인합니다.

**일반적인 사례:*** **촬영 전 표적**: 세션을 시작하기 전에 촬영된 표적
* **촬영 후 타겟**: 세션 완료 후 촬영된 이미지
* **현장 타겟**: 촬영 영역 내에 배치된 타겟
* **다중 타겟**: 세션당 2~3개의 타겟 이미지 (권장)

### 2단계: 타겟 열<img src="../.gitbook/assets/image (33).png" alt="" data-size="original"> 확인

보정 타겟이 포함된 각 이미지에 대해:

1. 파일 브라우저 테이블에서 해당 이미지를 찾습니다.
2. **타겟** 열(가장 오른쪽 열)을 찾습니다.
3. 해당 이미지의 타겟 열에 있는 확인란을 클릭합니다.
4. 타겟이 포함된 모든 이미지에 대해 이 과정을 반복합니다.

### 3단계: 선택 내용 확인

처리하기 전에 다음 사항을 다시 한 번 확인하십시오:

* [ ] 보정 타겟이 포함된 모든 이미지에 체크가 되어 있는지
* [ ] 타겟이 아닌 이미지가 실수로 체크되지 않았는지
* [ ] 체크된 이미지에서 타겟이 선명하게 보이는지

***

## LATTICE: DAQ가 녹화 중일 때 타겟은 선택 사항입니다

LATTICE 다중 스펙트럼 카메라의 경우, 프레임 내 보정 타겟은 가능한 **두 가지**반사율 기준 중**하나**입니다:

* **프레임 내 타겟**: 표시된 타겟 이미지가 ‘Chloros’의 품질(QA) 게이트를 통과하면, 해당 타겟은 주변 영상의**절대 반사율 기준**이 됩니다.
* **DAQ 하향 복사**: 타겟이 없거나(또는 QA 검사에 실패할 경우), Chloros는 대신 DAQ 광센서의 하향 복사 조도(ρ = π·L/E)를 기반으로 반사율을 계산합니다. `.daq` 또는 DAQ-M `.csv` 기록이 캡처 영역을 포함하는 경우,**타겟 이미지가 전혀 없어도** 보정된 반사율을 얻을 수 있습니다.

이 자동 동작이 기본 설정입니다. CLI/SDK에서 이는 `--reflectance-source auto`에 해당하며, `target`(엄격 — DAQ 대체 없음) 또는 `daq`(DAQ 우선)를 강제로 적용할 수도 있습니다. [CLI 참조 문서](../reference/cli-reference.md#per-product-export-toggles-lattice-multispectral)를 참조하십시오.

**LATTICE 타겟 형상**: Survey3에 사용되는 기존의 패널 감지 방식 외에도, LATTICE 처리는 프로젝트별로 구성되는**ArUco 마킹 타겟**,**고정 ROI 타겟**및**스트립 타겟**을 지원합니다. 단위별**측정된** 타겟 반사율 스캔 데이터는 일련번호(CLI: `--target-reflectance-dir`, 타겟 단위당 `<serial>.csv` 1개)로 제공될 수 있으며, 명목상 T3/T4P 스펙트럼이 대체값으로 사용됩니다.

{% hint style="info" %}
**F988 모듈**: F988 반사율은 현장 반사율 패널을 사용하여 보정됩니다. 해당 대역은 DAQ 광 센서의 보정 범위를 벗어남에 따라, Chloros는 가장 최근의 패널 캡처 데이터를 적용하고 패널 관측 사이에도 이를 유지합니다. F988 모듈이 DAQ 전용으로 처리되는 경우, Chloros는 해당 대역에 대한 DAQ 기반 반사율을 거부합니다(건너뛰는 이유: `dls-uncalibrated-band-988`). 패널 워크플로가 지원되는 방법입니다.
{% endhint %}

## 타겟 이미지에 대한 모범 사례

### 타겟 캡처 지침

**타이밍:**

* 캡처 세션 직전과 세션 진행 중 지속적으로 타겟 이미지를 캡처하십시오.
* DAQ 광 센서와 동일한 조명 조건에서 캡처하십시오.
* 최상의 결과를 얻으려면 가급적 자주 타겟 이미지를 촬영하십시오. 그렇지 않을 경우, 시간이 지남에 따라 광 센서 데이터를 사용하여 보정을 조정하게 됩니다.

**카메라 위치:**

* 타겟이 중앙에 위치하고 이미지 중앙의 약 40~60%를 차지하도록 카메라를 타겟 위에 들고 촬영하십시오.
* 카메라를 대상 표면과 평행하거나 정수직(nadir)이 되도록 유지하십시오.

**조명:**

* DAQ 광 센서와 동일한 주변 조명을 유지하십시오.
* 대상 표면에 그림자가 생기지 않도록 하십시오.
* 신체, 차량 또는 식물로 광원을 가리지 마십시오.
* 흐린 날씨가 가장 일관된 결과를 제공합니다.

**대상 상태:**

* 표적 패널을 깨끗하고 건조하게 유지하십시오.
* 표적의 모든 패널(예: T4의 4개 패널 모두)이 선명하게 보이고 가려지지 않아야 합니다.
* 가능하면 표적을 광원과 수직이거나 정수직 아래로 배치하십시오.

### 표적 이미지 수:

**최소:**세션당 표적 이미지 1장.**권장:** 세션당 표적 이미지 3~5장.**최적의 일정:**

* 광 센서 녹화가 시작된 직후 3~5장의 이미지를 촬영하십시오
* 최상의 결과를 얻으려면 촬영 사이에 카메라를 회전시키십시오
* 선택 사항: 조명 조건이 지속적으로 변하는 경우 세션 도중 주기적으로 촬영

***

## 여러 대의 카메라 사용

### 듀얼 카메라 설정

MAPIR 카메라 두 대를 동시에 사용하는 경우(예: Survey3W RGN + Survey3N OCN):

1. **두 대의 카메라**로 동시에 타겟 이미지를 촬영하십시오
2. 두 카메라 모두에 **동일한 물리적 대상**을 사용합니다
3. 파일 브라우저에서 **두 카메라 유형** 모두에 해당하는 대상 이미지를 표시합니다
4. Chloros은 각 카메라의 보정에 적합한 대상을 사용합니다

### 카메라 모델 열

**카메라 모델** 열을 통해 어떤 이미지가 어느 카메라에서 촬영된 것인지 확인할 수 있습니다:

* Survey3W\_RGN
* Survey3N\_OCN
* LATT-M3M-L41-F550
* LATT-M3C-L87-FRGN
* 등

이 열을 사용하여 프로젝트 내 각 카메라 유형에 대해 타깃을 올바르게 표시했는지 확인하십시오.

## 타겟 감지 설정

### 감지 민감도 조정

Chloros가 타겟을 올바르게 감지하지 못하는 경우, [프로젝트 설정](adjusting-project-settings.md)에서 다음 설정을 조정하십시오:**최소 보정 샘플 영역 (px):*** **기본값**: 25 픽셀
* 작은 아티팩트에서 오탐지가 발생하는 경우 **값을 늘리세요*** 타겟이 감지되지 않는 경우 **값을 줄이세요**

**최소 타겟 클러스터링(0-100):*** **기본값**: 60
* **타겟이 여러 개의 탐지 결과로 분할되는 경우** **값을 늘리세요*** **색상 변화가 있는 타겟이 완전히 탐지되지 않는 경우** **값을 줄이세요**{% hint style="info" %}**CLI 팁**: `chloros-cli process`는 동일한 조정 매개변수(`--min-target-size`, `--target-clustering`)을 지원하며, `--target`/`--targets` 플래그를 사용하면 전체 입력 폴더를 ‘타겟 패널 전용’으로 지정할 수 있습니다. [CLI 참조](../reference/cli-reference.md)를 참조하십시오.
{% endhint %}

## 일반적인 대상 이미지 문제

### 문제: 대상 감지되지 않음

**가능한 원인:**

* 파일 브라우저에서 타겟 이미지가 표시되지 않음
* 프레임 내 타겟이 너무 작음(이미지의 30% 미만)
* 조명 상태가 좋지 않음(그림자, 눈부심)
* 타겟 감지 설정이 너무 엄격함

**해결 방법:**

1. 올바른 이미지에 대해 ‘타겟’ 열이 선택되어 있는지 확인
2. 미리보기에서 타겟 이미지 품질을 검토하십시오
3. 품질이 좋지 않은 경우 타겟을 다시 촬영하십시오
4. 필요한 경우 타겟 감지 설정을 조정하십시오

### 문제: 잘못된 타겟 감지

**가능한 원인:**

* 흰색 건물, 차량 또는 지면 피복이 타겟으로 오인됨
* 식생 내의 밝은 부분
* 감지 민감도가 너무 낮음

**해결 방법:**

1. 실제 표적 이미지만 표시 — 선택된 이미지만 스캔됩니다
2. 최소 보정 샘플 면적을 늘립니다
3. 최소 표적 클러스터링 값을 높입니다
4. 표적 이미지에 표적만 표시되도록 합니다(배경 잡음 최소화)

## 검증 체크리스트

처리를 시작하기 전에 표적 이미지 선택을 확인하십시오:

* [ ] 세션당 최소 1개의 표적 이미지가 표시되어 있음 (또는 LATTICE의 경우, 해당 세션을 포괄하는 `.daq`/`.csv` 기록이 있음)
* [ ] 모든 대상 이미지에 대해 대상 열의 확인란이 선택되어 있음
* [ ] 조사 시기와 동일한 시간대에 캡처된 대상 이미지
* [ ] 클릭 시 미리보기에서 대상이 선명하게 보임
* [ ] 각 대상 이미지에서 모든 보정 패널이 보임
* [ ] 대상에 그림자나 가림 현상이 없음
* [ ] 듀얼 카메라의 경우: 두 카메라 유형 모두에서 표적이 표시되어 있음

***

## 표적 없는 처리

### LATTICE: DAQ 녹화 파일 사용 시

LATTICE 촬영 중에 DAQ 광 센서가 하향 복사 조도를 기록했을 경우, 표적은 필요하지 않습니다:

1. 이미지가 포함된 `.daq`(또는 DAQ-M `.csv`) 파일을 가져옵니다.
2. ‘타겟(Target)’ 열의 체크를 해제합니다.
3. 반사율은 DAQ 하향 기준값을 기반으로 자동으로 계산됩니다.
4. 방사도는 타겟이나 DAQ가 전혀 필요하지 않습니다. 카메라의 공장 출하 시 방사계 보정값만으로 산출됩니다

### 기준 데이터 없이 처리하기

타겟이나 DAQ 없이도 처리할 수 있습니다:

1. 모든 ‘타겟’ 열의 체크박스를 선택 해제합니다
2. 프로젝트 설정에서 &quot;반사율 보정/화이트 밸런스&quot;를 **비활성화**하면 타겟 감지 과정이 완전히 건너뜁니다
3. 비네트 보정은 여전히 적용됩니다
4. 출력물은 절대 반사율에 대해 보정되지 않습니다(LATTICE 멀티스펙트럼은 여전히 디베이어 처리된 미리보기 및 방사도 결과물을 내보냅니다)

{% hint style="warning" %}
**Survey3의 과학적 연구에는 권장하지 않음**: 반사율 보정이 없으면 Survey3의 픽셀 값은 상대적 밝기만을 나타낼 뿐, 과학적인 반사율 측정값은 아닙니다. 정확하고 재현 가능한 결과를 얻으려면 보정 타겟(또는 LATTICE의 경우 DAQ 광 센서)을 사용하십시오.
{% endhint %}
