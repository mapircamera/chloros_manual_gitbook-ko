# 프로젝트 설정 조정

이미지를 처리하기 전에, 워크플로 요구 사항에 맞게 프로젝트 설정을 구성하는 것이 중요합니다. ‘프로젝트 설정’ <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> 패널을 통해 보정, 처리 옵션, 다중 스펙트럼 지수 및 내보내기 형식을 포괄적으로 제어할 수 있습니다.

## 프로젝트 설정 열기

1. Chloros에서 프로젝트를 엽니다.
2. 왼쪽 사이드바에서 **프로젝트 설정** <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> 아이콘을 클릭합니다
3. 프로젝트 설정 패널에 모든 구성 옵션이 표시됩니다

{% hint style="info" %}
**설정은 프로젝트와 함께 자동으로 저장됩니다**. 프로젝트를 다시 열면 모든 설정이 복원됩니다.
{% endhint %}

***

## 일반적인 워크플로우를 위한 빠른 설정

### 기본 설정 (대부분의 사용자에게 권장)

일반적인 MAPIR Survey3 카메라 워크플로우의 경우, 기본 설정이 잘 작동합니다:

* ✅ **비네팅 보정**: 사용
* ✅ **반사율 보정**: 사용 (MAPIR 타겟 이미지가 필요함)
* ✅ **디베이어 방식**: 표준 (빠름, 중간 품질)
* ✅ **내보내기 형식**: TIFF (16비트)

이미지를 가져온 후 이 기본 설정으로 처리를 시작하면 됩니다.

***

## 프로젝트 설정 개요

프로젝트 설정 패널은 여러 카테고리로 구성되어 있습니다. 아래는 각 섹션에 대한 요약입니다. 전체 문서는 [프로젝트 설정](../project-settings/project-settings.md)을 참조하십시오.

### 타겟 감지

Chloros가 이미지에서 보정 타겟을 식별하는 방식을 제어합니다.

**주요 설정:*** **최소 보정 샘플 영역**: 타겟 감지를 위한 크기 임계값 (기본값: 25 픽셀)
* **최소 타겟 클러스터링**: 타겟 영역을 그룹화하기 위한 유사도 임계값 (기본값: 60)**조정 시점:**

* 오탐지가 발생하면 샘플 영역을 늘리십시오
* 표적이 탐지되지 않을 경우 줄이십시오
* 표적이 여러 개의 탐지 결과로 분할될 경우 클러스터링 값을 조정하십시오

### 처리

주요 이미지 처리 및 보정 옵션입니다.

**주요 설정:*** **비네팅 보정**: 가장자리의 렌즈 어두워짐을 보정합니다 ✅ 권장
* **반사율 보정**: 보정 표적을 사용하여 값을 정규화합니다 ✅ 권장
* **디베이어 방식**: RAW를 3채널 다중 스펙트럼으로 변환하는 알고리즘
* **최소 재보정 간격**: 보정 타겟을 사용하는 간격 (0 = 모두 사용)**고급 설정:*** **광센서 시간대 오프셋**: PPK 시간 동기화를 위한 설정 (기본값: 0)
* **PPK 보정 적용**: .daq 파일의 GPS/노출 핀 데이터 사용
* **노출 핀 1/2**: 듀얼 카메라 설정 시 카메라를 노출 핀에 할당

### 디베이어링 방식

현재 Chloros에서는 2가지 디베이어링 방식을 제공합니다:

#### 표준 (빠름, 중간 품질)

표준 디베이어링은 처리 속도가 빠르지만 디베이어링 색상 노이즈가 나타나므로, 정확도는 떨어지고 노이즈가 많은 이미지가 생성됩니다.

#### 텍스처 인식 (느림, 최고 품질) \[Chloros+ 전용]

텍스처 인식은 고품질 에지 인식 디베이어링과 AI/ML 노이즈 제거 모델을 결합하여 디베이어링 노이즈를 거의 모두 제거합니다. 텍스처 인식 모델은 실행에 GPU 메모리(VRAM)가 필요합니다. 더 빠른 처리를 위해 4GB 이상의 VRAM이 확보된 환경에서 사용하는 것을 권장합니다.

### 지수 (다중 스펙트럼 지수)

계산 및 내보낼 식생 지수를 설정합니다.

**지수 추가 방법:**

1.**&quot;지수 추가&quot;** 버튼을 클릭합니다
2. 드롭다운 메뉴에서 지수를 선택합니다(NDVI, NDRE, GNDVI 등).
3. 시각화 설정(LUT 색상, 값 범위)을 구성합니다.
4. 필요에 따라 여러 지수를 추가합니다.

**주요 지수:*** **NDVI**: 일반적인 식생 건강 상태 (가장 일반적)
* **NDRE**: RedEdge와 함께 초기 스트레스 감지
* **GNDVI**: 엽록소 농도에 민감
* **OSAVI**: 육안으로 확인 가능한 토양과 호환성 우수
* **EVI**: 높은 잎 면적 지수(LAI) 지역**사용자 정의 공식 (Chloros+ 전용):**

* 사용자 지정 다중 스펙트럼 지수 공식 생성
* 모든 이미지 채널에 밴드 연산 적용
* 재사용을 위해 사용자 지정 공식 저장

사용 가능한 모든 지수 및 공식은 [다중 스펙트럼 지수 공식](../project-settings/multispectral-index-formulas.md)을 참조하십시오.

### 내보내기

출력 파일 형식과 품질을 제어합니다.

**사용 가능한 형식:*** **TIFF (16비트)**: GIS 및 과학적 분석에 권장 (0-65,535 범위)
* **TIFF (32비트, 백분율)**: 부동 소수점 반사율 값 (0.0-1.0 범위)
* **PNG (8비트)**: 시각화를 위한 무손실 압축 (0-255 범위)
* **JPG (8비트)**: 파일 크기가 가장 작으며, 손실 압축 (0-255 범위)***

## 설정 저장 및 불러오기

### 프로젝트 템플릿 저장

일관된 워크플로우를 위해 재사용 가능한 템플릿을 생성합니다:

1. 프로젝트 설정 패널에서 원하는 모든 설정을 구성합니다
2. 하단의 **&quot;프로젝트 템플릿 저장&quot;** 섹션으로 스크롤합니다
3. 설명이 포함된 템플릿 이름을 입력합니다(예: &quot;Survey3N\_RGN\_Agriculture&quot;)
4. 저장 아이콘을 클릭합니다

**장점:**

* 여러 프로젝트에 동일한 설정을 적용할 수 있습니다
* 팀원들과 구성을 공유할 수 있습니다
* 반복되는 설문조사에서 일관성을 유지할 수 있습니다

### 새 프로젝트에서 템플릿 불러오기

새 프로젝트를 생성할 때:

1. 메인 메뉴에서 **&quot;새 프로젝트&quot;**를 선택합니다
2. **&quot;템플릿에서 불러오기&quot;** 옵션을 선택합니다
3. 저장된 템플릿을 선택합니다
4. 모든 설정이 자동으로 적용됩니다

### 작업 디렉터리

**&quot;프로젝트 저장 폴더&quot;** 설정은 새 프로젝트가 기본적으로 생성되는 위치를 지정합니다:

* **기본 위치**: `C:\Users\[Username]\Chloros Projects`
* **위치 변경**: 편집 아이콘을 클릭하고 새 폴더를 선택하세요
* **변경 시나리오**:
  * 팀 협업을 위한 네트워크 드라이브
  * 저장 공간이 더 많은 다른 드라이브
  * 연도/고객별로 정리된 폴더 구조

## PPK (사후 처리 기동학) 설정

정밀한 지리적 위치 파악을 위해 GPS가 탑재된 MAPIR DAQ 레코더를 사용하는 경우:

### 필수 조건

* GPS(GNSS) 모듈이 장착된 MAPIR DAQ
* 노출 핀 정보가 포함된 .daq 로그 파일
* 캡처 세션 중 DAQ 노출 핀에 연결된 카메라

### 구성 단계

1. .daq 로그 파일을 프로젝트 폴더에 배치합니다
2. 프로젝트 설정에서 **&quot;PPK 보정 적용&quot;** 확인란을 선택합니다
3. 필요한 경우 **&quot;광 센서 시간대 오프셋&quot;**을 설정합니다(기본값: UTC 기준 0)
4. 카메라를 노출 핀에 할당합니다:
   * **단일 카메라**: 핀 1에 자동으로 할당됩니다
   * **듀얼 카메라**: 각 카메라를 올바른 핀에 수동으로 할당합니다**노출 핀 할당:*** **노출 핀 1**: 드롭다운 메뉴에서 카메라 모델을 선택합니다
* **노출 핀 2**: 두 번째 카메라를 선택하거나 &quot;사용 안 함&quot;을 선택합니다
* 동일한 카메라를 두 핀 모두에 할당할 수 없습니다

{% hint style="warning" %}
**중요**: 노출 핀은 각 카메라에 올바르게 할당되어야 합니다. 잘못된 할당은 부정확한 위치 정보 데이터를 초래합니다.
{% endhint %}

## 고급 시나리오

### 다중 카메라 프로젝트

하나의 프로젝트에서 여러 대의 MAPIR 카메라의 이미지를 처리할 때:

1. Chloros가 각 카메라 모델을 자동으로 감지합니다
2. 각 카메라에 적절한 처리 프로필이 적용됩니다
3. PPK: 각 카메라를 올바른 노출 핀에 수동으로 할당합니다
4. 모든 카메라는 동일한 내보내기 형식과 인덱스를 사용합니다

**예시**: Survey3W RGN + Survey3N OCN 듀얼 카메라 리그

### 타임랩스 또는 다중 날짜 측량

시간이 지남에 따라 동일한 지역을 반복적으로 측량하는 경우:

1. 표준 설정이 포함된 템플릿을 생성합니다
2. 매 세션마다 일관된 보정 타겟 설정을 사용합니다
3. 각 날짜를 별도의 프로젝트로 처리합니다
4. 비교 가능한 결과를 위해 동일한 설정을 사용합니다
5. 시간적 분석을 위해 동일한 형식으로 내보냅니다

### 대규모 데이터셋

이미지가 많은 프로젝트(500장 이상)의 경우:

* 날짜나 지역별로 더 작은 프로젝트로 나누는 것을 고려하십시오
* 더 빠른 결과를 위해 Chloros+ 병렬 처리를 사용하십시오
* 일괄 자동화를 위해 CLI 또는 API 사용을 고려하십시오
* 타겟 감지 시간을 줄이기 위해 최소 재보정 간격을 조정하십시오

## 설정 확인

처리를 시작하기 전에 다음 주요 설정을 검토하십시오:

* [ ] 파일 브라우저에서 카메라 모델이 올바르게 감지되었는지
* [ ] 비네팅 보정이 활성화되었는지
* [ ] 반사율 보정이 활성화되었는지
* [ ] 보정 대상 이미지가 하나 이상 가져왔는지
* [ ] 원하는 다중 스펙트럼 지수가 추가되었는지
* [ ] 워크플로우에 적합한 내보내기 형식이 선택되었는지
* [ ] PPK 설정이 구성되었는지 (노출 이벤트가 포함된 .daq 파일을 사용하는 경우)
